## 5. หมายเหตุอื่น

- **Load combination (§8 ของ skill):** ตรงกับ ch05 Table 5.3.1 — ควรเพิ่มว่าลด L เป็น 0.5 ได้ตาม §5.3.3 และ W/E ต้องเป็นระดับกำลัง
- **ρw:** commentary R22.5.5.1 ให้นับเฉพาะเหล็กที่อยู่ลึกเกิน 2h/3 จากผิวอัด — ควรระบุในโค้ดสำหรับคานเหล็กหลายชั้น/เหล็กบน
- **Cover:** ตรงกับ ch20 Table 20.5.1.3.1 (คานภายใน 40 mm, สัมผัสดิน/อากาศ DB20+ 50 mm, ≤ DB16 40 mm, เทชิดดิน 75 mm)
- **ข้อจำกัดของการตรวจครั้งนี้:** KB เองเป็นสรุปจากฉบับ inch-pound — ค่า SI ด้านบนเป็นค่าแปลงมาตรฐานของ 318M ที่ตรงกับ skill แต่ยังควรเทียบกับเล่ม 318M ตัวจริงอีกครั้ง

2. เพิ่มตรวจ **ระยะขาปลอกตามขวาง** ตาม Table 9.7.6.2.2 (ค่ายืนยันแล้ว)
3. เพิ่มฟังก์ชัน **ℓd / ℓdh / ระยะทาบ** ตาม Ch.25 (รวม ψg)
4. เพิ่ม **checklist integrity + การตัดเหล็ก** ในรายงาน (อย่างน้อยเป็นรายการตรวจ)
5. ตรวจอัตโนมัติ: deep beam, h > 900 mm, Table 9.6.3.1 (h ≤ 250 mm), ปลอกยึดเหล็กอัด
