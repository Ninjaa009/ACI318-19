# ตรวจค่าคงที่ SI ที่สกิลใช้ (ACI 318M-19)

ตรวจเมื่อ 2026-10-05 · ใช้ร่วมกันทั้ง rc-beam-aci318m19 และ rc-column-aci318m19

## วิธีตรวจ

1. **ค่าต้นทาง inch-pound** ทุกตัวเทียบกับต้นฉบับ ACI 318-19 แล้ว (ข้อความ OCR + ภาพหน้า PDF) — Ch.6, 9, 10, 19, 20, 21, 22, 24, 25
2. **แปลงหน่วยแบบตรง** (1 MPa = 145.04 psi, √psi = 12.04√MPa, 1 in. = 25.4 mm) แล้วเทียบกับค่าที่สกิลใช้ — ผ่านเมื่อต่างไม่เกิน 3% (318M ปัดค่าคงที่เป็นตัวเลขกลม)
3. **แหล่งภายนอก** — เว็บของผู้ผลิตซอฟต์แวร์/บทเรียนถูกบล็อกจาก environment นี้ ใช้ได้เฉพาะข้อความสรุปของผลค้นหา ซึ่งยืนยันได้บางค่า:
   - สมการทั่วไป ℓd (25.4.2.4a) ฉบับ SI ใช้ **1.1λ√f′c** และ ℓd ≥ 300 mm
   - ℓdc = max(**0.24**fyψr/(λ√f′c), **0.043**fyψr)·db ≥ 200 mm (ตัวอย่าง DB32, fy 420: 0.043·420·32 = 578 mm)
   - ทาบรับแรงอัด **0.071**fy·db ≥ 300 mm (fy ≤ 420)
   - ψc = f′c/105 + 0.6 (ค่า SI ของ f′c/15,000 + 0.6)

ค่าตาราง Table 25.4.2.3 (2.1/1.7/1.4/1.1) สอดคล้องกับสมการทั่วไป 1.1 ด้วย: (cb+Ktr)/db = 1.5 → 1.1×1.5 = 1.65 ≈ 1.7; คูณ ψs = 0.8 → 2.06 ≈ 2.1; กรณีอื่น 1.1 และ 1.1/0.8 ≈ 1.4

## สิ่งที่แก้จากการตรวจนี้

- **เกณฑ์ขนาดเหล็กใน ℓd (Table 25.4.2.3, 25.4.2.5):** ACI ใช้สูตร/ψs ของ "เหล็กเล็ก" เฉพาะ **No.19 (19.1 mm) ลงไป** — เดิมสคริปต์นับ **DB20** เป็นเหล็กเล็ก (ℓd สั้นไป ~19%) แก้ให้ DB20 ใช้แถวเหล็กใหญ่ (1.7 / 1.1, ψs = 1.0) แล้ว

## ข้อจำกัดที่ยังเหลือ
