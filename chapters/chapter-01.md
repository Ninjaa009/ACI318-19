# ACI 318-19 Chapter 1 — General (ทั่วไป)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 9–14 — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

## 1.1 ขอบเขตของบท (Scope)

บทนี้ครอบคลุม:

- ข้อกำหนดทั่วไป
- วัตถุประสงค์
- การนำไปใช้ (applicability)
- การตีความ (interpretation)
- บทบาทของ building official และ licensed design professional
- เอกสารก่อสร้าง (construction documents)
- การทดสอบและตรวจสอบ (testing and inspection)
- การอนุมัติระบบพิเศษ (special systems)

Code นี้ใช้กับ plain concrete, คอนกรีตเสริมเหล็ก (nonprestressed), คอนกรีตอัดแรง (prestressed) และการยึดเข้ากับคอนกรีต (anchoring)

## 1.2 ทั่วไป (General)

| หัวข้อ | สาระสำคัญ |
|---|---|
| ฉบับทางการ | ภาษาอังกฤษ หน่วย inch-pound (ACI 318) |
| ฉบับอื่น | 318M (อังกฤษ, SI), 318S (สเปน, SI), 318SUS (สเปน, inch-pound) |
| ข้อขัดแย้งระหว่างฉบับ | ยึดฉบับทางการ |
| ระดับข้อกำหนด | เป็นข้อกำหนด **ขั้นต่ำ** — วิศวกรกำหนดให้สูงกว่าได้ |
| การแก้ไขโดยท้องถิ่น | เป็นกฎหมายของท้องถิ่นนั้น ไม่ใช่ส่วนหนึ่งของ Code |
| ไม่มี building code | ใช้ Code นี้เป็นเกณฑ์ขั้นต่ำได้ |

## 1.3 วัตถุประสงค์ (Purpose)

- เพื่อความปลอดภัยและสุขภาพของสาธารณะ ผ่านเกณฑ์ด้าน **strength, stability, serviceability, durability, integrity**
- ไม่ครอบคลุมทุกประเด็นการออกแบบ และไม่แทนวิจารณญาณทางวิศวกรรม
- ไม่กำหนดวิธีการก่อสร้าง (means and methods)

## 1.4 การนำไปใช้ (Applicability)

### ใช้กับ / ใช้ได้

- โครงสร้างคอนกรีตที่ออกแบบและก่อสร้างภายใต้ general building code
- การประเมิน ซ่อมแซม และฟื้นฟูโครงสร้างเดิม (ข้อกำหนดเฉพาะอยู่ใน **ACI 562**)
- โครงสร้างนอก building code โดยใช้ข้อที่เกี่ยวข้อง เช่น
  - ปล่องควัน: ACI 307
  - ไซโล: ACI 313
  - โครงสร้างนิวเคลียร์: ACI 349 และ ACI 359
- พื้นหล่อบน steel deck แบบ **noncomposite** (ตัว deck ใช้ SDI NC)
- เปลือกบาง (thin shell) และ folded plate ให้ใช้ **ACI 318.2**
- บ้านเดี่ยว บ้านแฝด และทาวน์เฮาส์: ฐานราก ผนังฐานราก และ slab-on-ground ใช้ **ACI 332** แทนได้

### ไม่ใช้กับ

- **เสาเข็ม เสาเข็มเจาะ และ caisson ที่ฝังในดิน** ยกเว้น:
  - (a) ส่วนที่อยู่ในอากาศ ในน้ำ หรือในดินที่ยึดรั้งด้านข้างไม่พอกันการโก่งเดาะ
  - (b) เสาเข็มสำเร็จรูปที่รับโครงสร้างใน SDC A, B (§13.4)
  - (c) deep foundation ที่รับโครงสร้างใน SDC C–F (Ch.13, §18.13)
- **slab-on-ground** ที่ไม่ได้ถ่ายแรงแนวดิ่งหรือแรงด้านข้างของโครงสร้างลงดิน (ใช้ ACI 360R)
- **ถังและอ่างเก็บน้ำ** (ใช้ ACI 350, 334.1R, 372R)
- **พื้น composite steel deck** (ใช้ SDI C) — แต่ตัวคอนกรีต และส่วนที่ออกแบบเป็น RC เช่น เหล็กรับโมเมนต์ลบเหนือจุดรองรับ ยังต้องเป็นไปตาม Code นี้

## 1.5 การตีความ (Interpretation)

- Code ประกอบด้วย chapters และ appendixes รวมถึงตาราง รูป เชิงอรรถ และมาตรฐานที่อ้างอิง
- **Commentary ไม่ใช่ข้อบังคับ** และใช้สร้างข้อขัดแย้งหรือความกำกวมกับ Code ไม่ได้
- ถ้าข้อกำหนดขัดกัน **ข้อเฉพาะ (specific) ชนะข้อทั่วไป (general)**
- ถ้า Code ขัดกับมาตรฐานที่อ้างอิงใน Ch.3 ให้ยึด Code นี้
- ถ้า Code นิยามคำไว้ ให้ใช้นิยามนั้น ถ้าไม่มี ให้ดู ACI Concrete Terminology ก่อน แล้วจึงดูพจนานุกรม
- ความหมายของคำ:
  - **shall** = บังคับ และข้อกำหนดเป็นข้อบังคับเสมอแม้ไม่มีคำว่า shall
  - **and** = ต้องครบทุกข้อ
  - **or** = เลือกได้ แต่ต้องเป็นไปตามอย่างน้อยหนึ่งข้อ
  - กาลปัจจุบันรวมถึงอนาคต
- **Severability:** ถ้าศาลตัดสินว่าข้อใดใช้ไม่ได้ ข้ออื่นยังมีผล และคำตัดสินมีผลเฉพาะในเขตอำนาจของศาลนั้น

## 1.6 Building official

- คือผู้บังคับใช้ Code (นิยามใน §2.3)
- การตัดสินใจมีผลเฉพาะในเขตอำนาจของตน และแก้ไข Code ไม่ได้ (มีเพียง ACI ที่แก้ได้)
- มีสิทธิ์สั่งทดสอบวัสดุใด ๆ ได้

## 1.7 Licensed design professional

- คือวิศวกรผู้รับผิดชอบงานออกแบบโครงสร้าง **หรือ** specialty engineer ที่ได้รับมอบหมายงานบางส่วน
- งานที่มอบหมายต้องมีเงื่อนไขดังนี้:
  - อำนาจของ specialty engineer จำกัดเฉพาะงานที่ได้รับมอบหมาย
  - ขอบเขตงานต้องชัดเจน จนเห็นความรับผิดชอบของแต่ละฝ่าย
- ตัวอย่างงานที่มักมอบหมาย: precast, post-tensioned

## 1.8 เอกสารก่อสร้างและบันทึกการออกแบบ

- ข้อมูลในเอกสารก่อสร้างต้องเป็นไปตาม **Ch.26** และตามที่ท้องถิ่นกำหนด
- ยื่นรายการคำนวณประกอบแบบเมื่อ building official ต้องการ
- **ใช้โปรแกรมคอมพิวเตอร์ได้** ต้องส่งสมมติฐาน input และ output ประกอบ
  - input: ชื่อชิ้นส่วน น้ำหนักบรรทุก และช่วงความยาว
  - output: แรงเฉือน โมเมนต์ และแรงปฏิกิริยาที่ตำแหน่งสำคัญ
  - เสา: ควรมี moment magnification factor ด้วย
- ใช้ model analysis เสริมรายการคำนวณได้

## 1.9 การทดสอบและตรวจสอบ

- ทดสอบวัสดุตาม Ch.26
- ตรวจงานก่อสร้างตาม general building code และ Ch.26
- บันทึกผลการตรวจตาม Ch.26

## 1.10 การอนุมัติระบบพิเศษ

- ระบบออกแบบ ระบบก่อสร้าง หรือวัสดุทางเลือกที่ Code ไม่ครอบคลุม แต่พิสูจน์ความเพียงพอแล้วด้วยการใช้งานจริง การวิเคราะห์ หรือการทดสอบ ยื่นข้อมูลต่อ building official หรือคณะกรรมการวิศวกรที่แต่งตั้งได้
- คณะกรรมการมีอำนาจตรวจสอบข้อมูล สั่งทดสอบ และออกกฎเฉพาะ ซึ่งเมื่อได้รับอนุมัติแล้วจะมีผลเท่ากับ Code
- ข้อนี้ไม่ใช้กับ model test ตาม §1.8.2 และการประเมินกำลังโครงสร้างเดิมตาม Ch.27
