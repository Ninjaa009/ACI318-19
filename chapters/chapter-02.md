# ACI 318-19 Chapter 2 — Notation and Terminology (สัญลักษณ์และนิยามศัพท์)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 15–46 (ฉบับ inch-pound) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> บทนี้ยาวมาก (สัญลักษณ์หลายร้อยตัว, นิยามศัพท์ราว 200 คำ) ไฟล์นี้คัดเฉพาะที่ใช้บ่อยในงานออกแบบ

## 2.1 ขอบเขต (Scope)

บทนี้กำหนดสัญลักษณ์ (notation) และนิยามศัพท์ (terminology) ที่ใช้ทั้ง Code

- ต้นฉบับใช้หน่วย inch-pound (in., psi, lb) ฉบับ ACI 318M ใช้ mm, MPa, N
- ถ้า Code นิยามคำไว้ ให้ใช้นิยามนั้นก่อนแหล่งอื่น (ดู §1.5.5)

## 2.3 นิยามศัพท์ที่สำคัญ (Terminology)

### คอนกรีต

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| concrete | ส่วนผสมซีเมนต์ (หรือวัสดุประสาน) มวลรวมละเอียด มวลรวมหยาบ น้ำ ±สารผสมเพิ่ม |
| structural concrete | คอนกรีตที่ใช้รับน้ำหนัก ทั้งแบบมีและไม่มีเหล็กเสริม |
| plain concrete | ไม่มีเหล็กเสริม หรือมีน้อยกว่าขั้นต่ำของคอนกรีตเสริมเหล็ก |
| reinforced concrete | มีเหล็กเสริมไม่น้อยกว่าขั้นต่ำ (รวมทั้งแบบอัดแรงและไม่อัดแรง) |
| nonprestressed concrete | RC ที่ไม่มีเหล็กอัดแรง หรือพื้นสองทางที่อัดแรงน้อยกว่าขั้นต่ำ |
| prestressed concrete | RC ที่สร้างหน่วยแรงภายในด้วยเหล็กอัดแรงเพื่อลดหน่วยแรงดึง |
| precast concrete | หล่อที่อื่นแล้วนำมาติดตั้ง |
| normalweight concrete | มวลรวมตาม ASTM C33 ความหนาแน่น > 135 lb/ft³ (โดยทั่วไป 145–150 lb/ft³) |
| lightweight concrete | ใช้มวลรวมมวลเบา ความหนาแน่นสมดุล (ASTM C567) 90–135 lb/ft³ |
| all-lightweight concrete | ใช้มวลรวมมวลเบาทั้งหยาบและละเอียด (ASTM C330) |
| w/cm ratio | อัตราส่วนมวลน้ำ (ไม่รวมที่มวลรวมดูดซับ) ต่อมวลวัสดุประสาน |
| cementitious materials | ปูนซีเมนต์และวัสดุปอซโซลาน/ตะกรัน ที่ใช้เป็นตัวประสาน |
| shotcrete | คอนกรีตหรือมอร์ตาร์พ่นด้วยแรงลม (dry-mix / wet-mix) |
| aggregate | มวลรวม รวมถึงมวลรวมรีไซเคิลจากคอนกรีตบด — ใหม่ใน 318-19 (ดู §26.4.1.2.1) |
| lightweight aggregate | ตาม ASTM C330 ความหนาแน่นหลวม ≤ 70 lb/ft³ |

### ชิ้นส่วนโครงสร้าง

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| column | ชิ้นส่วนรับแรงอัดเป็นหลัก รับโมเมนต์/เฉือน/บิดร่วมได้ |
| pedestal | ชิ้นส่วนรับแรงอัด ความสูง/ด้านแคบที่สุด **≤ 3** |
| wall | ชิ้นส่วนแนวดิ่ง ความยาว/ความหนา **> 3** ใช้กั้นหรือแบ่งพื้นที่ |
| wall pier | ส่วนผนังแนวดิ่งระหว่างช่องเปิด ℓw/bw ≤ 6.0 และ hw/ℓw ≥ 2.0 |
| boundary element | ขอบผนัง/ไดอะแฟรมที่เสริมเหล็กตามยาวและตามขวางเพิ่ม |
| collector | ชิ้นส่วนถ่ายแรงจากไดอะแฟรมเข้าสู่ระบบต้านแรงด้านข้าง |
| drop panel | ส่วนหนาใต้พื้นรอบเสา ลดเหล็กลบ ลดความหนาพื้น เพิ่มกำลังเฉือน |
| shear cap | ส่วนยื่นใต้พื้น เพื่อเพิ่มกำลังเฉือนอย่างเดียว |
| column capital | ส่วนขยายหัวเสาที่หล่อเป็นเนื้อเดียวกับเสา |
| one-way / two-way construction | ชิ้นส่วนที่ออกแบบให้ดัดทางเดียว / สองทาง |
| structural truss | กลุ่มชิ้นส่วน RC ที่รับแรงตามแนวแกนเป็นหลัก |

### เหล็กเสริม

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| deformed reinforcement | เหล็กข้ออ้อย, ลวดข้ออ้อย, ตะแกรงเชื่อม ตามมาตรฐานที่กำหนด |
| tie | เหล็กปลอกโอบเหล็กยืน (หรือ: ตัวรับแรงดึงใน strut-and-tie) |
| stirrup | เหล็กรับแรงเฉือน/แรงบิดในคาน |
| hoop | ปลอกปิดหรือปลอกพันต่อเนื่อง มีขอแบบแผ่นดินไหวทั้งสองปลาย |
| crosstie | เหล็กยึดรั้ง: ปลายหนึ่งขอแผ่นดินไหว อีกปลายขอ ≥ 90° ยื่น ≥ 6db |
| seismic hook | ของอ ≥ 135° (ปลอกกลม ≥ 90°) ยื่น ≥ 6db และ ≥ 3 in. |
| spiral reinforcement | เหล็กเกลียวต่อเนื่องพันเป็นวงรอบ |
| extreme tension reinforcement | เหล็กชั้นที่ไกลจากผิวรับแรงอัดที่สุด |
| development length | ระยะฝังที่ต้องการเพื่อให้เหล็กพัฒนากำลังออกแบบได้ |
| tendon / bonded / unbonded | ชุดเหล็กอัดแรง / ยึดเกาะกับคอนกรีต / ไม่ยึดเกาะ |
| pretensioning / post-tensioning | ดึงลวดก่อนเท / ดึงหลังคอนกรีตแข็งตัว |

### กำลังและน้ำหนักบรรทุก

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| nominal strength | กำลังที่คำนวณตาม Code ก่อนคูณ φ |
| design strength | φ × nominal strength |
| required strength | กำลังที่ต้องการเพื่อรับ factored load ตามชุดผสมน้ำหนัก |
| factored load | น้ำหนักบรรทุกคูณด้วย load factor |
| service load | น้ำหนักบรรทุกใช้งานจริง ไม่คูณ load factor |
| dead / superimposed dead load | น้ำหนักบรรทุกคงที่ / น้ำหนักคงที่อื่นนอกจากน้ำหนักตัวเอง |
| live load | น้ำหนักที่ไม่ได้กระทำถาวร (ไม่รวมแรงจากสิ่งแวดล้อม) |
| load path | ลำดับชิ้นส่วนและจุดต่อที่ถ่ายแรงจากจุดกระทำลงสู่ฐานราก |
| structural integrity | ความสามารถในการกระจายแรงและคงเสถียรภาพเมื่อเกิดความเสียหายเฉพาะจุด |

### การควบคุมความเครียด (Strain limits)

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| net tensile strain (εt) | ความเครียดดึงที่กำลังระบุ ไม่รวมผลจาก prestress, creep, shrinkage, อุณหภูมิ |
| compression-controlled strain limit | εt ที่สภาวะสมดุล (balanced) |
| compression-controlled section | εt ≤ ค่า compression-controlled strain limit |
| tension-controlled section | εt **≥ εty + 0.003** (เปลี่ยนจาก 0.005 ในฉบับก่อน) |

### งานแผ่นดินไหว

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| moment frame (ordinary / intermediate / special) | โครงข้อแข็ง OMF / IMF / SMF ตามระดับรายละเอียด |
| structural wall (ordinary / intermediate precast / special / ductile coupled) | ผนังรับแรงตามระดับรายละเอียด |
| special seismic systems | ระบบที่ใช้ SMF และ/หรือผนังพิเศษ |
| plastic hinge region | ช่วงที่ออกแบบให้เกิดการครากจากการดัด ยาว ≥ h จากหน้าตัดวิกฤต |
| base of structure | ระดับที่ถือว่าแรงแผ่นดินไหวเริ่มกระทำต่ออาคาร |
| seismic-force-resisting system | ส่วนของโครงสร้างที่ออกแบบให้ต้านแรงแผ่นดินไหว |

### Strut-and-Tie และการยึดฝัง (Anchoring)

| คำศัพท์ | ความหมายโดยสรุป |
|---|---|
| strut-and-tie model | แบบจำลอง truss ภายในบริเวณ D-region ประกอบด้วย strut, tie, node |
| strut / tie / node / nodal zone | ตัวรับแรงอัด / ตัวรับแรงดึง / จุดตัด / ปริมาตรคอนกรีตรอบ node |
| anchor (cast-in / post-installed) | ชิ้นเหล็กฝังก่อนเท / ติดตั้งภายหลังเพื่อถ่ายแรงเข้าคอนกรีต |
| anchor (adhesive / expansion / undercut / screw) | ประเภทพุก post-installed |
| concrete breakout strength | กำลังที่ลิ่มคอนกรีตรอบพุกหลุดออก |
| concrete pryout strength | กำลังที่คอนกรีตด้านหลังพุกงัดแตก (พุกสั้นรับแรงเฉือน) |
| anchor pullout strength | กำลังที่พุกถูกดึงหลุดโดยคอนกรีตไม่แตกเป็นลิ่ม |
| shear lug | เหล็กเชื่อมใต้แผ่นฐาน ถ่ายแรงเฉือนด้วยการแบกทาน — ใหม่ใน 318-19 |
