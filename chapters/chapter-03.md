# ACI 318-19 Chapter 3 — Referenced Standards (มาตรฐานอ้างอิง)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 47–50 — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

## 3.1 ขอบเขต (Scope)

- มาตรฐานที่ Code อ้างถึง (รวมถึงใน Annex, Appendix, Supplement) ถือเป็นส่วนหนึ่งของ Code **โดยไม่มีข้อยกเว้น** เว้นแต่ระบุไว้เป็นอย่างอื่น
- อ้างอิงถึง **ฉบับปีที่ระบุ** เท่านั้น ในบทอื่นจะเขียนแค่เลขมาตรฐานแบบย่อ แต่หมายถึงฉบับที่ระบุในบทนี้
- ถ้าใช้ฉบับปีอื่น ผู้ใช้ต้องประเมินเองว่าความแตกต่างมีผลหรือไม่
- มาตรฐาน ASTM แบบคู่ (เช่น A615/A615M) ในเนื้อหา Code เขียนย่อโดยไม่มี "M"
