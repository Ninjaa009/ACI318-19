# ACI 318-19 Chapter 4 — Structural System Requirements (ข้อกำหนดระบบโครงสร้าง)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 51–59 — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

บทนี้เพิ่มเข้ามาตั้งแต่ ACI 318-14 เพื่อมองโครงสร้าง **ทั้งระบบ** ไม่ใช่ออกแบบทีละชิ้น ส่วนใหญ่เป็นการชี้ไปยังบทอื่น จึงเหมือน "แผนที่" ของ Code

## 4.1 ขอบเขต

ใช้กับการออกแบบคอนกรีตโครงสร้างตามขอบเขตใน Ch.1

## 4.2 วัสดุ

|---|---|
| คุณสมบัติคอนกรีตสำหรับออกแบบ | Ch.19 |

| shotcrete | ใช้ข้อกำหนดเดียวกับคอนกรีต เว้นแต่ Code ระบุเป็นอย่างอื่น |

## 4.3 น้ำหนักออกแบบ

- น้ำหนักและชุดผสมน้ำหนักตาม **Ch.5**
- น้ำหนักที่ต้องพิจารณา เช่น dead, live, snow, wind, แผ่นดินไหว, อัดแรง, เครน, การสั่น, แรงกระแทก, การหดตัว, อุณหภูมิ, creep, การขยายตัวของคอนกรีตชดเชยการหดตัว, การทรุดตัวต่างกัน

## 4.4 ระบบโครงสร้างและเส้นทางถ่ายแรง (Load path)

### 4.4.1–4.4.5 ทั่วไป

- ระบบโครงสร้างประกอบด้วย (ตามที่มี): พื้นและหลังคา (one-way/two-way), คานและตง, เสา, ผนัง, ไดอะแฟรม, ฐานราก, จุดต่อ/รอยต่อ/พุกยึด
- ออกแบบแต่ละชิ้นส่วนตาม **Ch.7–18**
- ระบบที่ไม่ตรงตามนี้ใช้ได้ ถ้าได้รับอนุมัติตาม §1.10.1
- ต้องมี load path ต่อเนื่องอย่างน้อยหนึ่งเส้นทาง จากจุดที่แรงกระทำถึงจุดรองรับสุดท้าย โดยกำลังของทุกชิ้นส่วนบนเส้นทางต้องพอ — ควรตรวจหาจุดอ่อน (weak link) ตลอดเส้นทาง
- ต้องรองรับการเปลี่ยนแปลงปริมาตร (creep, shrinkage, อุณหภูมิ) และการทรุดตัวต่างกัน — แนวทางทั่วไป: เหล็กเสริม, closure strip, expansion joint

### 4.4.6 ระบบต้านแรงแผ่นดินไหว

| ข้อ | สาระสำคัญ |
|---|---|
| 4.4.6.1 | ทุกโครงสร้างต้องกำหนด SDC ตาม building code (ถ้าไม่มี ให้ building official กำหนด) |
| 4.4.6.2 | ชนิดระบบต้านแรงแผ่นดินไหวต้องเป็นตามที่ building code อนุญาต |
| 4.4.6.3 | **SDC A** → ไม่ต้องใช้ Ch.18 |
| 4.4.6.4 | **SDC B–F** → ต้องทำตาม Ch.18 เพิ่มจากบทอื่น |
| 4.4.6.5 | ชิ้นส่วนที่ไม่ได้เป็นส่วนของระบบต้านแรงแผ่นดินไหว: SDC B–F ต้องคิดผลต่อการตอบสนองของระบบและผลจากความเสียหาย; SDC D–F ต้องทำตาม Ch.18 (รองรับการเคลื่อนตัว drift) |
| 4.4.6.6 | ต้องคิดผลของชิ้นส่วนที่ไม่ใช่โครงสร้าง (§18.2.2.1) เช่น ผนังก่อที่ทำให้เกิด **short column** |
| 4.4.6.7 | ตรวจสอบด้วย nonlinear response history analysis → ใช้ Appendix A (ใหม่ใน 318-19) |

### 4.4.7 ไดอะแฟรม

- พื้น/หลังคาต้องรับ **ทั้ง** น้ำหนักแนวดิ่งนอกระนาบ **และ** แรงด้านข้างในระนาบพร้อมกัน
- ไดอะแฟรมและจุดต่อต้อง: ถ่ายแรงไปยังโครงข้อแข็ง/ผนัง, ค้ำยันชิ้นส่วนแนวดิ่ง/นอน/เอียง, รับแรงดันดินและแรงดันน้ำที่ถ่ายเข้ามา
- ต้องมี **collector** ในที่ที่ต้องถ่ายแรงระหว่างไดอะแฟรมกับชิ้นส่วนแนวดิ่ง
- ข้อกำหนดทั่วไปอยู่ใน Ch.12; SDC D–F ใช้ Ch.18 เพิ่ม

## 4.5 การวิเคราะห์โครงสร้าง

- ต้องเป็นไปตามหลัก **สมดุลของแรง** และ **ความสอดคล้องของการเสียรูป**
- วิธีวิเคราะห์ที่ยอมรับอยู่ใน **Ch.6** (รวมถึง strut-and-tie สำหรับบริเวณไม่ต่อเนื่อง)

## 4.6 กำลัง (Strength)

หลักการพื้นฐานของ Strength Design:

$$\phi S_n \ge U$$

- Sn = กำลังระบุ (โมเมนต์, เฉือน, บิด, แรงตามแกน, แบกทาน), φ = ตัวคูณลดกำลัง, U = กำลังที่ต้องการจากน้ำหนักประลัย
- φ ครอบคลุม: ความแปรปรวนของวัสดุและมิติ, สมมติฐานในสมการ, ความเหนียว, รูปแบบการวิบัติ, ความสำคัญของชิ้นส่วน
- ⚠️ **กำลังเกินไม่ได้ปลอดภัยเสมอ** — เช่น เพิ่มเหล็กรับโมเมนต์โดยไม่เพิ่มเหล็กปลอก อาจทำให้วิบัติด้วยแรงเฉือนก่อนการดัด (เปราะ) ซึ่งไม่ต้องการในอาคารที่ออกแบบให้เข้าช่วงไม่ยืดหยุ่นขณะเกิดแผ่นดินไหว

## 4.7 สภาวะใช้งาน (Serviceability)

- ต้องพิจารณา: แรงปฏิกิริยา โมเมนต์ เฉือน บิด แรงตามแกน จากการอัดแรง, creep, shrinkage, อุณหภูมิ, การหดตัวตามแกน, การยึดรั้งของชิ้นส่วนที่ต่อกัน และการทรุดตัว
- ถือว่าผ่าน ถ้าออกแบบตามบทของชิ้นส่วนนั้น ๆ
- ชุดผสมน้ำหนักระดับใช้งานไม่ได้กำหนดใน Code (ยกเว้นใน Ch.24) — ดู Appendix C ของ ASCE 7-16 (ไม่บังคับ)

## 4.8 ความทนทาน (Durability)

- ส่วนผสมคอนกรีตตาม §19.3.2 และ §26.4 โดยพิจารณา exposure category
- ป้องกันการกัดกร่อนของเหล็กตาม §20.5 (ระยะหุ้ม)

## 4.9 ความยั่งยืน (Sustainability)

- ระบุข้อกำหนดด้านความยั่งยืนในเอกสารก่อสร้างได้
- แต่ข้อกำหนดด้าน **กำลัง, serviceability, durability ของ Code มาก่อนเสมอ**

## 4.10 Structural integrity

- ต้องจัดเหล็กเสริมและจุดต่อให้โครงสร้างยึดกันเป็นหนึ่งเดียว เพื่อให้ความเสียหายเกิดเฉพาะจุดและไม่ลุกลามเป็นการวิบัติต่อเนื่อง

| พื้นสองทาง (ไม่อัดแรง) | 8.7.4.2 |

## 4.11 การทนไฟ

- ต้องเป็นไปตาม building code (แนวทางเพิ่มเติม: ACI 216.1)
- ถ้า building code กำหนดระยะหุ้มเพื่อกันไฟมากกว่า §20.5.1 → **ใช้ค่าที่มากกว่า**

## 4.12 ข้อกำหนดเฉพาะประเภทการก่อสร้าง

### 4.12.1 Precast

- ออกแบบทุกสภาวะตั้งแต่ผลิต → ถอดแบบ → กองเก็บ → ขนส่ง → ติดตั้ง → ใช้งาน (จุดรองรับและแรงเปลี่ยนไปในแต่ละช่วง)
- ต้องคิดผลของ **ค่าคลาดเคลื่อน (tolerance)** — ดู PCI MNL 120
- ต้องออกแบบแรงและการเสียรูปที่จุดต่อและบริเวณใกล้เคียง
- ถ้าต้องถ่ายแรงในระนาบ: load path ต้องต่อเนื่องผ่านจุดต่อ และถ้ามีแรงดึงต้องมีเหล็กรับ (ต่อทาบได้)
- การกระจายแรงตั้งฉากระนาบ ต้องหาจากการวิเคราะห์หรือทดสอบ (hollow-core กระจายแรงได้ดีกว่า double tee)

### 4.12.2 คอนกรีตอัดแรง

- ออกแบบทั้งกำลังและพฤติกรรมใช้งาน ทุกช่วงตั้งแต่เริ่มอัดแรง
- คิดผลต่อโครงสร้างข้างเคียงจากการเสียรูป การหดตัว การหมุน รวมทั้งอุณหภูมิ creep shrinkage การทรุดตัว
- คิดความเข้มของหน่วยแรงจากการอัดแรง
- ก่อน grout ได้กำลัง ให้หักพื้นที่ท่อ (duct) ออกจากคุณสมบัติหน้าตัด
- tendon ภายนอก (external) ใช้ได้ ประเมินด้วยข้อกำหนดกำลังและ serviceability ของ Code

### 4.12.3 ชิ้นส่วนรับแรงดัดแบบ composite

- ออกแบบแต่ละชิ้นส่วนทุกช่วงการรับน้ำหนัก
- ต้องรับน้ำหนักทั้งหมดที่เกิดก่อนชิ้นส่วน composite ได้กำลังเต็ม
- จัดเหล็กเพื่อลดการแตกร้าวและป้องกันการแยกตัวของชิ้นส่วน

### 4.12.4 คอนกรีตไม่เสริมเหล็ก

- ออกแบบตาม Ch.14

## 4.13 การก่อสร้างและการตรวจสอบ

- ข้อกำหนดการก่อสร้างและการตรวจสอบตาม **Ch.26** และ building code
