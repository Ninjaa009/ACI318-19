# ACI 318-19 Chapter 5 — Loads (น้ำหนักบรรทุก)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 61–65 — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

## 5.1 ขอบเขต

- ใช้เลือก load factor และชุดผสมน้ำหนัก (load combination) สำหรับการออกแบบ
- ยกเว้นการประเมินกำลังโครงสร้างเดิมตาม Ch.27

## 5.2 ทั่วไป

- น้ำหนักบรรทุกต้องรวม: น้ำหนักตัวเอง, น้ำหนักที่กระทำ, ผลจากการอัดแรง, แผ่นดินไหว, การยึดรั้งการเปลี่ยนแปลงปริมาตร และการทรุดตัวต่างกัน
- ค่าน้ำหนักและ **Seismic Design Category (SDC)** ให้ใช้ตาม building code หรือตามที่ building official กำหนด (Code นี้ไม่ได้กำหนดเอง)
- ลดค่า live load ตามพื้นที่ (live load reduction) ได้ตาม building code หรือ ASCE/SEI 7
- ถ้า building code กำหนดน้ำหนักต่างจาก ASCE 7 ให้ใช้ building code แต่ถ้าลักษณะต่างกันมาก อาจต้องปรับข้อกำหนดของ Code

### เทียบระดับความเสี่ยงแผ่นดินไหว (Table R5.2.2)

| แหล่งอ้างอิง | ต่ำ | ปานกลาง | สูง |
|---|---|---|---|
| ACI 318-08 ถึง 318-19, IBC, ASCE 7-98 ขึ้นไป | SDC A, B | SDC C | SDC D, E, F |
| ACI 318-05 และก่อนหน้า | Low | Moderate/Intermediate | High |
| BOCA, SBC, ASCE 7-93/95 | SPC A, B | SPC C | SPC D, E |
| UBC 1991–1997 | Zone 0, 1 | Zone 2 | Zone 3, 4 |

## 5.3 Load factors และชุดผสมน้ำหนัก

### 5.3.1 ชุดผสมน้ำหนักหลัก (Table 5.3.1)

กำลังที่ต้องการ **U** ต้องไม่น้อยกว่าผลของน้ำหนักประลัยในตารางนี้

| สมการ | ชุดผสมน้ำหนัก | น้ำหนักหลัก |
|---|---|---|
| 5.3.1a | U = 1.4D | D |
| 5.3.1b | U = 1.2D + 1.6L + 0.5(Lr หรือ S หรือ R) | L |
| 5.3.1c | U = 1.2D + 1.6(Lr หรือ S หรือ R) + (1.0L หรือ 0.5W) | Lr, S, R |
| 5.3.1d | U = 1.2D + 1.0W + 1.0L + 0.5(Lr หรือ S หรือ R) | W |
| 5.3.1e | U = 1.2D + 1.0E + 1.0L + 0.2S | E |
| 5.3.1f | U = 0.9D + 1.0W | W |
| 5.3.1g | U = 0.9D + 1.0E | E |

D = dead, L = live, Lr = roof live, S = snow, R = rain, W = wind, E = earthquake

**ข้อสังเกต**
- ต้องคำนึงถึงเครื่องหมาย (+/−) ของแต่ละน้ำหนัก ชุดที่ใช้ **0.9D** มีไว้สำหรับกรณีน้ำหนักคงที่ช่วยลดผลของแรงอื่น เช่น แรงยกหรือแรงดึงในเสา
- ถ้าผลของแรงไม่เป็นเชิงเส้นกับน้ำหนัก (เช่น P-delta) ต้องคูณ load factor ก่อนวิเคราะห์
- W และ E ในชุดนี้เป็นค่า **ระดับกำลัง (strength level)** load factor จึงเป็น 1.0
- E ตาม building code รวมทั้งแรงแนวราบ (Eh) และแนวดิ่ง (Ev) โดย Ev บวกหรือลบกับ D และใช้กับทุกชิ้นส่วน
- ค่า R ต้องรวมน้ำขังที่อาจเกิดขึ้น หลังคาต้องมีความลาดพอ และกระบวนการน้ำขังจาก deflection ต้องไม่ลุกลาม (self-limiting)

### ข้อกำหนดเพิ่มเติม (5.3.2 – 5.3.13)

| ข้อ | สาระสำคัญ |
|---|---|
| 5.3.2 | ต้องตรวจกรณีที่บางน้ำหนัก **ไม่กระทำ** พร้อมกัน (เช่น จัด live load สลับช่วง) |
| 5.3.3 | ลด load factor ของ L ในสมการ (c), (d), (e) เป็น **0.5** ได้ **ยกเว้น** โรงจอดรถ, พื้นที่ชุมนุมสาธารณะ, และพื้นที่ที่ L > 100 lb/ft² (≈ 4.79 kPa ≈ 488 kg/m²) — ใช้ร่วมกับการลด live load ตามพื้นที่ได้ |
| 5.3.4 | L ต้องรวม (ถ้ามี): น้ำหนักกระทำเป็นจุด, ยานพาหนะ, เครน, ราวกันตก/ราวมือจับ/แผงกั้นรถ, แรงกระแทก, การสั่นสะเทือน |
| 5.3.5 | ถ้า W เป็นค่า **ระดับใช้งาน (service level)** เช่น ASCE 7-05: ใช้ 1.6W แทน 1.0W ในสมการ (d), (f) และ 0.8W แทน 0.5W ในสมการ (c) |
| 5.3.6 | แรงจากการยึดรั้งการเปลี่ยนแปลงปริมาตรและการทรุดตัวต่างกัน (**T**) ต้องรวมถ้ามีผลต่อความปลอดภัย load factor ของ T **≥ 1.0** |
| 5.3.7 | แรงดันของไหล **F**: ดูตารางด้านล่าง |
| 5.3.8 | แรงดันดินด้านข้าง **H**: ดูตารางด้านล่าง |
| 5.3.9 | อยู่ในพื้นที่น้ำท่วม → ใช้น้ำหนักและชุดผสมของ ASCE/SEI 7 |
| 5.3.10 | มีน้ำแข็งเกาะ → ใช้น้ำหนักและชุดผสมของ ASCE/SEI 7 |
| 5.3.11 | แรงภายในจากแรงปฏิกิริยาที่เกิดจากการอัดแรง (secondary moment) ใช้ load factor **1.0** |
| 5.3.12 | ออกแบบ anchorage zone ของ post-tension: ใช้ **1.2 × แรงดึงลวดสูงสุด (jacking force)** |
| 5.3.13 | อัดแรงในแบบจำลอง strut-and-tie: **1.2** ถ้าเพิ่มแรงใน strut/tie, **0.9** ถ้าลดแรง |

### Load factor ของ F และ H

| กรณี | F (ของไหล) | H (แรงดันดิน) |
|---|---|---|
| กระทำลำพังหรือเสริมผลของ D | 1.4 ในสมการ (a) | — |
| เสริมผลของน้ำหนักหลัก | 1.2 ในสมการ (b)–(e) | 1.6 |
| ถาวรและต้านผลของน้ำหนักหลัก | 0.9 ในสมการ (g) | 0.9 |
| ไม่ถาวรและต้านผลของน้ำหนักหลัก | ไม่ต้องรวม | ไม่ต้องรวม |

## สรุปการใช้งานเร็ว

1. หา D, L, Lr, S, R, W, E จาก building code หรือ ASCE 7 (หรือ กฎกระทรวง/มยผ. สำหรับงานในไทย)
2. ตรวจว่า W และ E เป็นระดับกำลังหรือระดับใช้งาน → ถ้าเป็นระดับใช้งาน ปรับตาม 5.3.5
3. รันชุดผสมทั้ง 7 สมการ + จัดเรียง live load แบบสลับช่วง
4. ลด 1.0L เป็น 0.5L ได้ ถ้าไม่ใช่โรงจอดรถ/พื้นที่ชุมนุม และ L ≤ 100 psf
5. เพิ่ม F, H, T, ผลอัดแรง ตามกรณี
