# ACI 318-19 Chapter 11 — Walls (ผนัง)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 165–174 (ฉบับ inch-pound, f′c และ fy หน่วย psi) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ ไม่ใช่ค่าจากฉบับ 318M

## 11.1 ขอบเขต

- ผนังคอนกรีตเสริมเหล็กและอัดแรง: หล่อในที่, precast จากโรงงาน, precast หล่อในสนาม (รวม tilt-up)
- บทนี้ใช้กับผนังที่รับแรงแนวดิ่งและแรงด้านข้างทั่วไป รวมถึงแรงเฉือนในระนาบของผนังธรรมดา (ordinary structural wall)

| กรณี | ให้ใช้ |
|---|---|
| ผนังพิเศษ (special structural wall) | Ch.18 (§18.10) |
| ผนังคอนกรีตไม่เสริมเหล็ก | Ch.14 |
| กำแพงกันดินแบบ cantilever | Ch.13 |
| ผนังที่ทำหน้าที่เป็นคานคอดิน (grade beam) | §13.3.5 |
| ผนังหล่อในแบบหล่อฉนวน (insulating forms) | ใช้ได้กับอาคาร 1–2 ชั้น (แนวทาง: ACI 506R, PCA 100) |

"structural wall" ใน Code มีความหมายเดียวกับ "shear wall"

## 11.2 ทั่วไป

- วัสดุ: คอนกรีต Ch.19, เหล็ก Ch.20, ของฝัง §20.6
- จุดต่อผนัง precast §16.2, จุดต่อกับฐานราก §16.3

**การกระจายแรงกระทำเป็นจุด (11.2.3.1)** — ความยาวผนังที่ถือว่ารับแรงเป็นจุดแต่ละจุด (ถ้าไม่ได้วิเคราะห์ละเอียด) = ค่าน้อยกว่าของ
- ระยะศูนย์ถึงศูนย์ระหว่างแรง
- ความกว้างที่รองรับ + 4 × ความหนาผนัง

และห้ามเกินรอยต่อแนวดิ่งของผนัง เว้นแต่ออกแบบให้ถ่ายแรงข้ามรอยต่อได้

**ชิ้นส่วนที่ตัดกัน (11.2.4)**
- ผนังต้องยึดกับพื้น หลังคา เสา ผนังค้ำ ผนังที่ตัดกัน และฐานราก (ถ้าไม่ได้พึ่งชิ้นส่วนนั้นในการรองรับ ไม่ต้องยึดก็ได้)
- ผนังหล่อในที่ที่ **Pu > 0.2f′cAg**: คอนกรีตส่วนผนังที่อยู่ในความหนาพื้น ต้องมี f′c **≥ 0.8f′c ของผนัง** (ใหม่ใน 318-19)

## 11.3 ความหนาขั้นต่ำ (Table 11.3.1.1)

| ชนิดผนัง | ความหนาขั้นต่ำ h |
|---|---|
| ผนังรับน้ำหนัก (bearing) ¹ | ค่ามากกว่าของ 4 in. (≈ 100 mm) และ 1/25 ของความยาวหรือความสูงไม่ค้ำยัน (ค่าที่น้อยกว่า) |
| ผนังไม่รับน้ำหนัก (nonbearing) | ค่ามากกว่าของ 4 in. (≈ 100 mm) และ 1/30 ของความยาวหรือความสูงไม่ค้ำยัน (ค่าที่น้อยกว่า) |
| ผนังห้องใต้ดินภายนอก และผนังฐานราก ¹ | 7.5 in. (≈ 190 mm) |

¹ ใช้เฉพาะผนังที่ออกแบบด้วยวิธีอย่างง่าย §11.5.3 — ผนังที่ออกแบบตาม §11.5.2 หรือ §11.8 ไม่ต้องผ่านเกณฑ์นี้ และผนังบางกว่านี้ใช้ได้ถ้าวิเคราะห์ว่ากำลังและเสถียรภาพพอ

## 11.4 กำลังที่ต้องการ

- ชุดผสมน้ำหนัก Ch.5, การวิเคราะห์ Ch.6
- ความชะลูด: ตาม §6.6.4, 6.7 หรือ 6.8 — หรือใช้ §11.8 สำหรับความชะลูดนอกระนาบ
- ต้องออกแบบรับแรงอัดเยื้องศูนย์และแรงด้านข้าง
- แรงที่ต้องพิจารณา: แรงตามแกน, แรงเฉือนและโมเมนต์ **ทั้งในระนาบและนอกระนาบ**, น้ำหนักตัวเอง
- ออกแบบ Mu สูงสุดที่เกิดคู่กับ Pu ในแต่ละชุดผสม — Pu ≤ φPn,max (§22.4.2.1) โดย φ ของหน้าตัด compression-controlled; Mu ต้องขยายผลความชะลูด
- ออกแบบ Vu สูงสุดทั้งในระนาบและนอกระนาบ

## 11.5 กำลังออกแบบ

ต้องผ่าน φPn ≥ Pu, φMn ≥ Mu, φVn ≥ Vu (และคิดปฏิสัมพันธ์ P-M) โดย φ ตาม §21.2

### 11.5.2 แรงตามแกน + การดัด

- ผนังรับน้ำหนัก: Pn, Mn ตาม §22.4 หรือใช้วิธีอย่างง่าย §11.5.3 (นอกระนาบ)
- ผนังไม่รับน้ำหนัก: Mn ตาม §22.3 (ไม่ต้องคิดแรงตามแกน)

### 11.5.3 วิธีอย่างง่าย (แรงตามแกน + ดัดนอกระนาบ)

ใช้ได้เมื่อ **ผนังตันหน้าตัดสี่เหลี่ยม** และแรงลัพธ์อยู่ใน **middle third** ของความหนา (เยื้องศูนย์ ≤ h/6):

$$P_n = 0.55 f'_c A_g \left[1 - \left(\frac{k\ell_c}{32h}\right)^2\right] \quad (11.5.3.1)$$

แล้วคูณ φ ของหน้าตัด compression-controlled (§21.2.2) และต้องมีเหล็กอย่างน้อยตาม §11.6

**Table 11.5.3.2 — ค่า k**

| สภาพปลาย | k |
|---|---|
| ค้ำยันการเคลื่อนที่ด้านข้างบน-ล่าง + ยึดรั้งการหมุนที่ปลายใดปลายหนึ่งหรือทั้งสอง | 0.8 |
| ค้ำยันการเคลื่อนที่ด้านข้างบน-ล่าง + ไม่ยึดรั้งการหมุนทั้งสองปลาย | 1.0 |
| ไม่ค้ำยันการเคลื่อนที่ด้านข้าง | 2.0 |

### 11.5.4 แรงเฉือนในระนาบ

- คำนวณตาม 11.5.4.2–11.5.4.4 หรือ ถ้า **hw/ℓw < 2** ใช้ strut-and-tie (Ch.23) ได้ — ทุกกรณีต้องผ่าน §11.6, 11.7.2, 11.7.3
- **ขีดสูงสุด:** Vn ≤ **8√f′c·Acv** (ลดจาก 10 ใน 318-14 เพราะพื้นที่เปลี่ยนจาก h·d เป็น h·ℓw)

$$V_n = (\alpha_c \lambda \sqrt{f'_c} + \rho_t f_{yt}) A_{cv} \quad (11.5.4.3)$$

| hw/ℓw | αc |
|---|---|
| ≤ 1.5 | 3 |
| ≥ 2.0 | 2 |
| 1.5 – 2.0 | ประมาณค่าเชิงเส้น |

- **ผนังรับแรงดึงสุทธิ** (11.5.4.4): αc = 2(1 + Nu/(500Ag)) ≥ 0 โดย Nu เป็นลบเมื่อเป็นแรงดึง → กำลังจากคอนกรีตลดลงมาก เหล็กแนวนอนต้องรับแรงเฉือนเกือบทั้งหมด
- สมการรูปแบบเดียวกับผนังพิเศษ §18.10.4.1 (ใหม่ใน 318-19)

### 11.5.5 แรงเฉือนนอกระนาบ

- Vn ตาม §22.5

## 11.6 ขีดจำกัดเหล็กเสริม

ρℓ = อัตราส่วนเหล็กแนวดิ่ง (ตามยาว), ρt = อัตราส่วนเหล็กแนวนอน (ตามขวาง)

### 11.6.1 เมื่อ Vu (ในระนาบ) ≤ 0.5φαcλ√f′c·Acv — Table 11.6.1

| ชนิดผนัง | เหล็ก | ขนาด | fy (psi) | ρℓ ขั้นต่ำ | ρt ขั้นต่ำ |
|---|---|---|---|---|---|
| หล่อในที่ | เหล็กข้ออ้อย | ≤ No.5 | ≥ 60,000 | 0.0012 | 0.0020 |
| หล่อในที่ | เหล็กข้ออ้อย | ≤ No.5 | < 60,000 | 0.0015 | 0.0025 |
| หล่อในที่ | เหล็กข้ออ้อย | > No.5 | ทุกค่า | 0.0015 | 0.0025 |
| หล่อในที่ | ตะแกรงลวดเชื่อม | ≤ W31/D31 | ทุกค่า | 0.0012 | 0.0020 |
| Precast | เหล็กข้ออ้อยหรือตะแกรง | ทุกขนาด | ทุกค่า | 0.0010 | 0.0010 |

- ผนังอัดแรงที่หน่วยแรงอัดประสิทธิผลเฉลี่ย ≥ 225 psi ไม่ต้องผ่าน ρℓ ขั้นต่ำ
- ผนัง precast อัดแรงทางเดียว กว้าง ≤ 12 ft และไม่ได้ยึดทางขวาง ไม่ต้องมีเหล็กขั้นต่ำในทิศตั้งฉากกับเหล็กรับแรงดัด
- ไม่ต้องผ่านเกณฑ์นี้ถ้าวิเคราะห์ว่ากำลังและเสถียรภาพพอ

### 11.6.2 เมื่อ Vu (ในระนาบ) > 0.5φαcλ√f′c·Acv

- (a) ρℓ ≥ ค่ามากกว่าของ 0.0025 และ

$$\rho_\ell \ge 0.0025 + 0.5\left(2.5 - \frac{h_w}{\ell_w}\right)(\rho_t - 0.0025) \quad (11.6.2)$$

  แต่ไม่ต้องเกิน ρt ที่ต้องการตาม §11.5.4.3
- (b) ρt ≥ 0.0025
- ผนังเตี้ย (hw/ℓw < 0.5) → ρℓ เท่ากับ ρt; ผนังสูง (hw/ℓw > 2.5) → ρℓ ใช้แค่ขั้นต่ำ 0.0025 (เหล็กแนวดิ่งมีผลรับแรงเฉือนมากขึ้นในผนังเตี้ย)

## 11.7 รายละเอียดเหล็กเสริม

- ระยะหุ้ม §20.5.1, ระยะฝังยึด §25.4, ระยะต่อทาบ §25.5

### ระยะห่างเหล็ก (11.7.2, 11.7.3)

| | เหล็กแนวดิ่ง (ตามยาว) | เหล็กแนวนอน (ตามขวาง) |
|---|---|---|
| หล่อในที่ | ≤ ค่าน้อยกว่าของ 3h และ 18 in. (≈ 450 mm) | ≤ ค่าน้อยกว่าของ 3h และ 18 in. |
| หล่อในที่ + ต้องใช้เหล็กรับแรงเฉือนในระนาบ | ≤ ℓw/3 เพิ่ม | ≤ ℓw/5 เพิ่ม |
| precast | ≤ ค่าน้อยกว่าของ 5h และ 18 in. (ผนังภายนอก) / 30 in. (ผนังภายใน) | เหมือนกัน |

### อื่น ๆ

- **ผนังหนา > 10 in. (≈ 250 mm)** → เสริมเหล็ก **2 ชั้น** ทั้งสองทิศ ชั้นละด้าน (ยกเว้นผนังห้องใต้ดินชั้นเดียว และกำแพงกันดิน cantilever)
- เหล็กรับแรงดึงจากการดัดต้องกระจายดีและอยู่ใกล้ผิวรับแรงดึงที่สุด
- ถ้าเหล็กแนวดิ่งต้องรับแรงอัด **และ Ast > 0.01Ag** → ต้องมีปลอกยึดรั้งด้านข้าง (เหมือนเสา)
- **รอบช่องเปิด** (ประตู หน้าต่าง ฯลฯ) เพิ่มจากเหล็กขั้นต่ำ:
  - ผนังเหล็ก 2 ชั้น: อย่างน้อย **2 เส้น No.5** ทั้งสองทิศ
  - ผนังเหล็กชั้นเดียว: อย่างน้อย **1 เส้น No.5** ทั้งสองทิศ
  - ต้องฝังยึดให้ได้ fy (รับแรงดึง) ที่มุมช่องเปิด

## 11.8 วิธีทางเลือก: ผนังชะลูดนอกระนาบ (Slender wall)

เหมาะกับผนัง tilt-up ที่ยึดรั้งการหมุนที่หัวผนัง

### เงื่อนไขการใช้ (11.8.1.1)

- (a) หน้าตัดคงที่ตลอดความสูง (ผนังที่มีช่องเปิดใหญ่ไม่เข้าข่าย)
- (b) หน้าตัดเป็น tension-controlled สำหรับโมเมนต์นอกระนาบ
- (c) φMn ≥ Mcr (Mcr ใช้ fr ตาม §19.2.3)
- (d) Pu ที่กลางความสูง ≤ **0.06f′cAg**
- (e) การโก่งนอกระนาบที่น้ำหนักใช้งาน Δs (รวม PΔ) ≤ **ℓc/150**

### แบบจำลอง (11.8.2)

- วิเคราะห์เป็นคานช่วงเดียวรองรับแบบง่าย รับแรงตามแกน + แรงด้านข้างแผ่สม่ำเสมอ โมเมนต์และการโก่งสูงสุดที่กลางความสูง
- แรงกระทำเป็นจุดจากด้านบน: กระจายลงด้วยความลาด **2 ดิ่ง : 1 ราบ** แต่ไม่เกินระยะห่างระหว่างแรงหรือขอบแผ่นผนัง

### โมเมนต์ประลัย (11.8.3)

Mua = โมเมนต์ที่กลางความสูงจากแรงด้านข้างและแรงตามแกนเยื้องศูนย์ (ยังไม่รวม PΔ)

**(a) คำนวณวนซ้ำ**

$$M_u = M_{ua} + P_u\Delta_u, \qquad \Delta_u = \frac{5M_u\ell_c^2}{(0.75)48E_cI_{cr}}$$

$$I_{cr} = \frac{E_s}{E_c}\left(A_s + \frac{P_u}{f_y}\frac{h}{2d}\right)(d-c)^2 + \frac{\ell_w c^3}{3}, \qquad \frac{E_s}{E_c} \ge 6$$

**(b) คำนวณตรง**

$$M_u = \frac{M_{ua}}{1 - \dfrac{5P_u\ell_c^2}{(0.75)48E_cI_{cr}}}$$

### การโก่งที่น้ำหนักใช้งาน (11.8.4)

Ma = Msa + PsΔs (วนซ้ำ) แล้วหา Δs จาก Table 11.8.4.1:

| Ma | Δs |
|---|---|
| ≤ (2/3)Mcr | Δs = (Ma/Mcr)·Δcr |
| > (2/3)Mcr | Δs = (2/3)Δcr + [(Ma − (2/3)Mcr)/(Mn − (2/3)Mcr)]·(Δn − (2/3)Δcr) |

โดย Δcr = 5Mcr·ℓc² / (48EcIg) และ Δn = 5Mn·ℓc² / (48EcIcr)

- การโก่งเพิ่มขึ้นเร็วมากเมื่อ Ma เกิน (2/3)Mcr
- ชุดผสมน้ำหนักใช้งานที่ commentary แนะนำ (จาก ASCE 7 Appendix C): **D + 0.5L + Wa** หรือ **D + 0.5L + 0.7E**
