# ACI 318-19 Chapter 12 — Diaphragms (ไดอะแฟรม)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 175–189 (ฉบับ inch-pound, f′c และ fy หน่วย psi) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

## 12.1 ขอบเขต

ไดอะแฟรม = แผ่นพื้นแนวราบ (หรือเกือบราบ) ที่ถ่ายแรงด้านข้างไปยังชิ้นส่วนแนวดิ่งของระบบต้านแรงด้านข้าง ยึดโครงสร้างให้เป็นระบบ 3 มิติ และค้ำยันชิ้นส่วนต่าง ๆ — ทำงานเหมือน **คานลึกวางนอน** ที่พาดระหว่างผนัง/โครงข้อแข็ง

บทนี้ใช้กับไดอะแฟรม (ไม่อัดแรงและอัดแรง) 4 แบบ:

| แบบ | ลักษณะ |
|---|---|
| (a) | พื้นหล่อในที่ |
| (b) | topping หล่อในที่บนชิ้นส่วน precast |
| (c) | ชิ้นส่วน precast ที่มีแถบขอบ (end strip) เป็น topping หล่อในที่หรือคานขอบ |
| (d) | ชิ้นส่วน precast ต่อกันโดยไม่มี topping |

- ไม่ครอบคลุมไดอะแฟรมแบบอื่น เช่น โครงถักแนวราบ (horizontal truss)
- **SDC D, E, F** → ต้องผ่าน §18.12 เพิ่ม

**ศัพท์ที่ควรรู้:** chord (เหล็กขอบรับโมเมนต์), collector (ถ่ายแรงจากไดอะแฟรมเข้าชิ้นส่วนแนวดิ่ง), distributor (collector ที่ถ่ายแรงในทิศกลับกัน คือจากชิ้นส่วนแนวดิ่งเข้าไดอะแฟรม)

## 12.2 ทั่วไป

### แรงที่ต้องพิจารณา (12.2.1)

| | แรง | ตัวอย่าง |
|---|---|---|
| (a) | แรงในระนาบจากแรงด้านข้าง | ลม, แรงเฉื่อยแผ่นดินไหว, แรงดันดินที่ผนังห้องใต้ดิน |
| (b) | แรงถ่ายโอน (transfer forces) | ระบบต้านแรงเปลี่ยนตำแหน่งระหว่างชั้น เช่น จากอาคารสูงลง podium ที่ระดับดิน |
| (c) | แรงที่จุดต่อกับชิ้นส่วนแนวดิ่ง/ชิ้นส่วนไม่ใช่โครงสร้าง | ลมบนผนังภายนอก, แรงเฉื่อยของ cladding |
| (d) | แรงจากการค้ำยันชิ้นส่วนแนวดิ่งหรือเอียง | เสาเอียงสร้างแรงผลักแนวราบเข้าพื้น |
| (e) | แรงนอกระนาบ | น้ำหนักแนวดิ่ง, แรงยกจากลม, ความเร่งแนวดิ่งจากแผ่นดินไหว |

- ต้องคิดผลของช่องเปิดและช่องว่างในพื้น
- วัสดุ: คอนกรีต Ch.19, เหล็ก Ch.20

## 12.3 ความหนาขั้นต่ำ

- หนาพอสำหรับเสถียรภาพ กำลัง และ stiffness ภายใต้น้ำหนักประลัย
- ไม่น้อยกว่าความหนาที่ Code กำหนดให้พื้น/หลังคาในบทอื่น
- topping แบบ composite: คิดความหนารวม / topping แบบ non-composite: ต้องใช้ความหนา topping อย่างเดียว

## 12.4 กำลังที่ต้องการ

- ไดอะแฟรม, collector และจุดต่อ ใช้ชุดผสมน้ำหนักตาม Ch.5
- ไดอะแฟรมที่เป็นพื้น/หลังคา ต้องรวมแรงนอกระนาบ **ที่เกิดพร้อมกัน** — เช่น คานพื้นที่ทำหน้าที่ collector ด้วย ต้องออกแบบรับทั้งแรงตามแกน (collector) และโมเมนต์ (รับน้ำหนักแนวดิ่ง)

### 12.4.2 แบบจำลองและการวิเคราะห์

- ถ้า building code (เช่น ASCE 7) มีข้อกำหนดการจำลองไดอะแฟรม ให้ใช้ตามนั้นก่อน
- มิฉะนั้น ใช้ Ch.6 และสมมติฐาน stiffness ที่สมเหตุสมผลและสอดคล้องกันได้
- ต้องสอดคล้องกับสมดุลและเงื่อนไขขอบ

**วิธีคำนวณแรงในไดอะแฟรม (12.4.2.4)**

| วิธี | ใช้เมื่อ |
|---|---|
| (a) Rigid diaphragm | ไดอะแฟรมแข็งมากเทียบกับชิ้นส่วนแนวดิ่ง เช่น พื้นหล่อในที่สัดส่วนต่ำบนโครงข้อแข็ง |
| (b) Flexible diaphragm | ไดอะแฟรมอ่อนเทียบกับชิ้นส่วนแนวดิ่ง เช่น precast ต่อด้วยรอยต่อบนผนังรับแรงเฉือน — จำลองเป็นคานบนจุดรองรับแข็ง |
| (c) Bounding analysis | ทำ 2 กรณี (stiffness บน/ล่าง) แล้วใช้ค่าห่อหุ้ม |
| (d) Finite element | ไดอะแฟรมรูปร่างไม่สม่ำเสมอหรือมีแรงถ่ายโอนมาก — ต้องลด stiffness ตามการแตกร้าว และจำลองรอยต่อ precast ถ้ามี |
| (e) Strut-and-tie | ตาม §23.2 — ต้องคิดการกลับทิศของแรง |

- ไดอะแฟรม rigid/semi-rigid: จำลองเป็นคานแข็งวางบนสปริง (stiffness ของชิ้นส่วนแนวดิ่ง) และต้องคิดการบิดของอาคารจากความเยื้องศูนย์
- ไดอะแฟรมช่วงยาว สัดส่วนสูง มีช่องเปิดใหญ่ หรือไม่สม่ำเสมอ → ต้องคิดการเสียรูปในระนาบ

## 12.5 กำลังออกแบบ

- φSn ≥ U ทุกชุดผสม และคิดปฏิสัมพันธ์ของแรง เช่น collector ในคานรับแรงตามแกน + โมเมนต์, จุดต่อรับแรงดึง + เฉือน
- φ ตาม §21.2 — collector/strut รับแรงอัดใช้ §10.5.2 กับ φ compression-controlled; รับแรงดึง Asfy กับ φ = 0.90

### 12.5.1.3 แนวทางการออกแบบ

| แบบจำลอง | กำลังออกแบบตาม |
|---|---|
| (a) คานลึกเต็มความลึกไดอะแฟรม โมเมนต์รับโดยเหล็กขอบ (chord) | §12.5.2–12.5.4 (สมมติ shear flow สม่ำเสมอ) |
| (b) Strut-and-tie | §23.3 |
| (c) Finite element | Ch.22 — ต้องคิด shear ไม่สม่ำเสมอ และมี collector ถ่ายแรงเข้าชิ้นส่วนแนวดิ่ง |
| (d) วิธีอื่น | ต้องสมดุลและให้กำลัง ≥ ที่ต้องการ ทุกชิ้นส่วนบน load path |

- ใช้แรงอัดจากการอัดแรงช่วยรับแรงในไดอะแฟรมได้ (12.5.1.4) — กรณีลม/แผ่นดินไหว น้ำหนักแนวดิ่งน้อยลง ส่วนที่เหลือของ prestress ใช้รับโมเมนต์ในระนาบได้
- ใช้ลวด/เหล็กอัดแรงแบบไม่ดึง (nonprestressed, bonded) รับแรง collector/เฉือน/ดึง: หน่วยแรงที่ใช้ **≤ ค่าน้อยกว่าของ fy และ 60,000 psi** (เพื่อคุมรอยร้าว)

### 12.5.2 โมเมนต์และแรงตามแกน

- ออกแบบตาม §22.3 และ §22.4 ได้ (มักใช้คู่แรงดึง-อัดประมาณ, φ = 0.90)
- แรงดึงจากโมเมนต์รับได้โดย: (a) เหล็กข้ออ้อย §20.2.1, (b) ลวด/เหล็กอัดแรง §20.3.1 (ดึงหรือไม่ดึง), (c) อุปกรณ์กลข้ามรอยต่อ precast, (d) แรงอัดจาก prestress — ใช้ร่วมกันได้
- **เหล็ก (ไม่อัดแรง) และอุปกรณ์กลที่รับแรงดึงจากโมเมนต์ ต้องอยู่ภายใน h/4 จากขอบรับแรงดึง** (h = ความลึกไดอะแฟรมในระนาบ) — ถ้าความลึกเปลี่ยน ฝังยึดเข้าส่วนข้างเคียงได้แม้อยู่นอก h/4 ของส่วนนั้น
- prestressed reinforcement ไม่จำกัดตำแหน่ง
- อุปกรณ์กลข้ามรอยต่อ precast ต้องรับแรงดึงได้ภายใต้การเปิดของรอยต่อที่คาดไว้ (ประมาณ ≤ 0.1 in. ในช่วงเชิงเส้น แผ่นดินไหวอาจมากกว่า)

### 12.5.3 แรงเฉือน

- **φ = 0.75** (เว้นแต่ §21.2.4 ให้ใช้ค่าน้อยกว่า เช่น ระบบพิเศษใน SDC D–F)

**ไดอะแฟรมหล่อในที่ทั้งหมด**

$$V_n = A_{cv}\left(2\lambda\sqrt{f'_c} + \rho_t f_y\right) \quad (12.5.3.3)$$

$$V_u \le \phi\, 8A_{cv}\sqrt{f'_c} \quad (12.5.3.4)$$

- Acv = พื้นที่หน้าตัดรวม (ความหนา × ความลึกไดอะแฟรม) หักช่องว่าง
- ρt = เหล็กกระจายที่ **ขนาน** กับแรงเฉือนในระนาบ
- √f′c ≤ 100 psi

**Topping หล่อในที่บน precast (12.5.3.5)**
- (a) ใช้สมการเดียวกัน: Acv คิดจากความหนา topping (non-composite) หรือความหนารวม (composite); ถ้า composite ใช้ f′c ค่าน้อยกว่าของ precast และ topping
- (b) Vn ≤ กำลัง shear-friction (§22.9) ของ topping เหนือรอยต่อ precast รวมเหล็กที่ข้ามรอยต่อ (topping มักแตกร้าวตามแนวรอยต่อ)

**precast ไม่มี topping / มีแค่แถบขอบ (12.5.3.6)** — ออกแบบด้วย:
- (a) รอยต่อ grout: กำลังระบุ ≤ **80 psi** และเสริมเหล็ก shear-friction ตาม §22.9 **เพิ่มจาก** เหล็กรับแรงดึงจากโมเมนต์/แรงตามแกน
- (b) อุปกรณ์กลข้ามรอยต่อ ออกแบบรับแรงเฉือนภายใต้การเปิดของรอยต่อ
- ⚠️ Code ไม่มีข้อกำหนดสำหรับไดอะแฟรมไม่มี topping ใน SDC D, E, F

**การถ่ายแรงเฉือนเข้า collector หรือชิ้นส่วนแนวดิ่ง (12.5.3.7)**
- ผ่านคอนกรีต → ตรวจ shear-friction §22.9 (มักใช้เหล็กเสียบ dowel ข้าม cold joint เข้าผนัง)
- ผ่านอุปกรณ์กลหรือ dowel → คิดผลของแรงยกและการหมุนของชิ้นส่วนแนวดิ่ง

### 12.5.4 Collector

- ยื่นจากชิ้นส่วนแนวดิ่งข้ามไดอะแฟรมเต็มหรือบางส่วนของความลึก ตามที่ต้องใช้ถ่ายแรงเฉือน — หยุดได้ในช่วงที่ไม่ต้องถ่ายแรง
- collector ยื่นเข้าไปในพื้นทางขวางได้ เพื่อลดหน่วยแรงและความแออัดของเหล็ก (แนะนำความกว้างแต่ละข้าง ≤ ประมาณ ½ ของความยาวสัมผัสกับชิ้นส่วนแนวดิ่ง)
- ออกแบบเป็นชิ้นส่วนรับแรงดึง/อัดตาม §22.4 (ไม่บังคับรายละเอียดแบบเสา ยกเว้นตาม §18.12.7.6 — แต่ควรเสริมปลอกถ้าแรงอัดสูงหรือใช้เป็น strut ใกล้ขอบ/ช่องเปิด)
- **เหล็ก collector ต้องยื่นตามชิ้นส่วนแนวดิ่ง ≥ ค่ามากกว่าของ:**
  - (a) ความยาวฝังยึดรับแรงดึง
  - (b) ความยาวที่ต้องใช้ถ่ายแรงเข้าชิ้นส่วนแนวดิ่ง (ผ่าน shear-friction §22.9, อุปกรณ์กล หรือกลไกอื่น)

## 12.6 ขีดจำกัดเหล็กเสริม

- เหล็กกันร้าว (shrinkage & temperature) ตาม §24.4
- ไดอะแฟรมที่เป็นพื้น/หลังคา (ไม่ใช่ slab-on-ground) ต้องผ่านเหล็กขั้นต่ำของพื้นทางเดียว §7.6 หรือพื้นสองทาง §8.6
- **เหล็กรับแรงในระนาบไดอะแฟรม ต้องเพิ่มจากเหล็กที่รับแรงอื่น** — ยกเว้นเหล็กกันร้าว ใช้รับแรงไดอะแฟรมร่วมได้

## 12.7 รายละเอียดเหล็กเสริม

| หัวข้อ | ข้อกำหนด |
|---|---|
| ระยะหุ้ม | §20.5.1 (SDC D–F ดู §18.12.7.7) |
| ระยะฝังยึด | §25.4 เว้นแต่ Ch.18 ต้องการยาวกว่า |
| ต่อทาบ / เหล็กมัดรวม | §25.5 / §25.6 |
| ระยะห่างขั้นต่ำ | §25.2 (SDC D–F ระยะเหล็กโอบรัดใน collector ดู §18.12.7.6) |
| **ระยะห่างสูงสุด** | ค่าน้อยกว่าของ **5 × ความหนาไดอะแฟรม** และ **18 in.** |
| รายละเอียดพื้น | ผ่าน §7.7 (ทางเดียว) หรือ §8.7 (สองทาง) — ยกเว้น slab-on-ground |

- แรงดึง/อัดในเหล็กที่ทุกหน้าตัด ต้องฝังยึดได้ **ทั้งสองข้าง** ของหน้าตัดนั้น (หน้าตัดวิกฤต: จุดหน่วยแรงสูงสุด, จุดตัดเหล็กข้างเคียง, จุดไม่ต่อเนื่อง)
- เหล็กรับแรงดึงต้องยื่นเลยจุดที่ไม่ต้องใช้แล้ว **≥ ℓd** — ยกเว้นที่ขอบไดอะแฟรมและรอยต่อขยายตัว (ง่ายกว่าคานที่ต้องยื่น d หรือ 12db)
