# ACI 318-19 Chapter 17 — Anchoring to Concrete (การยึดฝังพุกในคอนกรีต)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 233–283 (ฉบับ inch-pound, f′c หน่วย psi, ความยาว in., แรง lb) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm / MPa" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ — สัมประสิทธิ์ในสมการ (24, 17, 16, 7, 9, 8, 160) ใช้กับหน่วย inch-pound เท่านั้น

## 17.1 ขอบเขต

ใช้ออกแบบพุกที่ถ่ายแรงดึง แรงเฉือน หรือทั้งสองอย่าง ระหว่าง (a) ชิ้นส่วนโครงสร้างที่ต่อกัน หรือ (b) อุปกรณ์ที่เกี่ยวกับความปลอดภัยกับชิ้นส่วนโครงสร้าง — ระดับความปลอดภัยมุ่งสำหรับสภาวะใช้งาน ไม่ใช่การยกหรือก่อสร้างระยะสั้น

**ชนิดพุกที่ครอบคลุม (17.1.2)**

| | ชนิด | เงื่อนไข |
|---|---|---|
| (a) | Headed stud, headed bolt (หล่อในที่) | รูปทรงให้กำลัง pullout ในคอนกรีตไม่แตกร้าว ≥ 1.4Np |
| (b) | Hooked bolt (J/L) | กำลัง pullout ไม่นับแรงเสียดทาน ≥ 1.4Np |
| (c) | พุกขยายตัว (expansion: torque-controlled / displacement-controlled) | ผ่าน ACI 355.2 |
| (d) | Undercut | ผ่าน ACI 355.2 |
| (e) | พุกเคมี (adhesive) | ผ่าน ACI 355.4 |
| (f) | พุกเกลียว (screw) — ใหม่ใน 318-19 | ผ่าน ACI 355.2 |
| (g) | Attachment ที่มี shear lug — ใหม่ใน 318-19 | ตาม §17.11 |

- ⛔ **ห้ามถอดแล้วติดตั้งพุกกลแบบ post-installed ซ้ำ**
- **ไม่ครอบคลุม:** น้ำหนักกระทำซ้ำรอบสูง (fatigue) หรือแรงกระแทก; specialty insert, through-bolt, พุกหลายตัวที่ต่อกับแผ่นเหล็กแผ่นเดียวที่ปลายฝัง, พุก grout, พุกยิง (powder/pneumatic)
- ใช้เหล็กเสริมเป็นพุก: ต้องตรวจ concrete breakout หรือใส่ anchor reinforcement ตาม §17.5.2.1

## 17.2 ทั่วไป

- ออกแบบด้วยแรงจากการวิเคราะห์แบบยืดหยุ่น — ถ้ากำลังถูกควบคุมด้วยเหล็กเหนียว ใช้การวิเคราะห์พลาสติกได้ (ต้องคิดความเข้ากันได้ของการเสียรูป)
- ต้องคิด **ผลของกลุ่มพุก** ถ้าพุก ≥ 2 ตัวรับแรงจากชิ้นส่วนเดียวกัน และห่างน้อยกว่าระยะที่ breakout ไม่ลดลง
- **พุกเคมี:** ติดตั้งในคอนกรีตอายุ **≥ 21 วัน**; ติดตั้งแนวนอนหรือเอียงขึ้นต้องผ่านการทดสอบความไวต่อทิศการติดตั้งตาม ACI 355.4
- ติดตั้งและตรวจตาม §26.7 และ §26.13

**Table 17.2.4.1 — ตัวปรับคอนกรีตมวลเบา λa**

| กรณี | λa |
|---|---|
| การวิบัติของคอนกรีต — พุกหล่อในที่และ undercut | 1.0λ |
| การวิบัติของคอนกรีต — พุก expansion, screw, adhesive | 0.8λ |
| การวิบัติของแรงยึดเกาะ (bond) ของพุกเคมี | 0.6λ |

(λ ตาม §19.2.4; ใช้ค่าอื่นได้ถ้าทดสอบตาม ACI 355.2/355.4)

## 17.5 กำลังออกแบบ

### 17.5.1 ทั่วไป

φSn ≥ U ทุกชุดผสม และคิดปฏิสัมพันธ์แรงดึง-เฉือนตาม §17.8

กำลังระบุต้องอิงแบบจำลองที่สอดคล้องกับผลทดสอบ ที่ **5 percent fractile** และคิดผลของขนาด จำนวนพุก ระยะห่าง ระยะขอบ ความลึกชิ้นส่วน ความเยื้องศูนย์ และการแตกร้าว — รูปแบบการวิบัติที่ต้องตรวจ:

| แรง | รูปแบบการวิบัติ | ข้อ |
|---|---|---|
| ดึง | (a) เหล็กพุกขาด | 17.6.1 |
| | (b) คอนกรีตแตกเป็นกรวย (concrete breakout) | 17.6.2 |
| | (c) พุกถูกดึงหลุด (pullout) — หล่อในที่, expansion, screw, undercut | 17.6.3 |
| | (d) คอนกรีตด้านข้างระเบิด (side-face blowout) — headed anchor | 17.6.4 |
| | (e) แรงยึดเกาะวิบัติ (bond) — พุกเคมี | 17.6.5 |
| เฉือน | (f) เหล็กพุกขาด | 17.7.1 |
| | (g) คอนกรีตขอบแตก (concrete breakout) | 17.7.2 |
| | (h) คอนกรีตงัดแตก (pryout) | 17.7.3 |

- วิธีใน §17.6–17.7 พัฒนาจาก **Concrete Capacity Design (CCD) Method** สมมติกรวยวิบัติทำมุม ~35° ใช้ได้กับรูปแบบไม่สม่ำเสมอ
- ใช้ผลทดสอบ (5 percent fractile) แทนได้

**Anchor reinforcement (17.5.2.1)** — ใช้กำลังของ anchor reinforcement แทน concrete breakout ได้ ถ้า:
- (a) **แรงดึง:** เหล็กพัฒนาได้ตาม Ch.25 ทั้งสองฝั่งของผิว breakout (แนะนำปลอก/hairpin ห่างจากศูนย์กลางพุก < 0.5hef, ไม่ใหญ่กว่า No.5)
- (b) **แรงเฉือน:** เหล็กพัฒนาได้ทั้งสองฝั่ง **หรือ** โอบและสัมผัสพุกและพัฒนาเลยผิว breakout (ไม่แนะนำใหญ่กว่า No.6; เหล็กขอบที่ห่างจากพุก < ค่าน้อยกว่าของ 0.5ca1 และ 0.3ca2 นับได้)
- φ ของ anchor reinforcement = **0.75**

**พุกเคมีรับแรงดึงค้าง (17.5.2.2)**

$$0.55\phi N_{ba} \ge N_{ua,s}$$

Nua,s = แรงดึงค้างประลัย — กลุ่มพุก: ตรวจพุกตัวที่รับแรงค้างมากสุด (พุกเคมีติดเพดานรับแรงดึงค้างเคยวิบัติ — ต้องใช้ผู้ติดตั้งที่ผ่านการรับรองและตรวจพิเศษ)

## 17.6 กำลังรับแรงดึง

### 17.6.1 เหล็กพุก Nsa

$$N_{sa} = A_{se,N}\,f_{uta}$$

futa ≤ ค่าน้อยกว่าของ **1.9fya** และ **125,000 psi (≈ 860 MPa)** — สำหรับเกลียว ASME B1.1: Ase,N = (π/4)(da − 0.9743/nt)², nt = จำนวนเกลียวต่อนิ้ว

### 17.6.2 Concrete breakout Ncb / Ncbg

$$N_{cb} = \frac{A_{Nc}}{A_{Nco}}\psi_{ed,N}\psi_{c,N}\psi_{cp,N}N_b \qquad N_{cbg} = \frac{A_{Nc}}{A_{Nco}}\psi_{ec,N}\psi_{ed,N}\psi_{c,N}\psi_{cp,N}N_b$$

**พื้นที่ฉาย**
- ANco = **9hef²** (พุกเดี่ยว ระยะขอบ ≥ 1.5hef — กรวยกว้าง 1.5hef รอบพุก)
- ANc = พื้นที่ฉายจริง (สี่เหลี่ยมยื่น 1.5hef จากพุก/แถวพุก ตัดด้วยขอบ) ≤ nANco — ตัวอย่าง: พุก 1 ตัวใกล้ขอบ 1 ด้าน ANc = (ca1 + 1.5hef)(2 × 1.5hef)
- ถ้าเพิ่มแผ่น/แหวนที่หัวพุก ฉายจากเส้นรอบแผ่นได้ (ไม่เกินความหนาแผ่นจากขอบหัวพุก)
- **ชิ้นส่วนแคบ (17.6.2.1.2):** พุกห่างขอบ < 1.5hef ตั้งแต่ **3 ด้านขึ้นไป** → hef ที่ใช้คำนวณ = ค่ามากกว่าของ **ca,max/1.5** และ **s/3** (s = ระยะห่างมากสุดในกลุ่ม)

**กำลังพื้นฐาน Nb (คอนกรีตแตกร้าว)**

$$N_b = k_c\lambda_a\sqrt{f'_c}\,h_{ef}^{1.5}$$

- kc = **24** (หล่อในที่), **17** (post-installed — เพิ่มได้ตามผลทดสอบแต่ ≤ 24)
- headed stud/bolt หล่อในที่ **11 in. ≤ hef ≤ 25 in.**: Nb = 16λa√f′c·hef^(5/3)

**ตัวปรับ**

| ตัวปรับ | ค่า |
|---|---|
| ψec,N (ความเยื้องศูนย์) | 1 / (1 + e′N/1.5hef) ≤ 1.0 — นับเฉพาะพุกที่รับแรงดึง; เยื้องสองแกน คูณกัน |
| ψed,N (ระยะขอบ) | ca,min ≥ 1.5hef → 1.0; ca,min < 1.5hef → 0.7 + 0.3ca,min/(1.5hef) |
| ψc,N (การแตกร้าว) | คอนกรีต **ไม่แตกร้าว** ที่น้ำหนักใช้งาน: 1.25 (หล่อในที่), 1.4 (post-installed ที่ kc = 17) หรือตามรายงานผลทดสอบ; คอนกรีต **แตกร้าว**: 1.0 (ต้องคุมรอยร้าวตาม §24.3.2) |
| ψcp,N (การแตกแยก — post-installed ในคอนกรีตไม่แตกร้าว ไม่มี supplementary reinforcement) | ca,min ≥ cac → 1.0; ca,min < cac → ca,min/cac ≥ 1.5hef/cac; กรณีอื่นรวมพุกหล่อในที่ = 1.0 |

post-installed ต้องผ่านการรับรองสำหรับคอนกรีตแตกร้าวตาม ACI 355.2/355.4 ถ้าใช้ในบริเวณแตกร้าว

### 17.6.3 Pullout Npn (พุกเดี่ยว)

$$N_{pn} = \psi_{c,P}N_p$$

| ชนิด | Np |
|---|---|
| Post-installed expansion, screw, undercut | จากผลทดสอบ ACI 355.2 (5 percent fractile) — **ห้ามคำนวณ** |
| Headed stud / headed bolt หล่อในที่ | **8Abrg·f′c** (Abrg = พื้นที่แบกทานสุทธิของหัว) |
| J-bolt / L-bolt | **0.9f′c·eh·da** โดย 3da ≤ eh ≤ 4.5da (eh = ระยะจากผิวในของก้านถึงปลายขอ) |

ψc,P = 1.4 (ไม่แตกร้าว), 1.0 (แตกร้าว)

### 17.6.4 Side-face blowout Nsb (headed anchor ฝังลึกใกล้ขอบ, hef > 2.5ca1)

$$N_{sb} = 160\,c_{a1}\sqrt{A_{brg}}\,\lambda_a\sqrt{f'_c}$$

- ca2 < 3ca1 → คูณ (1 + ca2/ca1)/4 โดย 1.0 ≤ ca2/ca1 ≤ 3.0
- กลุ่มพุก (s < 6ca1): Nsbg = (1 + s/6ca1)·Nsb (s = ระยะระหว่างพุกริมนอกตามขอบ)

### 17.6.5 Bond strength ของพุกเคมี Na / Nag

$$N_a = \frac{A_{Na}}{A_{Nao}}\psi_{ed,Na}\psi_{cp,Na}N_{ba} \qquad N_{ag} = \frac{A_{Na}}{A_{Nao}}\psi_{ec,Na}\psi_{ed,Na}\psi_{cp,Na}N_{ba}$$

- ANao = (2cNa)², **cNa = 10da√(τuncr/1100)** (ระยะวิกฤต — ไม่ขึ้นกับ hef และสถานะแตกร้าว)
- ANa = พื้นที่ฉาย (ยื่น cNa จากพุก/แถวพุก) ≤ nANao

**กำลังพื้นฐาน (คอนกรีตแตกร้าว)**

$$N_{ba} = \lambda_a\tau_{cr}\pi d_a h_{ef}$$

- τcr = แรงยึดเกาะลักษณะเฉพาะ (5 percent fractile ตาม ACI 355.4); คอนกรีตไม่แตกร้าวใช้ τuncr แทนได้

| ภายนอก (outdoor) | แห้ง – อิ่มตัว | 175°F (≈ 79°C) | 200 (≈ 1.4 MPa) | 650 (≈ 4.5 MPa) |
| ภายใน (indoor) | แห้ง | 110°F (≈ 43°C) | 300 (≈ 2.1 MPa) | 1000 (≈ 6.9 MPa) |

- ใช้ได้เมื่อ: ผ่าน ACI 355.4, เจาะด้วยสว่านกระแทกหรือ rock drill, f′c ขณะติดตั้ง ≥ 2500 psi, อายุ ≥ 21 วัน, อุณหภูมิคอนกรีตขณะติดตั้ง ≥ 50°F
- **รับแรงดึงค้าง:** คูณ τ ด้วย **0.4**; **แผ่นดินไหว (SDC C–F):** คูณ τcr ด้วย **0.8** และ τuncr ด้วย **0.4**

**ตัวปรับ**
- ψec,Na = 1 / (1 + e′N/cNa) ≤ 1.0
- ψed,Na: ca,min ≥ cNa → 1.0; ca,min < cNa → 0.7 + 0.3ca,min/cNa
- ψcp,Na (ไม่แตกร้าว ไม่มี supplementary reinforcement): ca,min ≥ cac → 1.0; ca,min < cac → ca,min/cac ≥ cNa/cac; กรณีอื่น 1.0

## 17.7 กำลังรับแรงเฉือน

### 17.7.1 เหล็กพุก Vsa

| ชนิด | Vsa |
|---|---|
| (a) Headed stud หล่อในที่ | Ase,V·futa |
| (b) Headed bolt, hooked bolt หล่อในที่ และ post-installed ที่ปลอกไม่ผ่านระนาบเฉือน | **0.6**Ase,V·futa |
| (c) Post-installed ที่ปลอก (sleeve) ผ่านระนาบเฉือน | จากผลทดสอบ ACI 355.2 (หรือใช้ (b)) |

- futa ≤ 1.9fya และ 125,000 psi
- ถ้าใช้แผ่น grout รองใต้ (built-up grout pad) → คูณ **0.80**

### 17.7.2 Concrete breakout Vcb / Vcbg

$$V_{cb} = \frac{A_{Vc}}{A_{Vco}}\psi_{ed,V}\psi_{c,V}\psi_{h,V}V_b \qquad V_{cbg} = \frac{A_{Vc}}{A_{Vco}}\psi_{ec,V}\psi_{ed,V}\psi_{c,V}\psi_{h,V}V_b$$

- (c) **แรงเฉือนขนานขอบ:** ใช้ 2 เท่าของค่าที่คิดแรงตั้งฉากขอบ โดย ψed,V = 1.0
- (d) **พุกที่มุม:** คำนวณแต่ละขอบ ใช้ค่าน้อยกว่า

**พื้นที่ฉาย**
- AVco = **4.5ca1²** (ครึ่งพีระมิด กว้าง 3ca1 ลึก 1.5ca1)
- AVc = พื้นที่ฉายจริงบนผิวข้าง ≤ nAVco — ตัวอย่าง: ha < 1.5ca1 → AVc = 2(1.5ca1)ha; ca2 < 1.5ca1 → AVc = 1.5ca1(1.5ca1 + ca2)
- **ชิ้นส่วนแคบและบาง (17.7.2.1.2):** ถ้า ca2 ทั้งสองด้านและ ha < 1.5ca1 → ca1 ที่ใช้ ≤ ค่ามากที่สุดของ ca2,max/1.5, ha/1.5, s/3
- พุกเชื่อมกับแผ่นยึดและห่างขอบไม่เท่ากัน: ประเมินจากแถวพุกที่ไกลขอบที่สุดได้ (ถือว่าแถวนั้นรับแรงเฉือนทั้งหมด)

**กำลังพื้นฐาน Vb (คอนกรีตแตกร้าว)** = ค่าน้อยกว่าของ:

$$V_b = 7\left(\frac{\ell_e}{d_a}\right)^{0.2}\sqrt{d_a}\,\lambda_a\sqrt{f'_c}\,(c_{a1})^{1.5} \quad \text{และ} \quad V_b = 9\lambda_a\sqrt{f'_c}\,(c_{a1})^{1.5}$$

- ℓe = ความยาวรับแรงของพุก: = hef (stiffness คงที่ตลอดความยาวฝัง), = 2da (torque-controlled expansion ที่มี sleeve แยก), **ℓe ≤ 8da** ทุกกรณี

**พุกหล่อในที่ที่เชื่อมต่อเนื่องกับแผ่นเหล็ก (17.7.2.2.2)** — Vb = ค่าน้อยกว่าของ 9λa√f′c·ca1^1.5 และ 8(ℓe/da)^0.2·√da·λa√f′c·ca1^1.5 ถ้า:
- (a) แผ่นหนา ≥ ค่ามากกว่าของ 0.5da และ ⅜ in.
- (b) ระยะห่างพุก ≥ 2.5 in.
- (c) มีเหล็กที่มุมถ้า ca2 ≤ 1.5hef
- (d) กลุ่มพุก: คิดจากแถวที่ไกลขอบที่สุด

**ตัวปรับ**

| ตัวปรับ | ค่า |
|---|---|
| ψec,V | 1 / (1 + e′V/1.5ca1) ≤ 1.0 — นับเฉพาะพุกที่รับแรงเฉือนทิศเดียวกัน |
| ψed,V (ใช้ ca2 ที่น้อยกว่า) | ca2 ≥ 1.5ca1 → 1.0; ca2 < 1.5ca1 → 0.7 + 0.3ca2/(1.5ca1) |
| ψc,V | ไม่แตกร้าว: 1.4; แตกร้าว: ตาม Table ด้านล่าง |
| ψh,V (ha < 1.5ca1) | √(1.5ca1/ha) ≥ 1.0 |

**Table 17.7.2.5.1 — ψc,V ในคอนกรีตแตกร้าว**

| สภาพ | ψc,V |
|---|---|
| ไม่มี supplementary reinforcement หรือเหล็กขอบเล็กกว่า No.4 | 1.0 |
| มีเหล็ก ≥ No.4 ระหว่างพุกกับขอบ | 1.2 |

### 17.7.3 Pryout Vcp / Vcpg

$$V_{cp} = k_{cp}N_{cp} \qquad V_{cpg} = k_{cp}N_{cpg}$$

- kcp = **1.0** ถ้า hef < 2.5 in., **2.0** ถ้า hef ≥ 2.5 in.
- Ncp (Ncpg) = Ncb (Ncbg) สำหรับพุกหล่อในที่ expansion screw undercut; พุกเคมีใช้ค่าน้อยกว่าของ Na (Nag) และ Ncb (Ncbg)

## 17.8 ปฏิสัมพันธ์แรงดึง-แรงเฉือน

- ละเลยปฏิสัมพันธ์ได้ถ้า **Nua/(φNn) ≤ 0.2** หรือ **Vua/(φVn) ≤ 0.2**
- ถ้าทั้งสองค่า > 0.2:

$$\frac{N_{ua}}{\phi N_n} + \frac{V_{ua}}{\phi V_n} \le 1.2$$

(φNn, φVn = กำลังที่ควบคุม — เป็นการประมาณเชิงเส้นสามช่วงของ (N/Nn)^(5/3) + (V/Vn)^(5/3) = 1)

## 17.10 ข้อกำหนดแผ่นดินไหว (SDC C, D, E, F)

- ⛔ ไม่ใช้กับพุกใน **plastic hinge zone** (ประมาณ 2 เท่าความลึกชิ้นส่วนจากผิวเสา/คาน) — ถ้าจำเป็นต้องถ่ายแรงผ่าน anchor reinforcement เข้าเนื้อชิ้นส่วน
- Post-installed ต้องผ่าน **Simulated Seismic Tests** ของ ACI 355.2/355.4 (Np, Vsa, τ ใช้ค่าจากการทดสอบนี้)
- anchor reinforcement ต้องเป็นเหล็กข้ออ้อยตาม §20.2.2

### 17.10.5 แรงดึง

- แรงดึงจากแผ่นดินไหว (ระดับกำลัง) **≤ 20%** ของแรงดึงประลัยรวมในชุดผสมเดียวกัน → ออกแบบตาม §17.6 และ Table 17.5.2 ปกติ
- **> 20%** → พุกและ attachment ต้องผ่านทางเลือกใดทางเลือกหนึ่ง:

| ทางเลือก | สาระสำคัญ |
|---|---|
| (a) พุกเหนียว | กำลังที่คอนกรีตควบคุม > กำลังเหล็กพุก (เหล็กคิด **1.2 × กำลังระบุ**); ถ่ายแรงผ่านเหล็กเหนียวที่มี **stretch length ≥ 8da**; กันโก่งเดาะถ้าแรงสลับ; ส่วนเกลียวไม่ตลอดต้องมี **futa/fya ≥ 1.3** (หรือขยายเกลียว upset) |
| (b) Attachment คราก | ออกแบบพุกรับแรงดึงสูงสุดที่ attachment ถ่ายมาได้เมื่อครากอย่างเหนียว (คิดกำลังเกินและ strain hardening — เหล็กโครงสร้างใช้ ~1.5 × fy ระบุ) |
| (c) Attachment ไม่คราก | ออกแบบรับแรงดึงสูงสุดที่ attachment ถ่ายมาได้ |
| (d) Overstrength | ออกแบบรับชุดผสมที่มี E โดย **Eh คูณ Ω₀** |

**กำลังออกแบบรับแรงดึง (17.10.5.4)** — คิดคอนกรีตแตกร้าว (เว้นแต่พิสูจน์ว่าไม่แตก):
- φNsa (ไม่ลด)
- **0.75**φNcb / 0.75φNcbg (ไม่ต้องคิดถ้ามี anchor reinforcement ตาม §17.5.2.1(a))
- **0.75**φNpn, **0.75**φNsb / Nsbg, **0.75**φNa / Nag

### 17.10.6 แรงเฉือน

- แรงเฉือนจากแผ่นดินไหว ≤ 20% → ออกแบบตาม §17.7 ปกติ
- > 20% → ทางเลือก (a) attachment คราก, (b) attachment ไม่คราก, (c) Eh × Ω₀ — **ไม่มีทางเลือก "พุกเหนียว"** สำหรับแรงเฉือน
- มี anchor reinforcement ตาม §17.5.2.1(b) → ไม่ต้องลดกำลังเพิ่ม
- ปฏิสัมพันธ์: ตาม §17.8 โดยใช้กำลังดึงจาก §17.10.5.4

## 17.11 Attachment ที่มี Shear lug (ใหม่ใน 318-19)

### 17.11.1 ทั่วไป

- shear lug = แผ่นเหล็กสี่เหลี่ยมหรือรูปพรรณที่ประกอบด้วยแผ่น เชื่อมใต้แผ่นฐาน (ใช้วิธีอื่นได้ถ้าพิสูจน์ด้วยการวิเคราะห์/ทดสอบ)
- ต้องมี **พุกอย่างน้อย 4 ตัว** ผ่าน Ch.17 (ยกเว้นการตรวจแรงเฉือนของพุก: เหล็ก, breakout, pryout)
- พุกเชื่อมกับแผ่นฐาน: ต้องรวมส่วนหนึ่งของแรงเฉือนในการตรวจปฏิสัมพันธ์ (§17.8)
- **การแบกทาน:** φVbrg,sl ≥ Vu, **φ = 0.65**
- **Concrete breakout ของ shear lug:** φVcb,sl ≥ Vu, **φ = 0.65**
- พุกรับแรงดึง: **hef/hsl ≥ 2.5** และ **hef/csl ≥ 2.5** (hsl = ความลึกฝัง lug, csl = ระยะจากแนวพุกรับแรงดึงถึงแนว lug ในทิศแรงเฉือน)
- ต้องคิดโมเมนต์จากคู่แรงแบกทาน-แรงเฉือน ในการออกแบบพุกรับแรงดึง
- แผ่นฐานแนวนอนที่มี lug: เจาะรู **≥ 1 in.** ทั้งสองด้านยาวของ lug (ตรวจการอัดแน่นและไล่อากาศ)

### 17.11.2 กำลังแบกทาน

$$V_{brg,sl} = 1.7f'_c\,A_{ef,sl}\,\psi_{brg,sl}$$

- Aef,sl = พื้นที่แบกทานประสิทธิผลใต้ผิวคอนกรีต ตั้งฉากแรงเฉือน — นับเฉพาะส่วนของ lug ภายใน **2tsl** จาก (a) ผิวล่างแผ่นฐาน ถ้าผิวแผ่นเสมอคอนกรีต, (b) ผิวคอนกรีต ถ้าแผ่นลอยเหนือคอนกรีต, (c) รอยต่อกับครีบ (stiffener); และ (d) ขอบนำของครีบใต้ผิวคอนกรีต
- ครีบ (ถ้ามี) ยาวในทิศแรงเฉือน ≥ 0.5hsl

**ψbrg,sl**
- แรงดึงตามแกน: 1 + Pu/(nNsa) ≤ 1.0 (Pu เป็นลบ, n = จำนวนพุกรับแรงดึง)
- ไม่มีแรงตามแกน: 1.0
- แรงอัดตามแกน: 1 + 4Pu/(Abp·f′c) ≤ 2.0 (Abp = พื้นที่แผ่นฐานที่สัมผัสคอนกรีต/grout)

- **lug หลายตัว** ตั้งฉากแรงเฉือน: รวมกำลังได้ ถ้าหน่วยแรงเฉือนบนระนาบคอนกรีตระหว่าง lug ≤ **0.2f′c**

### 17.11.3 Concrete breakout ของ shear lug

- ใช้ §17.7.2 สมการ (17.7.2.1a) โดย Vb จาก **9λa√f′c·ca1^1.5** (ca1 = ระยะจากผิวแบกทานของ lug ถึงขอบ)
- AVc = พื้นที่ฉายบนผิวข้าง: ยื่น 1.5ca1 แนวนอนจากขอบ lug และ 1.5ca1 แนวดิ่งจากความลึกประสิทธิผล hef,sl (ไม่รวม Aef,sl)
- แรงขนานขอบ: ใช้ §17.7.2.1(c) โดย ca1 วัดถึงกึ่งกลาง lug และ ψec,V = 1.0
- lug ที่มุม: คำนวณแต่ละขอบ ใช้ค่าน้อยสุด; lug หลายตัว: ตรวจทุกผิว breakout ที่เป็นไปได้
