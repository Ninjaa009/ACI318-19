# ACI 318-19 Chapter 23 — Strut-and-Tie Method (วิธีแบบจำลองโครงถัก)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 435–454 (ฉบับ inch-pound, f′c และ fy หน่วย psi) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm / MPa" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ ไม่ใช่ค่าจากฉบับ 318M · บทนี้ปรับปรุงมากในฉบับ 2019

## 23.1 ขอบเขต

- ใช้ออกแบบชิ้นส่วนหรือบริเวณที่ **ความไม่ต่อเนื่องของน้ำหนักหรือรูปทรง** ทำให้ความเครียดตามยาวในหน้าตัดกระจายไม่เป็นเชิงเส้น
- ชิ้นส่วนคอนกรีตใด ๆ หรือบริเวณไม่ต่อเนื่อง ออกแบบโดยจำลองเป็น **โครงถักในอุดมคติ** ได้

**D-region vs B-region**
- **D-region** (Discontinuity): บริเวณใกล้แรงกระทำเป็นจุด แรงปฏิกิริยา หรือจุดเปลี่ยนรูปทรง (ช่องเปิด มุม dapped end corbel) — ตามหลัก St. Venant ยาวประมาณ **h** จากจุดไม่ต่อเนื่อง; ใช้สมมติฐาน plane sections ไม่ได้
- **B-region** (Beam/Bernoulli): บริเวณที่ใช้ทฤษฎีดัดปกติได้
- ตัวอย่าง D-region: คานลึก, corbel, dapped end, pile cap, จุดต่อคาน-เสา, ช่องเปิดใน web, รอยต่อเปลี่ยนความลึก

**ขั้นตอน STM (commentary)**
1. กำหนดและแยก D-region
2. หาแรงลัพธ์ที่ขอบ D-region
3. เลือกแบบจำลอง truss แล้วหาแรงใน strut และ tie (แกน strut/tie ให้ตรงกับสนามแรงอัด/แรงดึงโดยประมาณ)
4. ออกแบบ strut, tie, nodal zone ให้มีกำลังพอ และยึดปลายเหล็ก tie ในหรือเลย nodal zone

STM เป็นวิธี **lower-bound** (ทฤษฎีพลาสติก) — ไม่ได้มีไว้ออกแบบโครงถักจริง เพราะไม่คิดผลรอง (โมเมนต์)

## 23.2 ทั่วไป

| ข้อ | ข้อกำหนด |
|---|---|
| 23.2.1 | แบบจำลองประกอบด้วย **strut** (อัด), **tie** (ดึง), เชื่อมกันที่ **node** เป็นโครงถัก 2 หรือ 3 มิติ |
| 23.2.2 | รูปทรงโครงถักต้องสอดคล้องกับขนาดของ strut, tie, nodal zone, พื้นที่แบกทาน และจุดรองรับ |
| 23.2.3 | ต้องถ่ายน้ำหนักประลัยทั้งหมดไปยังจุดรองรับหรือ B-region ข้างเคียงได้ |
| 23.2.4 | แรงภายในต้องสมดุลกับแรงกระทำและแรงปฏิกิริยา |
| 23.2.5 | tie ตัดผ่าน strut หรือ tie อื่นได้ |
| 23.2.6 | strut ตัดหรือซ้อนกันได้ **เฉพาะที่ node** |
| 23.2.7 | **มุมระหว่างแกน strut กับ tie ที่ node เดียวกัน ≥ 25°** (กันรอยร้าวและความไม่เข้ากันของการเสียรูป; ห้ามจำลอง shear span ของคานชะลูดด้วย strut ลาดน้อยกว่า 25°) |
| 23.2.8 | ผลของการอัดแรงรวมเป็นแรงภายนอก โดย load factor ตาม §5.3.11 — pretensioned สมมติแรงอัดกระทำที่ปลายช่วง transfer length ได้ |
| 23.2.9 | **คานลึก** ที่ออกแบบด้วย STM ต้องผ่าน §9.9.2.1 (ขีดมิติ), §9.9.3.1 (เหล็กขั้นต่ำ), §9.9.4 (รายละเอียด) |
| 23.2.10 | **Bracket/corbel ที่ av/d < 2.0** ด้วย STM ต้องผ่าน §16.5.2, §16.5.6 และ **Asc ≥ 0.04(f′c/fy)(bwd)** |
| 23.2.11 | ระนาบที่ต้องถ่ายแรงเฉือนข้าม (รอยร้าว, รอยต่อต่างวัสดุ, cold joint เช่น corbel กับผิวเสา) → ใช้ shear friction §22.9 |
| 23.2.12 | ชิ้นส่วนในระบบต้านแรงแผ่นดินไหว → §23.11 |

**ชนิด node (ตามเครื่องหมายแรง)**
- **C-C-C**: แรงอัด 3 แรง
- **C-C-T**: แรงอัด 2 แรง + แรงดึง 1 แรง
- **C-T-T**: แรงอัด 1 แรง + แรงดึง 2 แรง
- node ต้องมีอย่างน้อย 3 แรงเพื่อสมดุล; ถ้ามีมากกว่า 3 ให้รวมแรงบางตัวเป็นแรงลัพธ์
- **Hydrostatic node**: หน่วยแรงบนทุกผิวเท่ากัน ผิวตั้งฉากแกน strut/tie → ความยาวผิว ∝ แรง

## 23.3 กำลังออกแบบ

ทุกชุดผสม ทุกองค์ประกอบ:

| องค์ประกอบ | เกณฑ์ |
|---|---|
| Strut | φFns ≥ Fus |
| Tie | φFnt ≥ Fut |
| Nodal zone | φFnn ≥ Fus |

**φ = 0.75** (Table 21.2.1(g)) — Fu = แรงมากที่สุดในองค์ประกอบนั้นจากทุกชุดผสม

## 23.4 กำลังของ Strut

$$F_{ns} = f_{ce}A_{cs} \qquad\text{(ไม่มีเหล็กตามยาว)}$$

$$F_{ns} = f_{ce}A_{cs} + A'_sf'_s \qquad\text{(มีเหล็กตามยาว)}$$

- ประเมินที่ **ปลายแต่ละด้าน** ใช้ค่าน้อยกว่า; Acs = พื้นที่หน้าตัดที่ปลาย strut (ตั้งฉากแกน) = ws × ความหนา
- f′s ใช้ fy ได้สำหรับเหล็ก Grade 40 หรือ 60
- strut ที่ปลายทั้งสองต่างกัน → ถือเป็นชิ้นส่วนรับแรงอัดเรียวสม่ำเสมอ

**กำลังอัดประสิทธิผล**

$$f_{ce} = 0.85\beta_c\beta_sf'_c$$

### Table 23.4.3(a) — สัมประสิทธิ์ strut βs

| ตำแหน่ง strut | ชนิด | เกณฑ์ | βs |
|---|---|---|---|
| ชิ้นส่วนรับแรงดึง หรือโซนรับแรงดึง | ทุกชนิด | ทุกกรณี | **0.4** |
| กรณีอื่นทั้งหมด | Boundary strut | ทุกกรณี | **1.0** |
| | Interior strut | มีเหล็กกระจายตาม Table 23.5.1 (a) หรือ (b) | **0.75** |
| | | อยู่ในบริเวณที่ผ่านสมการ (23.4.4) | **0.75** |
| | | จุดต่อคาน-เสา | **0.75** |
| | | กรณีอื่นทั้งหมด | **0.4** |

- **Boundary strut** = strut ตามขอบชิ้นส่วน (เช่น โซนอัดของคาน) ไม่มีแรงดึงขวาง — คล้ายบล็อกหน่วยแรง
- **Interior strut** = strut ภายในที่อาจแตกร้าวตามยาว (bottle-shaped)
- βs = 0.4 กรณีไม่มีเหล็กกระจาย: กันการวิบัติแบบแรงดึงทแยง (ฉบับ 2019 ลดจาก 0.6λ)

### Table 23.4.3(b) — ตัวปรับการโอบรัด βc

| ตำแหน่ง | βc |
|---|---|
| ปลาย strut ที่ต่อกับ node ที่มีพื้นที่แบกทาน / node ที่มีพื้นที่แบกทาน | ค่าน้อยกว่าของ **√(A2/A1)** และ **2.0** |
| กรณีอื่น | 1.0 |

(A1, A2 นิยามเหมือน §22.8.3 — คอนกรีตรอบพื้นที่แบกทานโอบรัดให้กำลังสูงขึ้น; ฉบับ 2019 เพิ่มใหม่)

### 23.4.4 เงื่อนไขใช้ βs = 0.75 โดยไม่มีเหล็กกระจาย

$$V_u \le \phi\,5\tan\theta\,\lambda\lambda_s\sqrt{f'_c}\,b_wd$$

- θ = มุม strut กับ tie; λs:
  - มีเหล็กกระจายตาม §23.5 → **λs = 1.0**
  - ไม่มี → λs = √(2/(1 + d/10)) ≤ 1 (d หน่วย in.)
- กัน diagonal tension failure — strut ชันมาก Vu อาจเกิน φ10λλs√f′c·bwd ได้

## 23.5 เหล็กกระจายขั้นต่ำ

D-region ที่ออกแบบด้วย STM ต้องมีเหล็กกระจายข้ามแกน interior strut (ช่วยกระจายแรงใหม่หลังแตกร้าว คุมรอยร้าวที่น้ำหนักใช้งาน และเพิ่มความเหนียว):

**Table 23.5.1**

| การยึดรั้งด้านข้างของ strut | การจัดเหล็ก | อัตราส่วนขั้นต่ำ |
|---|---|---|
| ไม่ถูกยึดรั้ง | ตะแกรงตั้งฉาก (orthogonal grid) | **0.0025** ทั้งสองทิศ |
| | เหล็กทิศเดียวตัด strut ที่มุม α1 | **0.0025 / sin²α1** |
| ถูกยึดรั้ง | ไม่ต้องมีเหล็กกระจาย | — |

(อัตราส่วนรวมทั้งสองผิว + ชั้นในถ้ามี)

- ระยะห่าง **≤ 12 in. (≈ 300 mm)**
- มุม **α1 ≥ 40°**
- พัฒนาเหล็กเลยขอบ strut ตาม §25.4

**ถือว่า strut ถูกยึดรั้งด้านข้าง (23.5.3)** ถ้า:
- (a) D-region ต่อเนื่องในทิศตั้งฉากกับระนาบแบบจำลอง (เช่น corbel ต่อเนื่องรับพื้น)
- (b) คอนกรีตที่ยึดรั้ง strut ยื่นเลยผิวข้างแต่ละด้าน **≥ ½ ความกว้าง strut** (เช่น pile cap, beam ledge)
- (c) strut อยู่ในจุดต่อที่ถูกโอบรัดตาม §15.2.5 หรือ §15.2.6

## 23.6 รายละเอียดเหล็กใน Strut

- เหล็กรับแรงอัดใน strut ต้อง **ขนานแกน strut** และโอบด้วยปลอกปิด (§23.6.3) หรือเกลียว (§23.6.4) ตลอดความยาว
- ยึดให้พัฒนา f′s ที่ผิว nodal zone
- ปลอกปิดตาม §25.7.2 และ:
  - ระยะห่าง ≤ ค่าน้อยสุดของ (a) **ด้านแคบสุดของหน้าตัด strut** (b) **48db** ของปลอก (c) **16db** ของเหล็กรับแรงอัด
  - ปลอกวงแรก ≤ **0.5s** จากผิว nodal zone ที่ปลายแต่ละด้าน
  - ทุกมุมและเหล็กเว้นเส้นต้องยึดรั้งด้วยมุมปลอก/crosstie ที่ ≤ 135° และไม่มีเหล็กใดห่างเกิน **6 in.** (ระยะว่าง) จากเหล็กที่ถูกยึดรั้ง
- เกลียวตาม §25.7.3

## 23.7 กำลังของ Tie

- เหล็ก tie เป็นเหล็กไม่อัดแรงหรืออัดแรง

$$F_{nt} = A_{ts}f_y + A_{tp}\Delta f_p$$

- Atp = 0 สำหรับชิ้นส่วนไม่อัดแรง
- Δfp ใช้ **60,000 psi** (ลวดยึดเกาะ) หรือ **10,000 psi** (ไม่ยึดเกาะ) ได้ — สูงกว่าได้ถ้าวิเคราะห์ แต่ ≤ (fpy − fse)
- (กำลังรวมของ tie อัดแรง = Atp(fse + Δfp) — ผลของ fse คิดเป็นแรงภายนอกตาม §23.2.8)
- fy ของ tie ตามยาว ≤ 80,000 psi; tie อื่น ≤ 60,000 psi (Table 20.2.2.4(a))
- คอนกรีตรอบ tie **ไม่นับ** รับแรงดึง (แต่ช่วยลดการยืดตัวที่น้ำหนักใช้งาน)

## 23.8 รายละเอียดเหล็ก Tie

- **แกนศูนย์ถ่วงของเหล็ก tie ต้องตรงกับแกน tie** ในแบบจำลอง
- ความกว้าง tie ประสิทธิผล wt (commentary):
  - เหล็กชั้นเดียว: wt ≈ เส้นผ่านศูนย์กลางเหล็ก + 2 × ระยะหุ้ม
  - ขีดบน: wt,max = Fnt/(fce·bs) (เทียบ hydrostatic node)
  - ถ้า wt กว้างกว่า (a) ให้กระจายเหล็กสม่ำเสมอทั่วความกว้างและความหนา
- **การยึดปลาย:** อุปกรณ์กล, anchorage ของ PT, ขอมาตรฐาน หรือการพัฒนาเหล็กตรงตาม §23.8.3 (ยกเว้น tie จาก curved-bar node ตาม §23.10)
- **แรงใน tie ต้องพัฒนาได้ที่จุดที่ศูนย์ถ่วงเหล็กออกจาก extended nodal zone** (ℓanc) — extended nodal zone = บริเวณที่ขอบ strut และ tie ประสิทธิผลตัดกัน
- ลดระยะพัฒนาได้ด้วยขอ เหล็กหัว อุปกรณ์กล การโอบรัด หรือแบ่งเป็นเหล็กเล็กหลายชั้น; ขอ 90° ต้องโอบรัดด้วยเหล็กกันแตกที่จุดรองรับ; คานลึกใช้ hairpin ต่อทาบได้

## 23.9 กำลังของ Nodal zone

$$F_{nn} = f_{ce}A_{nz}, \qquad f_{ce} = 0.85\beta_c\beta_nf'_c$$

### Table 23.9.2 — สัมประสิทธิ์ nodal zone βn

| ลักษณะ nodal zone | βn |
|---|---|
| ล้อมรอบด้วย strut, พื้นที่แบกทาน หรือทั้งสอง (C-C-C) | **1.0** |
| ยึด tie **1 ตัว** (C-C-T) | **0.80** |
| ยึด tie **≥ 2 ตัว** (C-T-T, T-T-T) | **0.60** |

(βn ต่ำลงเพราะความเครียดดึงของ tie ไม่เข้ากับความเครียดอัดของ strut)

- ใช้ fce สูงขึ้นได้ ถ้ามีเหล็กโอบรัดใน nodal zone และพิสูจน์ด้วยการทดสอบ/วิเคราะห์
- **Anz** = ค่าน้อยกว่าของ (a) พื้นที่ผิว nodal zone ตั้งฉากแนวแรง Fus (b) พื้นที่หน้าตัดผ่าน nodal zone ตั้งฉากแรงลัพธ์บนหน้าตัดนั้น
- **3 มิติ:** พื้นที่ผิวแต่ละผิว ≥ ตาม 23.9.4 และรูปร่างผิวคล้ายภาพฉายปลาย strut บนผิวนั้น

**สรุป fce (สร้างเอง):**

| องค์ประกอบ | 0.85βcβ × f′c (βc = 1) |
|---|---|
| Boundary strut, C-C-C node | 0.85f′c |
| Interior strut มีเหล็กกระจาย, C-C-T node | 0.64 / 0.68f′c |
| C-T-T node | 0.51f′c |
| Strut ไม่มีเหล็กกระจาย / ในโซนดึง | 0.34f′c |

## 23.10 Curved-bar nodes (ใหม่ใน 318-19)

node ที่เกิดจากส่วนโค้งของเหล็กต่อเนื่อง (มุมโครง C-T-T) หรือ tie ที่ยึดด้วยการงอ 180° (C-C-T)

**รัศมีดัด rb** — ถ้าระยะหุ้มตั้งฉากระนาบการดัด ≥ 2db, rb ≥ ค่าตามนี้ (และ ≥ ½ ของเส้นผ่านศูนย์กลางดัดขั้นต่ำตาม §25.3):

| กรณี | rb |
|---|---|
| (a) ดัด < 180° | rb ≥ 2Atsfy / (bs·f′c) |
| (b) tie ยึดด้วยการดัด 180° | rb ≥ 1.5Atsfy / (wt·f′c) |

- bs = ความกว้าง strut ตั้งฉากระนาบแบบจำลอง; wt = ความกว้าง tie ประสิทธิผล
- ระยะหุ้มด้านข้าง cc < 2db → คูณ rb ด้วย **2db/cc**
- หลายชั้นเหล็ก: Ats = พื้นที่รวม, rb = รัศมีของชั้นในสุด
- **มุมโครง (frame corner):** จุดศูนย์กลางความโค้งต้องอยู่ **ภายในจุดต่อ**
- ความยาวโค้ง ℓcb ต้องพัฒนาผลต่างแรงระหว่างขาตรงสองข้าง — มุม 90° ใช้ **ℓcb > ℓd(1 − tanθc)** ได้ (θc = มุมที่เล็กกว่าระหว่างแกน strut กับ tie)

## 23.11 การออกแบบต้านแผ่นดินไหวด้วย STM

ใช้กับบริเวณในระบบต้านแรงแผ่นดินไหวของ **SDC D, E, F** — ต้องผ่าน (a) Ch.18 และ (b) §23.11.2–23.11.5 **เว้นแต่** แรง E ใน strut/tie ขยายด้วย **Ω₀ ≥ 2.5** (หรือค่าน้อยกว่าที่วิเคราะห์ได้) — ควรทำแบบจำลองแยกตามทิศแรงสลับ

| ข้อ | ข้อกำหนด |
|---|---|
| 23.11.2 Strut | fce ตาม §23.4 **× 0.8** (รอยร้าวจากแรงสลับ) |
| 23.11.3 รายละเอียด strut | โอบรัดแต่ละ strut (23.11.3.2) หรือทั้งหน้าตัด (23.11.3.3) |
| 23.11.4 Tie | ระยะพัฒนา **× 1.25** (เผื่อ fy จริงสูงกว่าและ strain hardening) |
| 23.11.5 Node | Fnn ตาม §23.9 **× 0.8** |

**โอบรัดแต่ละ strut (23.11.3.2)** — เหล็กตามยาว ≥ 4 เส้น (1 เส้นทุกมุม), เหล็กตามขวางตั้งฉาก strut:
- รายละเอียดตาม §18.7.5.2(a)–(e), ต่อเนื่องผ่าน nodal zone
- Ash/(sbc) ≥ ค่ามากกว่าของ **0.3(Acs/Ach − 1)f′c/fyt** และ **0.09f′c/fyt** (Ach วัดถึงขอบนอกเหล็กตามขวางของ strut; ใช้ hoop สองชิ้นตาม §18.6.4.3 ได้)
- ระยะตาม §18.7.5.3(d) และไม่เกิน:

| เกรดเหล็ก | ระยะสูงสุด (ค่าน้อยกว่า) |
|---|---|
| Grade 60 | 6db, 6 in. |
| Grade 80 | 5db, 6 in. |
| Grade 100 | 4db, 6 in. |

**โอบรัดทั้งหน้าตัด (23.11.3.3)** — เหล็กตามขวางทั้งสองทิศตั้งฉากและตลอดความหนา:
- Ash/(sbc) ≥ ค่ามากกว่าของ **0.3(Ag/Ach − 1)f′c/fyt** และ **0.09f′c/fyt**
- ระยะตามแกนชิ้นส่วนตามตารางข้างบน
- ระยะ crosstie/ขา hoop ทั้งแนวดิ่งและนอน **≤ 8 in.**; ทุก crosstie และขา hoop ต้องจับเหล็กยืนขนาดเท่าหรือใหญ่กว่า
