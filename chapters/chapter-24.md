# ACI 318-19 Chapter 24 — Serviceability (สภาวะใช้งาน)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 455–466 (ฉบับ inch-pound, f′c และ fy หน่วย psi) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm / MPa" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ ไม่ใช่ค่าจากฉบับ 318M

## 24.1 ขอบเขต

ข้อกำหนด serviceability ขั้นต่ำ:
- (a) การโก่งตัวจากน้ำหนักแนวดิ่งระดับใช้งาน (§24.2)
- (b) การกระจายเหล็กรับแรงดัดในพื้นทางเดียวและคาน เพื่อคุมรอยร้าว (§24.3)
- (c) เหล็กกันร้าว (shrinkage & temperature) (§24.4)
- (d) หน่วยแรงที่ยอมให้ในชิ้นส่วนอัดแรง (§24.5)

**การสั่นสะเทือน:** บทนี้ไม่มีข้อกำหนดเฉพาะ — พื้นหล่อในที่ที่ผ่านความหนาขั้นต่ำ (§7.3, 8.3, 9.3) และ §24.2 โดยทั่วไปสั่นอยู่ในระดับที่คนรับได้ แต่ควรตรวจเพิ่มเมื่อ: (a) ช่วงยาว/ผังเปิดโล่ง (b) พื้นที่ต้องการควบคุมการสั่นเข้มงวด (โรงงานความแม่นยำสูง, ห้องแล็บ) (c) มีน้ำหนักเป็นจังหวะหรือเครื่องจักร — พื้นอัดแรงไม่อยู่ใต้เกณฑ์ความหนาขั้นต่ำ จึงอาจสั่นง่ายกว่า (แนวทาง: PCI MNL 120, ATC Design Guide 1)

## 24.2 การโก่งตัวจากน้ำหนักแนวดิ่ง

- ชิ้นส่วนรับแรงดัดต้องมี stiffness พอจำกัดการโก่งตัวที่กระทบกำลังหรือ serviceability

**สองวิธีคุมการโก่งตัว**
1. ใช้ **ความหนาขั้นต่ำ** (§7.3.1 พื้นทางเดียว, §9.3.1 คาน, §8.3.1 พื้นสองทาง) — ใช้ได้กับชิ้นส่วนไม่อัดแรงที่ไม่รองรับสิ่งที่เสียหายง่าย
2. **คำนวณ** ตาม §24.2.3–24.2.5 แล้วเทียบกับ Table 24.2.2 — ต้องใช้กับ: ชิ้นส่วนที่บางกว่าเกณฑ์, ชิ้นส่วนทางเดียวที่รองรับสิ่งที่เสียหายง่าย, ชิ้นส่วนอัดแรงทุกตัว

### Table 24.2.2 — การโก่งตัวสูงสุดที่ยอมให้

| ชิ้นส่วน | สภาพ | การโก่งตัวที่พิจารณา | ขีดจำกัด |
|---|---|---|---|
| หลังคาแบน | ไม่รองรับหรือติดกับสิ่งที่ไม่ใช่โครงสร้างซึ่งอาจเสียหายจากการโก่งมาก | ทันที จาก Lr, S, R สูงสุด | ℓ/180 ¹ |

2. หักการโก่งที่เกิดก่อนติดตั้งสิ่งที่ไม่ใช่โครงสร้างออกได้ (อาศัยข้อมูลพฤติกรรม เช่น Fig. R24.2.4.1)
3. เกินได้ถ้ามีมาตรการป้องกันความเสียหาย
4. ต้องไม่เกินค่าคลาดเคลื่อนที่สิ่งที่ไม่ใช่โครงสร้างรองรับได้

### 24.2.3 การโก่งตัวทันที

- ใช้สูตรการโก่งยืดหยุ่น โดยคิดผลของการแตกร้าวและเหล็กต่อ stiffness
- ต้องคิดการเปลี่ยนหน้าตัด (เช่น haunch)
- พื้นสองทาง: คิดขนาด รูปร่างแผง สภาพจุดรองรับ และการยึดรั้งที่ขอบ
- Ec ตาม §19.2.2

**Ie สำหรับชิ้นส่วนไม่อัดแรง (Table 24.2.3.5)** — ใหม่ใน 318-19 (สมการ Bischoff แทน Branson):

$$M_{cr} = \frac{f_r I_g}{y_t}$$

| Ma | Ie |
|---|---|
| ≤ (2/3)Mcr | Ig |
| > (2/3)Mcr | Icr / [1 − ((2/3)Mcr/Ma)²(1 − Icr/Ig)] |

- ตัวคูณ 2/3 เผื่อการยึดรั้งที่ลด Mcr ประสิทธิผล และกำลังรับแรงดึงที่ลดลงช่วงก่อสร้าง
- สมการ Branson เดิมให้การโก่งต่ำเกินจริงในชิ้นส่วนเหล็กน้อย (เช่น พื้น) — ถ้า ρ > 1% และ Ma ≥ 2Mcr ผลใกล้เคียงกัน
- **ชิ้นส่วนต่อเนื่อง:** ใช้ Ie เฉลี่ยของหน้าตัดโมเมนต์บวกและลบวิกฤตได้
- **หน้าตัดคงที่ (prismatic):** ใช้ Ie ที่กลางช่วง (ช่วงเดียวและต่อเนื่อง) หรือที่จุดรองรับ (cantilever) ได้

**ชิ้นส่วนอัดแรง**
- **Class U:** ใช้ Ig ได้
- **Class T และ C:** ใช้หน้าตัดแปลงแตกร้าว หรือความสัมพันธ์โมเมนต์-การโก่งแบบ bilinear หรือ (สมการ Branson เดิม):

$$I_e = \left(\frac{M_{cr}}{M_a}\right)^3 I_g + \left[1 - \left(\frac{M_{cr}}{M_a}\right)^3\right]I_{cr}, \qquad M_{cr} = \frac{(f_r + f_{pe})I_g}{y_t}$$

### 24.2.4 การโก่งตัวตามเวลา (Long-term)

**ชิ้นส่วนไม่อัดแรง** — การโก่งเพิ่มจาก creep และ shrinkage = การโก่งทันทีจากน้ำหนักค้าง × λΔ:

$$\lambda_\Delta = \frac{\xi}{1 + 50\rho'}$$

- ρ′ = อัตราส่วนเหล็กรับแรงอัด ที่กลางช่วง (ช่วงเดียว/ต่อเนื่อง) หรือที่จุดรองรับ (cantilever)

**Table 24.2.4.1.3 — ξ**

| ระยะเวลาน้ำหนักค้าง | ξ |
|---|---|
| 3 เดือน | 1.0 |
| 6 เดือน | 1.2 |
| 12 เดือน | 1.4 |
| ≥ 60 เดือน (5 ปี) | 2.0 |

- คิดเฉพาะ dead load และส่วนของน้ำหนักอื่นที่ค้างนานพอ
- พื้นสองทางก็ใช้วิธีนี้

**ชิ้นส่วนอัดแรง** — ต้องคำนวณโดยคิดหน่วยแรงในคอนกรีตและเหล็กภายใต้น้ำหนักค้าง, creep, shrinkage และ relaxation ของลวด (การหดตัวตามแกนของชิ้นส่วนอัดแรงทำให้แรงอัดลดลงและโก่งเพิ่ม — แนวทาง: ACI 209R, ACI 435)

### 24.2.5 ชิ้นส่วน composite

- **มีค้ำยันขณะก่อสร้าง** (dead load รับโดยหน้าตัด composite เต็มหลังถอดค้ำ): คิดเหมือนหล่อเป็นเนื้อเดียวได้
- **ไม่มีค้ำยัน:** ต้องคิดขนาดและระยะเวลาของน้ำหนักก่อนและหลังเป็น composite
- ต้องคิดการโก่งจากการหดตัวต่างกันระหว่าง precast กับคอนกรีตหล่อในที่ และ creep ตามแกนของชิ้นส่วนอัดแรง

## 24.3 การกระจายเหล็กรับแรงดัด (คุมรอยร้าว)

ใช้กับพื้นทางเดียวและคาน — ไม่อัดแรง และอัดแรง Class C

**Table 24.3.2 — ระยะห่างสูงสุดของเหล็กยึดเกาะชั้นใกล้ผิวรับแรงดึง**

| ชนิดเหล็ก | s สูงสุด = ค่าน้อยกว่าของ |
|---|---|
| เหล็กข้ออ้อยหรือลวด | 15(40,000/fs) − 2.5cc **และ** 12(40,000/fs) |
| ลวดอัดแรงยึดเกาะ | (2/3)[15(40,000/Δfps) − 2.5cc] **และ** (2/3)[12(40,000/Δfps)] |
| ผสมเหล็กข้ออ้อย + ลวดอัดแรงยึดเกาะ | (5/6)[15(40,000/Δfps) − 2.5cc] **และ** (5/6)[12(40,000/Δfps)] |

(s และ cc หน่วย in.; fs, Δfps หน่วย psi; cc = ระยะน้อยสุดจากผิวเหล็กถึงผิวรับแรงดึง)

- **fs** = หน่วยแรงในเหล็กชั้นใกล้ผิวดึงที่น้ำหนักใช้งาน — คำนวณจากโมเมนต์ไม่คูณ factor หรือใช้ **fs = (2/3)fy** ได้
- **ตัวอย่าง:** Grade 60, fs = 40,000 psi, cc = 2 in. → s = 15 − 5 = **10 in. (≈ 250 mm)**
- **Δfps** = หน่วยแรงที่เปลี่ยนในลวดอัดแรงยึดเกาะ = หน่วยแรงจากหน้าตัดแตกร้าว − fdc (ใช้ fdc = fse ได้); **Δfps ≤ 36,000 psi** — ถ้า Δfps ≤ 20,000 psi ไม่ต้องผ่านตาราง
- ลวดอัดแรงมีตัวคูณ 2/3 เพราะยึดเกาะได้ด้อยกว่าเหล็กข้ออ้อย
- มีเหล็ก/strand/tendon เส้นเดียวใกล้ผิวดึงสุด → ความกว้างผิวดึงต้อง ≤ s

**ปีกคาน T รับแรงดึง (24.3.4)**
- เหล็กรับแรงดึงที่ไม่ได้อยู่เหนือ web กระจายภายในค่าน้อยกว่าของ **ความกว้างปีกประสิทธิผล (§6.3.2)** และ **ℓn/10**
- ถ้า ℓn/10 ควบคุม → เพิ่มเหล็กตามยาวที่ส่วนนอกของปีก ≥ ตาม §24.4.3.1

**สภาพพิเศษ (24.3.5):** ชิ้นส่วนรับ fatigue, ออกแบบกันน้ำ, หรือสภาพกัดกร่อน → กำหนดระยะห่างจากการศึกษาเฉพาะ และไม่เกิน Table 24.3.2 (ACI 350 สำหรับโครงสร้างเก็บน้ำ)

- commentary: Code ไม่แยกสภาพภายใน/ภายนอก เพราะงานวิจัยไม่พบความสัมพันธ์ชัดเจนระหว่างความกว้างรอยร้าวกับการเกิดสนิม — คุณภาพคอนกรีต การอัดแน่น และระยะหุ้มสำคัญกว่า

## 24.4 เหล็กกันร้าว (Shrinkage & Temperature)

- ต้องมีในพื้นทางเดียว **ตั้งฉาก** กับเหล็กรับแรงดัด (ไม่ใช้กับ slab-on-ground)
- ถ้าการหดตัวและการเปลี่ยนแปลงอุณหภูมิถูกยึดรั้ง (ผนัง/เสาแข็ง) → คิดผล T ตาม §5.3.6 (อาจต้องเหล็กมากกว่าขั้นต่ำ; ใช้ closure strip ช่วยได้)

### 24.4.3 เหล็กข้ออ้อย

| ข้อ | ข้อกำหนด |
|---|---|
| 24.4.3.1 | ชนิดเหล็กตาม Table 20.2.2.4(a) |
| 24.4.3.2 | **As/Ag ≥ 0.0018** (ทุกเกรด — ใหม่ใน 318-19 ยกเลิกการลดเหล็กสำหรับ fy > 60,000 psi เพราะกำลังครากสูงไม่ช่วยคุมรอยร้าว) |
| 24.4.3.3 | ระยะห่าง **≤ ค่าน้อยกว่าของ 5h และ 18 in. (≈ 450 mm)** |
| 24.4.3.4 | ทุกหน้าตัดที่ต้องใช้ ต้องพัฒนา **fy** ได้ (ต่อทาบ/ฝังยึดตาม Ch.25) |
| 24.4.3.5 | พื้น precast ทางเดียว และแผงผนัง precast อัดแรงทางเดียว **ไม่ต้อง** มีเหล็กตั้งฉาก ถ้า: (a) กว้าง ≤ **12 ft** (b) ไม่ได้ต่อเชิงกลจนเกิดการยึดรั้งทางขวาง (c) ไม่ต้องรับแรงดัดทางขวาง |

- 0.0018 เป็นค่าเชิงประสบการณ์ วางใกล้ผิวบน ล่าง หรือกระจายทั้งสองผิวได้ — ถ้าต้องการคุมรอยร้าวหรือกันรั่ว ดู ACI 224R หรือ ACI 350

### 24.4.4 เหล็กอัดแรง

- ชนิดตาม Table 20.3.2.2
- แรงอัดประสิทธิผลหลังหักการสูญเสีย ต้องให้หน่วยแรงอัดเฉลี่ย **≥ 100 psi (≈ 0.7 MPa)** บนพื้นที่หน้าตัดรวม

## 24.5 หน่วยแรงที่ยอมให้ในชิ้นส่วนอัดแรงรับแรงดัด

### 24.5.1 ทั่วไป

- จำกัดหน่วยแรงคอนกรีตตาม §24.5.2–24.5.4 เว้นแต่พิสูจน์ด้วยการทดสอบ/วิเคราะห์ว่าสมรรถนะไม่ลดลง (ขีดจำกัดนี้เป็นเรื่อง serviceability ไม่ได้รับประกันกำลัง)
- คำนวณหน่วยแรงที่ถ่ายแรง ที่น้ำหนักใช้งาน และที่น้ำหนักแตกร้าว ด้วยทฤษฎียืดหยุ่น: (a) ความเครียดแปรเชิงเส้นตามระยะจากแกนสะเทิน (b) หน้าตัดแตกร้าว คอนกรีตไม่รับแรงดึง
