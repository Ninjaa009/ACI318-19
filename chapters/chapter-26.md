# ACI 318-19 Chapter 26 — Construction Documents and Inspection (เอกสารก่อสร้างและการตรวจงาน)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 515–556 (ฉบับ inch-pound) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm / MPa / m³" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ ไม่ใช่ค่าจากฉบับ 318M

## 26.1 ขอบเขต

บทนี้กำหนดว่า **วิศวกรผู้ออกแบบ (licensed design professional, LDP)** ต้องใส่อะไรลงในเอกสารก่อสร้าง (แบบ + รายการประกอบแบบ) แบ่งเป็น 3 ประเภท

| ประเภท | ความหมาย |
|---|---|
| **Design information** | ข้อมูลเฉพาะโครงการที่มาจากการออกแบบ ใส่เฉพาะที่เกี่ยวข้อง |
| **Compliance requirements** | ข้อกำหนดคุณภาพขั้นต่ำทั่วไปของงานก่อสร้าง ไม่ต้องคัดลอกตามตัวอักษร เขียนต่างหรือเข้มกว่าได้ |
| **Inspection requirements** | การตรวจงาน (§26.13) ใช้เมื่อกฎหมายอาคารท้องถิ่นไม่ได้กำหนด — ถ้ามี ข้อกำหนดท้องถิ่นมาก่อน |

- เจตนา: ผู้รับเหมาไม่ต้องอ่านหรือตีความ Code เอง ทุกอย่างที่จำเป็นต้องอยู่ในเอกสารก่อสร้าง
- **หลีกเลี่ยง** การเขียนลอย ๆ ว่า "ให้เป็นไปตาม ACI 318" หรืออ้างเลขข้อของ Code ในแบบ — ให้เขียนข้อกำหนดออกมาเลย (อ้างมาตรฐาน ACI/ASTM อื่นได้ เช่น ACI 301 ซึ่งเป็นรายการประกอบแบบอ้างอิงที่สอดคล้องกับ 318)
- ข้อกำหนดการติดตั้งและตรวจ anchor ย้ายจาก Ch.17 (ฉบับ 2014) มาอยู่บทนี้

## 26.2 เกณฑ์การออกแบบ

**ข้อมูลที่ต้องระบุ**
- ชื่อและปีของ Code, กฎหมายอาคาร และเอกสารเพิ่มเติมที่ใช้ออกแบบ
- น้ำหนักบรรทุกที่ใช้ออกแบบ (แนวดิ่ง/แนวราบ)
- งานออกแบบที่มอบให้ผู้รับเหมา (delegated design) พร้อมเกณฑ์ออกแบบ (มิติ น้ำหนัก สมมติฐาน)

**ข้อกำหนด**
- งาน delegated design ต้องทำโดย **specialty engineer** ของผู้รับเหมา ให้สอดคล้องกับเอกสารก่อสร้าง
- ผู้รับเหมาส่งข้อมูลให้ LDP ยืนยันว่าทำตามขอบเขตที่มอบหมาย

## 26.3 ข้อมูลชิ้นส่วน

- ขนาด ตำแหน่ง และค่าคลาดเคลื่อน (อ้าง ACI 117 สำหรับหล่อในที่, ACI ITG-7 สำหรับหล่อสำเร็จ — ถ้าต้องการเข้มกว่าให้ระบุ)
- ชิ้นส่วนที่ต้องก่อสร้างด้วย **shotcrete**
- ชิ้นส่วนที่ต้องทดสอบ **โมดูลัสยืดหยุ่น Ec** ของส่วนผสม
- ใช้ shotcrete กับชิ้นส่วนที่ไม่ได้ระบุไว้ได้ ถ้าเป็นไปตามสัญญาโครงการ

## 26.4 วัสดุและส่วนผสมคอนกรีต

### 26.4.1 วัสดุ

| วัสดุ | มาตรฐาน |
|---|---|
| ปูนซีเมนต์ปอร์ตแลนด์ | ASTM C150 |
| Blended hydraulic cement | ASTM C595 (ยกเว้น Type IS (≥70) และ Type IT (S≥70)) |
| Expansive cement | ASTM C845 |
| Hydraulic cement | ASTM C1157 |
| เถ้าลอย/pozzolan ธรรมชาติ | ASTM C618 |
| Slag cement | ASTM C989 |
| Silica fume | ASTM C1240 |
| มวลรวมปกติ / มวลเบา | ASTM C33 / C330 |
| มวลรวม shotcrete (gradation) | ASTM C1436 |
| Mineral filler | ASTM C1797 |
| น้ำผสม | ASTM C1602 (น้ำประปาใช้ได้โดยไม่ต้องทดสอบ) |
| สารผสมเพิ่ม: ลดน้ำ/ปรับเวลา, ทำคอนกรีตไหล, กักฟองอากาศ, ยับยั้งสนิมจากคลอไรด์ | C494, C1017, C260, C1582 |
| สารผสมเพิ่มใน shotcrete | ASTM C1141 |
| วัสดุผสมแห้งสำเร็จรูปสำหรับ shotcrete | ASTM C1480 |

- **ปูนทางเลือก (alternative cement)** ใช้ได้เมื่อ LDP และเจ้าพนักงานอนุมัติ โดยมีผลทดสอบยืนยันสมรรถนะ (กำลัง ไฟ ความทนทาน)
- มวลรวมนอกมาตรฐานใช้ได้ ถ้าพิสูจน์ด้วยการทดสอบหรือประวัติการใช้งานและเจ้าพนักงานอนุมัติ
- **มวลรวมจากคอนกรีตบด/รีไซเคิล** ต้องได้รับอนุมัติจาก LDP และเจ้าพนักงาน มีหลักฐานว่าให้คุณสมบัติกลและความทนทานตามออกแบบ และมีโปรแกรมทดสอบ/ควบคุมคุณภาพตลอดโครงการ
- สารผสมเพิ่มที่ไม่ตรงมาตรฐานต้องให้ LDP ทบทวนก่อน; ใช้กับ expansive cement ต้องเข้ากันได้
- **เส้นใยเหล็กรับแรงเฉือน**: เป็นเส้นใยข้ออ้อยตาม ASTM A820, อัตราส่วนยาว/เส้นผ่านศูนย์กลาง **50–100**

### 26.4.2 ข้อกำหนดส่วนผสม

**ข้อมูลที่ต้องระบุสำหรับแต่ละส่วนผสม** (ตามชั้นสภาวะแวดล้อม Ch.19 หรือการออกแบบ)
1. f′c ขั้นต่ำ
2. Ec ขั้นต่ำ (ถ้าระบุ)
3. อายุทดสอบ ถ้าไม่ใช่ 28 วัน
4. w/cm สูงสุด ตามชั้นที่เข้มที่สุด
5. ขนาดมวลรวมหยาบโตสุด ≤ ค่าน้อยสุดของ
   - 1/5 ระยะแคบสุดระหว่างข้างแบบ
   - 1/3 ความหนาพื้น
   - 3/4 ระยะว่างขั้นต่ำระหว่างเหล็ก/ลวด/ท่อ
   - ยกเว้นได้ถ้า LDP เห็นว่าเทและอัดแน่นได้โดยไม่เกิดโพรง
6. ปริมาณฟองอากาศ (Exposure F)
7. ขีดจำกัด SCM สำหรับ F3
8. ห้าม mineral filler จากหินปูนในชั้น S1–S3 (เว้นแต่ LDP อนุมัติ)
9. วัสดุประสานสำหรับชั้น S
10. อนุญาตวัสดุประสานทางเลือกในชั้น S หรือไม่
11. ห้ามแคลเซียมคลอไรด์ใน S2/S3
12. การประเมินปฏิกิริยาด่าง-มวลรวม (AAR) สำหรับ W1/W2
13. ขีดจำกัดคลอไรด์ที่ละลายน้ำได้ (Exposure C)
14. ความหนาแน่นสมดุลของคอนกรีตมวลเบา
15. ส่งสัดส่วนปริมาตรมวลรวม ถ้าใช้ Table 19.2.4.1(b) หาค่า λ
16. ข้อกำหนดคอนกรีตเส้นใยเหล็กรับเฉือน
17. มวลรวม shotcrete ≤ **½ in. (≈ 12 mm)**

- ระบุชั้นสภาวะแวดล้อมของชิ้นส่วนได้ (ไม่บังคับ แต่ถ้าใช้ ACI 301 ให้ผู้รับเหมากำหนดส่วนผสม ต้องระบุชั้นทุกชิ้นส่วน)
- ระบุกำลังอัดที่ต้องการในแต่ละขั้นก่อสร้าง เช่น ถอดแบบ/ค้ำยัน, ดึงลวด PT, ถอดแบบชิ้นส่วนสำเร็จ, ขนย้าย/ติดตั้ง

**ข้อกำหนด**
- ส่วนที่ LDP ไม่ได้ออกแบบ: ผู้รับเหมาเสนอกำลังที่ต้องการในแต่ละขั้นให้ตรวจ
- **Exposure F3 — ขีดจำกัด SCM (% โดยมวลของวัสดุประสานทั้งหมด, Table 26.4.2.2(b))** — นับ SCM ที่อยู่ใน blended cement ด้วย และใช้ขีดจำกัดเดี่ยวไม่ว่าจะมีกี่ชนิด

| SCM | สูงสุด |
|---|---|
| เถ้าลอย/pozzolan (C618) | 25% |
| Slag cement (C989) | 50% |
| Silica fume (C1240) | 10% |
| เถ้าลอย + silica fume รวม | 35% |
| เถ้าลอย + slag + silica fume รวม | 50% |

- **Exposure S — วัสดุประสานทางเลือก** ใช้ได้ถ้าการขยายตัวตาม ASTM C1012 ไม่เกิน (Table 26.4.2.2(c)):

| ชั้น | 6 เดือน | 12 เดือน | 18 เดือน |
|---|---|---|---|
| S1 | 0.10% | — | — |
| S2 | 0.05% | 0.10%* | — |
| S3 option 1 | — | — | 0.10% |
| S3 option 2 | 0.05% | 0.10%* | — |

\* ใช้เกณฑ์ 12 เดือนเฉพาะเมื่อ 6 เดือนเกินขีดจำกัด

- คอนกรีตสัมผัสน้ำ: ส่งหลักฐานว่ามวลรวมไม่ทำปฏิกิริยา alkali-silica (หรือมีมาตรการลด) และไม่ทำปฏิกิริยา alkali-carbonate
- **คลอไรด์**: แสดงความสอดคล้องได้ 2 ทาง
  - (1) คำนวณคลอไรด์รวมจากวัสดุตามสัดส่วนผสม (อนุรักษ์ — ย้ายจาก commentary มาเป็นตัวบทในฉบับ 2019)
  - (2) ทดสอบคลอไรด์ที่ละลายน้ำได้ของคอนกรีตแข็งตัวตาม ASTM C1218 ที่อายุ **28–42 วัน**
- คอนกรีตอัดแรง: **ห้ามสารผสมเพิ่มที่มีแคลเซียมคลอไรด์**
- เทบน/ชิดแบบเหล็กชุบสังกะสีที่ทิ้งไว้ถาวร: คลอไรด์ละลายน้ำได้ ≤ **0.30%** ของวัสดุประสาน (ถ้าชิ้นส่วนไม่ได้กำหนดเข้มกว่า)
- คอนกรีตมวลเบา: ยอมรับด้วยความหนาแน่นสด (ASTM C138) ที่สัมพันธ์กับความหนาแน่นสมดุล (C567)
- **คอนกรีตเส้นใยเหล็กรับเฉือน**: ตาม ASTM C1116 และมีเส้นใยข้ออ้อย **≥ 100 lb/yd³ (≈ 60 kg/m³)**

### 26.4.3 การออกแบบส่วนผสม

- ส่วนผสมต้อง (1) เทได้ไม่แยกตัวและหุ้มเหล็กเต็ม (2) ทนทานตามที่กำหนด (3) ผ่านเกณฑ์กำลังของตัวอย่างบ่มมาตรฐาน (4) ผ่านเกณฑ์ Ec ถ้ากำหนด
- **ทดสอบ Ec**: เฉลี่ยจากทรงกระบอก ≥ 3 ก้อนจากตัวอย่างเดียวกัน หล่อและบ่มในห้องปฏิบัติการ (C192) ทดสอบตาม C469 ที่ 28 วันหรืออายุที่กำหนด — ผ่านเมื่อค่าวัด ≥ ค่าที่กำหนด
- ออกแบบสัดส่วนตาม **ACI 301 Article 4.2.3** หรือวิธีอื่นที่ LDP ยอมรับซึ่งมีความน่าจะเป็นผ่านเกณฑ์ไม่น้อยกว่า — ประวัติกำลังที่ใช้ต้องไม่เก่ากว่า **24 เดือน**
  - ข้อกำหนดเชิงสถิติถูกตัดออกจาก Code ตั้งแต่ฉบับ 2014
- วัสดุที่ใช้ออกแบบส่วนผสมต้องตรงกับที่จะใช้จริง; หลายส่วนผสมต้องผ่านข้อกำหนดของตนเองทุกส่วนผสม
- Shotcrete: เทได้ไม่แยกตัว หุ้มเหล็ก ทนทาน และผ่านเกณฑ์กำลังของ shotcrete

### 26.4.4 เอกสารคุณสมบัติส่วนผสม

- ส่งให้ LDP ทบทวน **ก่อนใช้** และ **ก่อนเปลี่ยน** ส่วนผสม — หลักฐานคือผลกำลังต่อเนื่องของส่วนผสมเดียวกันจากโครงการก่อน หรือผล trial batch
- ไม่มีข้อมูลทดสอบ:
  - f′c ≤ **5000 psi (≈ 35 MPa)** ใช้ประสบการณ์/ข้อมูลอื่นได้ถ้า LDP อนุมัติ
  - f′c > 5000 psi ต้องมีผลทดสอบ
- ปรับส่วนผสมระหว่างงานได้ โดยส่งหลักฐานให้ LDP ก่อน
- Shotcrete ส่งเอกสารเช่นเดียวกัน

## 26.5 การผลิตและก่อสร้างคอนกรีต

### 26.5.1 การผลิต
- เก็บวัสดุประสาน/มวลรวมป้องกันเสื่อมสภาพหรือปนเปื้อน — วัสดุเสื่อม/ปนเปื้อนห้ามใช้
- อุปกรณ์ผสม/ขนส่ง และการชั่ง ผสม ส่ง ตาม **ASTM C94** (คอนกรีตผสมเสร็จ) หรือ **C685** (ผสมตามปริมาตร)

### 26.5.2 การเทและอัดแน่น
- กำจัดเศษวัสดุและน้ำแข็ง; กำจัดน้ำขังก่อนเท (เว้นแต่ใช้ tremie หรือได้รับอนุญาต)
- ⛔ ห้ามสูบคอนกรีตผ่านท่ออะลูมิเนียม
- เทในอัตราที่ส่งคอนกรีตได้พอ, workability พออัดแน่นได้, ไม่แยกตัว, ไม่หยุดนานจนเกิด cold joint, และวางใกล้ตำแหน่งสุดท้ายมากที่สุด
- คอนกรีตปนเปื้อนหรือหมด workability จนอัดแน่นไม่ได้ ห้ามใช้; เติมน้ำ (retemper) ได้ตาม C94 ถ้า LDP ไม่ห้าม
- เทต่อเนื่องจนจบแผงหรือช่วงตามรอยต่อที่กำหนด; อัดแน่นรอบเหล็ก สิ่งฝัง และมุมแบบ
- **Shotcrete**
  - ลอก rebound และ overspray ก่อนพ่นชั้นใหม่; ห้ามนำเศษตัดแต่ง/rebound กลับมาใช้
  - ผิวที่จะพ่นทับทำให้หยาบ amplitude ≈ **¼ in. (≈ 6 mm)** ก่อน final set
  - ก่อนพ่นทับผิวที่แข็งแล้ว: ลอก laitance ทำความสะอาดรอยต่อ และทำให้ผิวชื้น
  - ส่วนที่ย้อย หลุด แยกตัว เป็นโพรง ต้องรื้อทำใหม่
  - ผู้พ่น (nozzle operator) ต้องได้รับรอง; ถ้ากำหนด mockup panel ผู้พ่นทุกคนต้องผ่าน

### 26.5.3 การบ่ม

| คอนกรีต | อุณหภูมิ | ระยะเวลาชื้นอย่างน้อย |
|---|---|---|
| ปกติ | ≥ 50°F (10°C) | **7 วัน** แรก |
| High-early-strength | ≥ 50°F (10°C) | **3 วัน** แรก |

- **บ่มเร่ง** (ไอน้ำแรงดันสูง ไอน้ำปกติ ความร้อน+ความชื้น ฯลฯ) ได้ ถ้ากำลังถึงที่ต้องการในแต่ละขั้นและไม่ลดความทนทาน
- ถ้า LDP หรือเจ้าพนักงานกำหนด ให้ทำ **ทรงกระบอกบ่มหน้างาน** (6×12 in. ≥ 2 ก้อน หรือ 4×8 in. ≥ 3 ก้อน) จากตัวอย่างเดียวกับก้อนบ่มมาตรฐาน บ่มตาม C31 ทดสอบตาม C39
- **การบ่ม/ป้องกันถือว่าพอ** เมื่อ (1) กำลังเฉลี่ยก้อนบ่มหน้างาน ≥ **85%** ของก้อนบ่มมาตรฐานคู่กัน หรือ (2) เกิน f′c มากกว่า **500 psi (≈ 3.5 MPa)**
- **บ่ม shotcrete**
  - 24 ชม.แรก: ขังน้ำ/พ่นละออง/ฉีดน้ำต่อเนื่อง, คลุมวัสดุดูดน้ำที่ชื้นตลอด หรือสารเคลือบบ่ม
  - หลัง 24 ชม.: วิธีเดิม, แผ่นคลุม หรือวัสดุเก็บความชื้นที่ชื้นตลอด
  - บ่มรวม ≥ **7 วัน** (≥ **3 วัน** ถ้าใช้ปูนให้กำลังเร็วหรือสารเร่ง)

### 26.5.4–26.5.5 อากาศหนาว / อากาศร้อน
- ระบุขีดจำกัดอุณหภูมิคอนกรีตขณะส่งมอบ ทั้งอากาศหนาวและร้อน
- **หนาว**: มีอุปกรณ์อุ่นวัสดุและป้องกันคอนกรีต; ห้ามใช้วัสดุแข็งตัวหรือมีน้ำแข็ง; แบบ ไส้ และดินที่สัมผัสคอนกรีตต้องไม่มีน้ำค้างแข็ง
- **ร้อน**: เลือกวัสดุและวิธีผลิตให้อุณหภูมิตามกำหนด; ควบคุมการขนย้าย เท ป้องกัน และบ่ม เพื่อลดอุณหภูมิและการระเหยที่ลดกำลัง/ความทนทาน

### 26.5.6 รอยต่อ (construction / contraction / isolation)

**ข้อมูลที่ต้องระบุ**
- ตำแหน่งและรายละเอียดรอยต่อ (ถ้าการออกแบบต้องการ)
- รายละเอียดถ่ายแรงเฉือนผ่าน construction joint และการเตรียมผิว/ทำผิวหยาบ
- ตำแหน่งที่ถ่ายแรงเฉือนระหว่างเหล็กรูปพรรณกับคอนกรีตด้วย stud/เหล็กเชื่อม (เหล็กต้องสะอาด ไม่ทาสี)
- การเตรียมผิวชิ้นส่วนสำเร็จรูปที่จะเท topping แบบ composite
- รอยต่อ shotcrete ที่ยอมให้ตัดตรง

**ข้อกำหนด**
- รอยต่อที่ไม่ได้แสดงหรือต่างจากแบบ ส่งให้ LDP ทบทวน
- พื้น/คาน (ไม่อัดแรง): รอยต่อก่อสร้างอยู่ใน **1/3 กลางช่วง** เว้นแต่ LDP อนุมัติ
- รอยต่อในคาน girder ห่างจากผิวคานที่มาตัดอย่างน้อย **2 เท่าของความกว้างคานนั้น**
- ทำความสะอาด ลอก laitance, ทำผิวหยาบถ้ากำหนด, ทำให้เปียกและไล่น้ำขังก่อนเท
- Shotcrete: ตัดรอยต่อเอียง **45°** กับผิวสำเร็จ (เว้นแต่กำหนดตัดตรง); รอยต่อนอกแบบต้องขออนุมัติก่อนพ่น

### 26.5.7 การก่อสร้างชิ้นส่วน

**ข้อมูลที่ต้องระบุ**
- รายละเอียดรองรับการเปลี่ยนมิติจากอัดแรง คืบ หดตัว อุณหภูมิ
- ระบุ slab-on-ground ที่เป็น diaphragm หรือส่วนของระบบต้านแผ่นดินไหว
- ฐานรากลาด/ขั้นบันไดที่ทำงานเป็นหน่วยเดียว
- ตำแหน่งที่ต้องเทคอนกรีตพื้นและเสาให้เป็นเนื้อเดียว (§15.5 — คอนกรีตเสากำลังสูงกว่าพื้น)
- ตำแหน่งใช้คอนกรีตเส้นใยเหล็กรับเฉือน

**ข้อกำหนด**
- คาน/พื้นบนเสาหรือผนัง เทได้เมื่อคอนกรีตในเสา/ผนัง **ไม่เหลวแล้ว**
- คาน haunch drop panel shear cap capital เทเป็นเนื้อเดียวกับพื้น เว้นแต่แบบแสดงเป็นอย่างอื่น
- ตำแหน่งที่ต้องเทพื้นกับเสาร่วมกัน: คอนกรีตเสาต้องเต็มความลึกพื้นและยื่นเข้าไปในพื้น **≥ 2 ft (≈ 600 mm)** จากผิวเสา
- ⛔ ห้ามตัด (saw cut) หรือทำรอยต่อที่กระทบ slab-on-ground ที่เป็น diaphragm/ระบบต้านแผ่นดินไหว เว้นแต่ระบุหรือ LDP อนุมัติ

## 26.6 เหล็กเสริม

### 26.6.1 ทั่วไป

**ข้อมูลที่ต้องระบุ**
- มาตรฐาน ASTM และชั้นคุณภาพ (รวมข้อกำหนดพิเศษสำหรับระบบแผ่นดินไหวพิเศษ §20.2.2.5)
- ชนิด ขนาด ตำแหน่ง รายละเอียด และระยะฝัง
- ระยะหุ้มคอนกรีต
- ตำแหน่ง/ความยาวทาบ, ชนิด/ตำแหน่งการต่อทางกล end-bearing และการเชื่อม
- การเคลือบป้องกัน และการป้องกันสนิมของเหล็กที่ยื่นรอต่อในอนาคต

**ข้อกำหนด**
- ส่ง **mill test report**
- เหล็กมีสนิม/สะเก็ดรีดใช้ได้ ถ้าตัวอย่างที่ขัดด้วยแปรงลวดแล้วยังผ่านมิติขั้นต่ำ (รวมความสูงบั้ง) และน้ำหนักต่อความยาว
- ลวดอัดแรงต้องไม่มีสะเก็ดรีด หลุมสนิม หรือสนิมมาก (สนิมบาง ๆ ได้)
- ขณะเท เหล็กที่ต้องยึดเกาะต้องไม่มีน้ำแข็ง โคลน น้ำมัน หรือสารเคลือบที่ลดแรงยึดเกาะ

### 26.6.2 การวางเหล็ก — ค่าคลาดเคลื่อน

**Table 26.6.2.1(a) — d และระยะหุ้ม**

| d | คลาดเคลื่อน d | คลาดเคลื่อนระยะหุ้ม |
|---|---|---|
| ≤ 8 in. (≈ 200 mm) | ±3/8 in. (≈ 10 mm) | ค่าน้อยกว่าของ −3/8 in. และ −(1/3) ระยะหุ้มที่กำหนด |
| > 8 in. | ±1/2 in. (≈ 13 mm) | ค่าน้อยกว่าของ −1/2 in. และ −(1/3) ระยะหุ้มที่กำหนด |

- ระยะหุ้มถึงผิวท้องแบบ: −1/4 in. (≈ 6 mm)

**Table 26.6.2.1(b) — ตำแหน่งตามยาวของจุดดัดและปลายเหล็ก**

| ตำแหน่ง | คลาดเคลื่อน |
|---|---|
| ปลายไม่ต่อเนื่องของ bracket/corbel | ±1/2 in. |
| ปลายไม่ต่อเนื่องของชิ้นส่วนอื่น | ±1 in. (≈ 25 mm) |
| ตำแหน่งอื่น | ±2 in. (≈ 50 mm) |

- ระยะหุ้มยังต้องเป็นไปตาม Table (a) ที่ปลายไม่ต่อเนื่อง

**ระยะ hoop ในระบบแผ่นดินไหวปานกลาง/พิเศษ** (ใหม่ในฉบับ 2019)
- บวก: ไม่เกินค่าน้อยกว่าของ +1½ in. และ +1.5db ของเหล็กยืนเส้นเล็กสุด
- ลบ: ไม่เกินค่าน้อยกว่าของ −1 in. ต่อ ft ของด้านแคบสุดของชิ้นส่วน และ −3 in.
- การปรับระยะต้องไม่ทำให้ hoop ชิดกันเกิน 2 วง

**ข้อกำหนดการวาง**
- วางและยึดเหล็ก (รวมเหล็กมัดรวม) ไม่ให้เคลื่อนเกินค่าคลาดเคลื่อนขณะเท
- เกลียวเป็นเส้นต่อเนื่อง ระยะสม่ำเสมอ ไม่บิดเบี้ยว
- ต่อเหล็กเฉพาะที่แบบอนุญาตหรือ LDP อนุมัติ
- **ต่อแบบ end-bearing ของเหล็กยืนเสา**: ปลายตัดฉากสัมผัสกันตรงศูนย์; ปลายเรียบตั้งฉากแกนเหล็กภายใน **1.5°** และประกอบแล้วสัมผัสเต็มภายใน **3°**

### 26.6.3 การดัด
- ระบุรูปดัดที่ไม่ใช่มาตรฐาน
- ดัดเย็นก่อนวางเหล็ก (เว้นแต่ LDP อนุญาต)
- ⛔ ห้ามดัดเหล็กที่ฝังในคอนกรีตแล้วบางส่วนที่หน้างาน เว้นแต่แบบแสดงหรือ LDP อนุญาต
- เหล็กดัดหลบ (offset bar) ดัดก่อนวางในแบบ

### 26.6.4 การเชื่อม
- ระบุรายละเอียดเชื่อมเหล็กยึดที่หน้า bracket/corbel (§16.5.6.3)
- เชื่อมตาม **AWS D1.4**; เหล็กที่ไม่ใช่ ASTM A706 ต้องมี mill test report แสดงคุณสมบัติตาม D1.4 (ความเชื่อมได้)
- ⛔ ห้ามเชื่อมเหล็กไขว้เพื่อประกอบโครงเหล็ก ยกเว้นที่หน้า bracket/corbel หรือ LDP อนุญาต

## 26.7 Anchor ในคอนกรีต

**ข้อมูลที่ต้องระบุ**
- การประเมิน/รับรอง anchor ตาม §17.1.2
- ชนิด ขนาด ตำแหน่ง ระยะฝังประสิทธิผล และข้อกำหนดติดตั้ง
- เหล็ก anchor reinforcement (§17.5.2.1) และเหล็กโอบรัดสำหรับ anchor ที่หัวเสา/ตอม่อ (§10.7.6.1.5)
- Shear lug (§17.11) และรูบนแผ่นฐานไว้ตรวจและระบายอากาศเมื่อเทคอนกรีตหรือ grout
- ระยะขอบขั้นต่ำ (§17.9) และการป้องกันสนิมของ anchor ที่รอต่อในอนาคต
- **Post-installed**: หมวด anchor, กำลังคอนกรีต, ชนิดมวลรวม, ชนิดคอนกรีตมวลเบา, แรงบิดติดตั้ง, การเจาะและเตรียมรู
- **Adhesive (รับแรงดึง)**: ช่วงอุณหภูมิคอนกรีต, สภาพความชื้นขณะติดตั้ง, ชนิดคอนกรีตมวลเบา, การเจาะและเตรียมรู
- ระบุ adhesive anchor ที่ติดตั้งแนวนอนหรือเงยขึ้นเพื่อรับแรงดึงค้างนาน, anchor ที่ต้อง proof load, และใบรับรองผู้ติดตั้ง

**ข้อกำหนด**
- Cast-in anchor และเหล็กยึดต้องยึดแน่นในแบบตามทิศทางที่กำหนด และอัดแน่นคอนกรีตรอบ ๆ
- ตรวจการอัดแน่นรอบ shear lug ผ่านรูตรวจของแผ่นฐาน
- Post-installed ติดตั้งตามคำแนะนำผู้ผลิต (adhesive ตาม **MPII**) โดยผู้ติดตั้งที่มีคุณสมบัติ
- Adhesive anchor แนวนอน/เงยขึ้นที่รับแรงดึงค้างนาน: ผู้ติดตั้งต้อง **ได้รับรอง**
- Adhesive anchor ติดตั้งในคอนกรีตอายุ **≥ 21 วัน**

## 26.8 สิ่งฝังในคอนกรีต (embedments)

**ข้อมูลที่ต้องระบุ**
- ชนิด ขนาด รายละเอียด ตำแหน่งของสิ่งฝังที่ LDP ออกแบบ
- เหล็กเสริมตั้งฉากกับท่อฝัง
- ระยะหุ้มของท่อและข้อต่อ
- การป้องกันสนิมของสิ่งฝังที่จะต่อในอนาคต

**ข้อกำหนด**
- สิ่งฝังที่ไม่อยู่ในแบบ ส่งให้ LDP ทบทวน
- อะลูมิเนียมฝัง ต้องเคลือบ/หุ้มกันปฏิกิริยากับคอนกรีตและกัลวานิกกับเหล็ก
- ท่อที่ไม่อยู่ในแบบ ต้องออกแบบรับผลของวัสดุ แรงดัน อุณหภูมิ
- ⛔ ห้ามปล่อยของเหลว ก๊าซ ไอ (ยกเว้นน้ำ ≤ **90°F / 50 psi**) เข้าท่อ จนคอนกรีตได้กำลังตามกำหนด
- พื้นตัน: ท่อ (ยกเว้นระบบทำความร้อน/ละลายหิมะ) อยู่ระหว่างเหล็กบนและล่าง
- ท่อร้อยสายและท่อต่าง ๆ ต้องทำและติดตั้งโดยไม่ต้องตัด ดัด หรือย้ายเหล็กเสริม

## 26.9 คอนกรีตหล่อสำเร็จ

**ข้อมูลที่ต้องระบุ**
- ค่าคลาดเคลื่อนมิติชิ้นส่วนและส่วนที่ประกบกัน
- อุปกรณ์ยก สิ่งฝัง และเหล็กรับแรงชั่วคราวจากการยก เก็บ ขนส่ง ติดตั้ง (ถ้า LDP ออกแบบ)

**ข้อกำหนด**
- ทำเครื่องหมายตำแหน่ง ทิศทาง วันผลิต ให้ตรงกับแบบติดตั้ง
- ถ้า LDP ไม่ได้ออกแบบอุปกรณ์ยก ผู้ผลิตต้องจัดทำเอง
- ค้ำยันระหว่างติดตั้งจนรอยต่อถาวรเสร็จ
- **ฝังของขณะคอนกรีตยังเหลว** (ถ้า LDP อนุมัติ): ต้องยื่นออกมาหรือมองเห็นได้, ไม่ต้องผูกกับเหล็ก, ยึดตำแหน่งไว้ขณะคอนกรีตเหลว, และอัดแน่นรอบ ๆ

## 26.10 คอนกรีตอัดแรง

**ข้อมูลที่ต้องระบุ**
- ขนาดและตำแหน่งแรงอัด, ลำดับการดึงลวด
- ชนิด/รายละเอียด anchorage PT ที่ LDP เลือก
- ค่าคลาดเคลื่อนตำแหน่ง tendon/ท่อ (ตาม Table 26.6.2.1(a))
- การป้องกันสนิมของ tendon ข้อต่อ หัวยึด
- ข้อกำหนดท่อและการ grout tendon แบบยึดเกาะ (รวมคลอไรด์ §19.4.1)

**ข้อกำหนด**
- ระบบ anchorage ที่ไม่อยู่ในแบบ ส่งให้ LDP ทบทวน
- วาง/ยึด tendon และท่อไม่ให้เคลื่อนเกินค่าคลาดเคลื่อน
- Coupler อยู่ในตำแหน่งที่อนุมัติ และมีปลอกยาวพอให้เคลื่อนตัว
- ตัด/เชื่อมใกล้ลวดอัดแรง ห้ามให้โดนประกายไฟ กระแสลงดิน หรือความร้อนที่ทำให้คุณสมบัติเสื่อม
- **ตรวจแรงอัดและแรงเสียดทาน** ด้วย (1) ระยะยืดที่วัด เทียบกับระยะยืดที่คำนวณจาก E จริง และ (2) แรงดึงจากอุปกรณ์สอบเทียบ (เกจ load cell dynamometer)
  - ผลต่างเกิน **5%** (pretensioned) หรือ **7%** (post-tensioned) ต้องหาสาเหตุและแก้ไข
- แรงอัดที่หายไปจากลวดขาดที่ไม่ได้เปลี่ยน ≤ **2%** ของแรงอัดรวม (เว้นแต่ LDP อนุมัติ)
- ตัดลวดจากแท่นดึงด้วยไฟ: เลือกตำแหน่งและลำดับไม่ให้เกิดหน่วยแรงชั่วคราวไม่พึงประสงค์; ลวดยาวที่โผล่ ตัดใกล้ชิ้นส่วน
- **ห้ามดึงลวด PT** จนคอนกรีตมีกำลัง **≥ 2500 psi (≈ 17 MPa)** สำหรับ tendon เส้นเดี่ยวหรือเหล็กเส้น, **≥ 4000 psi (≈ 28 MPa)** สำหรับ multistrand
  - ยกเว้น: ใช้ anchorage ขนาดใหญ่ชดเชย หรือดึงไม่เกิน **50%** ของแรงสุดท้าย

## 26.11 แบบหล่อ

**ข้อมูลที่ต้องระบุ**
- ผู้รับเหมาเป็นผู้ออกแบบ ทำ ติดตั้ง และรื้อแบบ
- ตำแหน่งชิ้นส่วน composite ที่ต้องค้ำยัน และข้อกำหนดการรื้อค้ำยัน

**ข้อกำหนด**
- ออกแบบแบบหล่อคำนึงถึง
  - วิธีและอัตราการเท
  - น้ำหนักก่อสร้าง (แนวดิ่ง แนวราบ กระแทก)
  - ไม่ทำความเสียหายแก่ส่วนที่สร้างแล้ว
  - ชิ้นส่วน PT: เผื่อการเคลื่อนตัวขณะดึงลวด และการกระจายน้ำหนักบนแบบใหม่
- แบบได้รูปร่าง แนว มิติตามแบบ, แน่นไม่ให้น้ำปูนรั่ว, ค้ำ/ยึดให้คงรูป

**การรื้อแบบและค้ำยันซ้ำ (reshore)**
- ผู้รับเหมาจัดทำ **ขั้นตอนและกำหนดการรื้อแบบ/ค้ำยันซ้ำ** ก่อนเริ่มงาน พร้อมคำนวณน้ำหนักที่ถ่ายลงโครงสร้าง — ส่งผลวิเคราะห์และข้อกำหนดกำลังคอนกรีตให้ LDP และเจ้าพนักงานเมื่อขอ
- ห้ามวางน้ำหนักก่อสร้างหรือรื้อแบบ จนกว่าส่วนนั้น (รวมแบบที่เหลือ) **รับน้ำหนักตัวเองและน้ำหนักที่วางได้อย่างปลอดภัยโดยไม่เสียการใช้งาน**
  - พิสูจน์ด้วยการวิเคราะห์ (น้ำหนักที่คาด กำลังแบบ และกำลังคอนกรีตในที่) — กำลังในที่ประเมินจาก **ทรงกระบอกบ่มหน้างาน** หรือวิธีอื่นที่ LDP อนุมัติ
- รื้อแบบโดยไม่ลดความปลอดภัย; คอนกรีตที่เปิดผิวต้องแข็งแรงพอไม่เสียหาย
- ค้ำยันชิ้นส่วน PT รื้อได้เมื่อดึงลวดพอรับน้ำหนักตัวเองและน้ำหนักก่อสร้าง
- น้ำหนักก่อสร้างบนส่วนที่ไม่มีค้ำยัน ≤ SDL + LL (รวมการลด) เว้นแต่วิเคราะห์แล้วรับได้

## 26.12 การประเมินและยอมรับคอนกรีตที่แข็งตัว

### 26.12.1 ทั่วไป
- **ผลกำลังหนึ่งครั้ง (strength test)** = ค่าเฉลี่ยกำลังอัดของทรงกระบอก **6×12 in. ≥ 2 ก้อน** หรือ **4×8 in. ≥ 3 ก้อน**
  - ทำจากตัวอย่างเดียวกัน เก็บที่จุดส่งมอบ (C172), บ่มมาตรฐาน (C31), ทดสอบ (C39) ที่ 28 วันหรืออายุที่กำหนด
- **Shotcrete**: เฉลี่ยของ **แท่งเจาะ 3 in. ≥ 3 แท่ง** จากแผงทดสอบ (C1140) ที่ 28 วันหรืออายุที่กำหนด
- ห้องปฏิบัติการตาม ASTM C1077
- ช่างทดสอบหน้างาน (ทดสอบคอนกรีตสด ทำตัวอย่าง วัดอุณหภูมิ) และช่างห้องปฏิบัติการ **ต้องได้รับรอง**
- ส่งรายงานผลทุกฉบับให้ LDP ผู้รับเหมา ผู้ผลิตคอนกรีต (และเจ้าของ/เจ้าพนักงานถ้าขอ)

### 26.12.2 ความถี่ในการเก็บตัวอย่าง

ต่อส่วนผสมต่อวันที่เท เก็บอย่างน้อยค่ามากสุดของ

| เกณฑ์ | ความถี่ |
|---|---|
| ต่อวัน | ≥ 1 ครั้ง |
| ปริมาตร | ≥ 1 ครั้ง / **150 yd³ (≈ 115 m³)** |
| พื้น/ผนัง | ≥ 1 ครั้ง / **5000 ft² (≈ 465 m²)** ของพื้นที่ผิว |

- ทั้งโครงการได้ผล < 5 ครั้งสำหรับส่วนผสมหนึ่ง → เก็บจาก **≥ 5 รถ** ที่สุ่ม (หรือทุกรถถ้าน้อยกว่า 5)
- ส่วนผสมรวม < **50 yd³ (≈ 38 m³)** → ไม่ต้องทดสอบกำลัง ถ้าเจ้าพนักงานอนุมัติหลักฐานกำลังที่น่าพอใจ
- Shotcrete: แผงทดสอบต่อส่วนผสมต่อผู้พ่น อย่างน้อยวันละครั้ง หรือทุก **50 yd³** (เลือกที่ได้จำนวนแผงมากกว่า)

### 26.12.3 เกณฑ์ยอมรับ (ตัวอย่างบ่มมาตรฐาน)

ผ่านเมื่อ **ทั้งสองข้อ**
1. ค่าเฉลี่ยของผลกำลัง **3 ครั้งติดต่อกัน** ทุกชุด ≥ f′c
2. ไม่มีผลกำลังครั้งใดต่ำกว่า f′c เกิน
   - **500 psi (≈ 3.5 MPa)** เมื่อ f′c ≤ 5000 psi
   - **0.10f′c** เมื่อ f′c > 5000 psi

- ข้อใดไม่ผ่าน → ต้องปรับให้ผลถัดไปสูงขึ้น
- ข้อ 2 ไม่ผ่าน → ต้องสอบสวนตาม §26.12.6

### 26.12.4 เกณฑ์ยอมรับ shotcrete
- แผงทดสอบพ่นในทิศทางเดียวกันและโดยผู้พ่นคนเดียวกับงานจริง; แท่งเจาะทดสอบตาม C1604
- ผ่านเมื่อ (1) ค่าเฉลี่ยของแผง **3 แผงติดกัน** ≥ f′c และ (2) ค่าเฉลี่ย 3 แท่งจากแผงเดียว ≥ **0.85f′c** และไม่มีแท่งใด < **0.75f′c**
- ไม่ผ่านต้องปรับปรุง และสอบสวนเมื่อข้อ (2) ไม่ผ่าน

### 26.12.5 ความหนาแน่นคอนกรีตมวลเบา
- เก็บตัวอย่างด้วยความถี่ตาม §26.12.2 ที่จุดส่งมอบ ทดสอบตาม C138
- ยอมรับเมื่อความหนาแน่นสดอยู่ในช่วง **±4.0 lb/ft³ (≈ ±64 kg/m³)** ของค่าที่สอดคล้องกับความหนาแน่นสมดุลที่กำหนด (เว้นแต่ LDP อนุญาตอื่น)

### 26.12.6 การสอบสวนผลกำลังต่ำ
- ผลบ่มมาตรฐานต่ำกว่าเกณฑ์ หรือก้อนบ่มหน้างานแสดงว่าการบ่มบกพร่อง → ต้องดำเนินการให้มั่นใจว่าโครงสร้างยังปลอดภัย
- ยืนยันว่าคอนกรีตกำลังต่ำจริงและคำนวณแล้วกำลังโครงสร้างลดลงมาก → **เจาะแกน (core)** ตาม ASTM C42 ได้ — **3 แท่ง ต่อผลกำลังหนึ่งครั้งที่ไม่ผ่าน**
- LDP หรือเจ้าพนักงานปรับรายละเอียดการทดสอบตาม C42 ได้
- ปรับสภาพความชื้น: เก็บในถุงปิดสนิท ทดสอบระหว่าง **5 วัน หลังเปียกครั้งสุดท้าย** ถึง **7 วัน หลังเจาะ** (เว้นแต่อนุมัติอื่น)
- **คอนกรีตบริเวณนั้นถือว่าโครงสร้างใช้ได้** เมื่อ
  1. เฉลี่ย 3 แท่ง ≥ **0.85f′c**
  2. ไม่มีแท่งใด < **0.75f′c**
- ไม่ต้องปรับค่ากำลังแท่งเจาะตามอายุ
- เจาะเพิ่มได้ในตำแหน่งที่ผลกระจัดกระจาย
- ยังไม่ผ่านและยังสงสัยความปลอดภัย → ผู้มีอำนาจสั่ง **ประเมินกำลังตาม Ch.27** หรือดำเนินการอื่น

### 26.12.7 การยอมรับคอนกรีตเส้นใยเหล็ก (รับเฉือน)
1. ผ่านเกณฑ์กำลังอัดแบบบ่มมาตรฐาน
2. **Residual strength** จากการทดสอบดัด ASTM C1609 ที่การแอ่นกลางช่วง **L/300** ≥ ค่ามากกว่าของ **90%** ของกำลัง first-peak ที่วัดได้ และ **90%** ของกำลังที่ตรงกับ 7.5√f′c (psi)
3. ที่การแอ่น **L/150** ≥ ค่ามากกว่าของ **75%** ของ first-peak และ **75%** ของกำลังที่ตรงกับ 7.5√f′c

7.5√f′c (psi) ≈ 0.62√f′c (MPa) = modulus of rupture ตาม Eq. 19.2.3.1

## 26.13 การตรวจงาน

### 26.13.1 ทั่วไป
- ตรวจตามกฎหมายอาคาร และอย่างน้อยตาม §26.13 (ถ้าไม่มีกฎหมายอาคาร ใช้ Code นี้)
- **ผู้ตรวจ**: LDP ผู้ออกแบบ, ผู้ที่อยู่ภายใต้การกำกับของ LDP, หรือผู้ตรวจที่มีคุณสมบัติ — ผู้ตรวจงานแบบ เทคอนกรีต เหล็กเสริม สิ่งฝัง **ต้องได้รับรอง**
- **ชิ้นส่วนแผ่นดินไหวสำคัญ** (SMF, boundary element ของผนังพิเศษ, คานเชื่อม, diaphragm สำเร็จรูป SDC C–F ที่ใช้รอยต่อความเสียรูปปานกลาง/สูง) ตรวจโดย LDP, ผู้ที่อยู่ใต้การกำกับของ LDP ที่มีความสามารถ หรือผู้ตรวจที่ได้รับรอง — รอยต่อ diaphragm สำเร็จรูปตรวจตาม ACI 550.5
- การเชื่อมเหล็ก: ผู้ตรวจงานเชื่อมที่มีคุณสมบัติตาม AWS D1.4; เหล็กที่ไม่ใช่ A706 ต้องยืนยันความเชื่อมได้ด้วยเอกสาร
- Post-installed expansion/screw/undercut anchor: ผู้ตรวจที่ได้รับรอง หรือผู้มีคุณสมบัติที่ LDP และเจ้าพนักงานอนุมัติ
- **Adhesive anchor ทุกตัว**: ผู้ตรวจที่ได้รับรอง

### 26.13.2 รายงานการตรวจ
- บันทึกตลอดทุกขั้นงาน และ **เก็บอย่างน้อย 2 ปี** หลังโครงการเสร็จ
- ต้องมี
  - ความก้าวหน้าทั่วไป
  - น้ำหนักก่อสร้างสำคัญบนพื้น/ชิ้นส่วน/ผนังที่เสร็จแล้ว
  - วันเวลาผสม ปริมาณ ส่วนผสม ตำแหน่งที่เท และผลทดสอบคอนกรีตสด/แข็งตัวทุกส่วนผสม
  - อุณหภูมิคอนกรีตและการป้องกันขณะเท/บ่ม เมื่ออากาศ < **40°F (4°C)** หรือ > **95°F (35°C)**
  - การวางเหล็ก และการดึงลวด (บันทึกระยะยืดและแรงจากเกจที่สอบเทียบ)
- เหล็ก **A615 ในระบบแผ่นดินไหวพิเศษ**: ตรวจ mill test report ให้ตรงเอกสาร
- ยืนยันความเชื่อมได้ของเหล็กที่ไม่ใช่ A706 (ถ้าต้องเชื่อม)
- Post-installed และ adhesive anchor: ตรวจวัสดุและวิธีติดตั้งตามแบบและคำแนะนำผู้ผลิต (MPII) และผล proof load ถ้ากำหนด

### 26.13.3 รายการที่ต้องตรวจ (ถ้ากฎหมายอาคารไม่ได้กำหนดอื่น)

| ตรวจต่อเนื่อง (continuous) | ตรวจเป็นช่วง (periodic) |
|---|---|
| ส่วนผสมคอนกรีตก่อนเท ตรงกับตำแหน่งที่ใช้ | การวางเหล็ก สิ่งฝัง และ tendon PT |
| การดึงลวดอัดแรงและ grout tendon | การเชื่อมเหล็ก (นอกเหนือช่องซ้าย) |
| การวางเหล็ก **SMF, boundary element ผนังพิเศษ, คานเชื่อม** | วิธีและระยะเวลาบ่มของแต่ละชิ้นส่วน |
| การเชื่อมเหล็กในชิ้นส่วนกลุ่มเดียวกัน | การทำและรื้อแบบ/ค้ำยันซ้ำ |
| Post-installed anchor (ถ้าเงื่อนไขการรับรองกำหนด) และ adhesive แนวนอน/เงยที่รับแรงดึงค้างนาน | ลำดับติดตั้งและต่อชิ้นส่วนสำเร็จ |
| | ยืนยันกำลังในที่ก่อนดึงลวด PT และก่อนรื้อค้ำยัน/แบบของคานและพื้น |
| | การวาง cast-in anchor และเหล็ก anchor reinforcement (รวมค่าคลาดเคลื่อน) |
| | การติดตั้ง post-installed expansion/screw/undercut anchor และ adhesive anchor อื่น |
| | Proof load ของ anchor (ถ้ากำหนด) |
