# ACI 318-19 Chapter 27 — Strength Evaluation of Existing Structures (การประเมินกำลังโครงสร้างเดิม)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 559–565 (ฉบับ inch-pound) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm / kg" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ ไม่ใช่ค่าจากฉบับ 318M

## 27.1 ขอบเขต

- ใช้ประเมินกำลังของ **โครงสร้างที่มีอยู่แล้ว** ด้วยการวิเคราะห์ หรือด้วยการ **ทดสอบรับน้ำหนัก (load test)**
- กรณีที่ต้องประเมิน เช่น
  - วัสดุคุณภาพต่ำ เช่น ผลกำลังคอนกรีตไม่ผ่านตาม §26.12.6
  - มีหลักฐานว่าก่อสร้างผิด
  - เปลี่ยนการใช้งานอาคาร
  - โครงสร้างดูไม่เป็นไปตาม Code
- ไม่ครอบคลุม load test เพื่ออนุมัติวิธีออกแบบหรือก่อสร้างใหม่ (ระบบ/วัสดุทางเลือกดู §1.10)

## 27.2 ทั่วไป

- สงสัยความปลอดภัยและจะใช้งานต่อ → ต้องประเมินกำลังตามที่ LDP หรือเจ้าพนักงานกำหนด
- ถ้าจะใช้ load test ควรตกลงทุกฝ่ายก่อน: บริเวณที่ทดสอบ ขนาดน้ำหนัก ขั้นตอน และเกณฑ์ยอมรับ
- ถ้าปัญหาเป็นทั้งระบบ ทดสอบทุกชิ้นไม่ได้ → ทำแผนสอบสวนเฉพาะประเด็น

**เลือกวิธี**

| สถานการณ์ | วิธี |
|---|---|
| เข้าใจผลของจุดบกพร่องดี **และ** วัดมิติ/คุณสมบัติวัสดุได้ (เช่น แรงอัด แรงดัด หรือแรงอัดร่วมดัด) | **ประเมินด้วยการวิเคราะห์** (§27.3) |
| เข้าใจผลไม่ดี **หรือ** วัดข้อมูลที่ต้องใช้ไม่ได้ (มักเป็นปัญหาแรงเฉือนหรือแรงยึดเกาะ) | **ต้องทำ load test** (§27.4) — ควรมีการวิเคราะห์ประกอบ |

- **โครงสร้างเสื่อมสภาพ** ที่ผ่าน load test: ใช้งานต่อได้เฉพาะช่วงเวลาที่ LDP กำหนด และประเมินซ้ำเป็นระยะถ้าจำเป็น
  - กำหนดช่วงเวลาตามลักษณะการเสื่อม สภาพแวดล้อม/น้ำหนัก ประวัติการใช้งาน และขอบเขตการตรวจ
  - อาจจำกัด LL ระหว่างช่วงตรวจ
- ไม่ผ่านเกณฑ์ของ §27.3, §27.5 หรือ §27.6 → ใช้งานที่ **ระดับน้ำหนักต่ำลง (lower load rating)** ได้ ถ้าเจ้าพนักงานอนุมัติ
  - ยกเว้นชิ้นส่วนที่ **วิบัติขณะทดสอบ** ห้ามใช้งาน

## 27.3 ประเมินด้วยการวิเคราะห์

### 27.3.1 ตรวจสภาพจริง (as-built)
- **วัดมิติจริงที่หน้าตัดวิกฤต** (จุดที่หน่วยแรงสูงสุดจากโมเมนต์ แรงเฉือน แรงตามแกน รวมจุดเสื่อมสภาพเฉพาะที่)
- **ตำแหน่งและขนาดเหล็ก** หาจากการวัด
  - ใช้แบบเดิมได้ ถ้าสุ่มตรวจที่ตำแหน่งตัวแทนแล้วตรงกับแบบ
  - ใช้วิธีไม่ทำลาย (NDT) ได้; ถ้าผลสม่ำเสมอลดจำนวนจุดวัดได้
- **f′c เทียบเท่า** (ถ้าจำเป็น) ประเมินจาก
  - ผลทรงกระบอกตอนก่อสร้าง, แท่งเจาะจากโครงสร้าง หรือทั้งสองอย่าง
  - ข้อมูลต้องเป็นตัวแทนบริเวณที่สงสัย
  - วิธีทางสถิติดู ACI 214.4R — ไม่ใช้กับการสอบสวนผลกำลังต่ำของงานใหม่ (ใช้ §26.12)
- เจาะและทดสอบแท่งตาม **ASTM C42**
- คุณสมบัติเหล็ก: ใช้ผลทดสอบแรงดึงของตัวอย่างตัวแทนได้ (จำนวนขึ้นกับความสม่ำเสมอ ให้ LDP กำหนด)

### 27.3.2 ตัวคูณลดกำลัง

เมื่อได้มิติ เหล็ก และวัสดุจริงตาม §27.3.1 แล้ว **เพิ่ม φ ได้** (เพราะลดความไม่แน่นอน) แต่ไม่เกินค่าใน Table 27.3.2.1

| กำลัง | การจำแนก | เหล็กตามขวาง | φ สูงสุด |
|---|---|---|---|
| ดัด แรงตามแกน หรือร่วม | Tension-controlled | ทุกกรณี | **1.0** |
| | Compression-controlled | เกลียว (ตาม §10.7.6.3, §20.2.2, §25.7.3) | **0.9** |
| | | อื่น ๆ | **0.8** |
| เฉือน บิด หรือร่วม | | | **0.8** |
| แบกทาน (bearing) | | | **0.8** |

เทียบ φ ออกแบบ (Ch.21): 0.90 / 0.75 / 0.65 / 0.75 / 0.65

## 27.4 ประเมินด้วยการทดสอบรับน้ำหนัก

### 27.4.1–27.4.5 ทั่วไป
- ทดสอบแบบ **monotonic** (§27.5) หรือ **cyclic** (§27.6)
  - แนะนำ **monotonic** ถ้ากำลังอาจถูกจำกัดด้วยคอนกรีต แรงเฉือน หรือการยึดเหล็ก เพราะการคงน้ำหนักไว้นานทำให้รอยร้าว คืบ และการลื่นของเหล็กแสดงออกได้ดีกว่า
- ทดสอบอย่างปลอดภัยต่อชีวิตและโครงสร้าง โดยมาตรการความปลอดภัยต้องไม่รบกวนหรือกระทบผลทดสอบ
- ส่วนที่ทดสอบต้องมีอายุ **≥ 56 วัน** (ทดสอบเร็วกว่านี้ได้ถ้าเจ้าของ ผู้รับเหมา LDP และทุกฝ่ายตกลง)
- **ชิ้นส่วนสำเร็จรูปที่จะทำ composite** กับคอนกรีตหล่อในที่ ทดสอบดัดตัวเดียวได้ ถ้า
  - คำนวณแล้วชิ้นเดี่ยวไม่วิบัติจากแรงอัดหรือโก่งเดาะ
  - น้ำหนักทดสอบทำให้แรงในเหล็กรับแรงดึงเท่ากับเมื่อทดสอบชิ้นส่วน composite

### 27.4.6 การจัดน้ำหนักและตัวคูณ
- จัดน้ำหนักให้ **ผลสูงสุดในบริเวณวิกฤต** ของชิ้นส่วนที่ประเมิน และลดการแบ่งน้ำหนักไปชิ้นส่วนข้างเคียง (ถ้าวิเคราะห์แล้วชิ้นข้างเคียงช่วยรับ ให้เพิ่มน้ำหนักทดสอบชดเชย)
- **น้ำหนักทดสอบรวม Tt** (รวม DL ที่มีอยู่แล้ว) ≥ ค่ามากสุดของ

| สมการ | Tt |
|---|---|
| (27.4.6.2a) | 1.0Dw + 1.1Ds + 1.6L + 0.5(Lr หรือ S หรือ R) |
| (27.4.6.2b) | 1.0Dw + 1.1Ds + 1.0L + 1.6(Lr หรือ S หรือ R) |
| (27.4.6.2c) | 1.3(Dw + Ds) |

- **Dw** = น้ำหนักตัวเองของชิ้นส่วน
- **Ds** = น้ำหนักบรรทุกคงที่เพิ่มเติม (superimposed) — รวมโครงที่รองรับได้
- แยก DL เป็นสองส่วนเป็น **ของใหม่ในฉบับ 2019** ให้สอดคล้องกับ ACI 437.2
- ลด L ได้ตามกฎหมายอาคาร
- ตัวคูณ L ในสมการ (b) ลดเป็น **0.5** ได้ ยกเว้น
  - ที่จอดรถ
  - ที่ชุมนุมสาธารณะ
  - พื้นที่ L > **100 lb/ft² (≈ 4.8 kN/m², ≈ 490 kg/m²)**
- หน่วยน้ำหนักคอนกรีตปกติ: ใช้ **150 lb/ft³ (≈ 2,400 kg/m³)** ถ้าไม่มีเอกสารหรือผลทดสอบ
  - คอนกรีตชนิดอื่น เช่น มวลเบา ใช้ผลทดสอบหรือเอกสาร
- Dw อาจรวมน้ำหนัก topping ที่ยังไม่ได้เทในขณะทดสอบ

## 27.5 วิธีทดสอบแบบ monotonic

### 27.5.1 การวางน้ำหนัก
- วาง Tt อย่างน้อย **4 ขั้นเท่า ๆ กัน** (ควรตรวจหาความเสียหายทุกขั้น)
- น้ำหนักแผ่กระจายต้องกระจายจริง — **หลีกเลี่ยง arching** ของวัสดุถ่วง เช่น กองอิฐที่เกยกันทำให้น้ำหนักกลางช่วงลดลง
- คง Tt ไว้ **≥ 24 ชั่วโมง** หลังขั้นสุดท้าย (เว้นแต่เห็นสัญญาณวิบัติ) แล้วรื้อออกโดยเร็วหลังบันทึกผล

### 27.5.2 การวัดผล
- วัดการแอ่น ความเครียด การลื่น ความกว้างรอยร้าว ที่ตำแหน่งที่คาดว่าตอบสนองสูงสุด (วัดเพิ่มถ้าจำเป็น)
- ค่าเริ่มต้นวัดไม่เกิน **1 ชั่วโมง** ก่อนวางน้ำหนักขั้นแรก
- วัดหลังแต่ละขั้น และหลังคง Tt ครบ 24 ชั่วโมง
- วัดชุดสุดท้าย **24 ชั่วโมงหลังรื้อ** Tt

### 27.5.3 เกณฑ์ยอมรับ
- ไม่มี **กะเทาะ แตกบด** หรือหลักฐานวิบัติอื่น
  - กะเทาะเฉพาะที่จากการหล่อไม่สมบูรณ์ไม่จำเป็นต้องแปลว่าวิบัติ
  - **ชิ้นส่วนที่วิบัติห้ามทดสอบซ้ำ** และห้ามใช้งานแม้ที่ระดับน้ำหนักต่ำลง
- ไม่มี **รอยร้าวที่บ่งชี้การวิบัติจากแรงเฉือนใกล้เกิด**: รอยร้าวทแยงยาวจนภาพฉายแนวนอน ≈ ความลึกชิ้นส่วน และกว้างจนไม่มี aggregate interlock ร่วมกับปลอกเริ่มครากหรือหลุดยึด
- บริเวณ **ไม่มีเหล็กตามขวาง**: รอยร้าวทแยงที่ภาพฉายแนวนอน > ความลึกชิ้นส่วนต้องประเมิน
  - ชิ้นส่วนลึกไม่คงที่ ใช้ความลึกที่กึ่งกลางรอยร้าว
- บริเวณ **ฝังยึดและทาบเหล็ก**: รอยร้าวทแยงสั้น ๆ หรือรอยร้าวตามแนวเหล็กต้องประเมิน เพราะอาจเป็นสัญญาณวิบัติแบบเปราะ
- **การคืนตัวของการแอ่น**

| เกณฑ์ | สมการ |
|---|---|
| การแอ่นคงค้าง | **Δr ≤ Δ1/4** (27.5.3.5) |
| ยกเว้น | ถ้า Δ1 ≤ ค่ามากกว่าของ **0.05 in. (≈ 1.3 mm)** และ **ℓt/2000** ไม่ต้องตรวจ Δr (โครงสร้างแข็งมาก ความคลาดเคลื่อนการวัดใกล้ค่าการแอ่นจริง) |
| ทดสอบซ้ำ (ถ้า Δr ไม่ผ่าน) | เริ่มได้ไม่เร็วกว่า **72 ชั่วโมง** หลังรื้อน้ำหนักครั้งแรก → ผ่านเมื่อ **Δr ≤ Δ2/5** (27.5.3.8) |

- Δ1, Δ2 = การแอ่นสูงสุดในการทดสอบครั้งที่ 1, 2
- Δr = การแอ่นคงค้างหลังรื้อน้ำหนัก
- ℓt = ช่วงของชิ้นส่วนที่ทดสอบ
- ควรกำหนดเกณฑ์รอยร้าว (ชนิด ตำแหน่ง วิธีวัด ขีดจำกัด) ไว้ก่อนทดสอบ

## 27.6 วิธีทดสอบแบบ cyclic

- ใช้ตาม **ACI 437.2** ได้ — วางและปลดน้ำหนักซ้ำ ๆ โดยเพิ่มระดับขึ้นเรื่อย ๆ
- ประเมินจากการเบี่ยงเบนของกราฟน้ำหนัก-การเสียรูปจากพฤติกรรมเชิงเส้น การแอ่นคงค้างในแต่ละรอบ และการคืนตัวหลังทดสอบ
- เกณฑ์ยอมรับตาม ACI 437.2
- ไม่ผ่าน → **ทดสอบซ้ำได้** ตาม ACI 437.2 และ **ยกเว้น** ขีดจำกัดการแอ่นสูงสุด ℓt/180 ที่ห้ามทดสอบซ้ำใน ACI 437.2 (ให้สอดคล้องกับวิธี monotonic)

## Workflow ประเมินโครงสร้างเดิม (สรุป)

1. ระบุประเด็นที่สงสัย (วัสดุ ก่อสร้างผิด เปลี่ยนการใช้งาน เสื่อมสภาพ)
2. ประเด็นเป็นแรงดัด/แรงอัดที่วัดข้อมูลได้ → **วิเคราะห์**: วัดมิติ เหล็ก เจาะแกนหา f′c เทียบเท่า ทดสอบเหล็ก แล้วใช้ φ ตาม Table 27.3.2.1
3. ประเด็นเป็นแรงเฉือน/แรงยึดเกาะ หรือวัดข้อมูลไม่ได้ → **load test**: ตกลงเกณฑ์กับทุกฝ่าย อายุ ≥ 56 วัน คำนวณ Tt จัดน้ำหนักให้วิกฤต
4. Monotonic: 4 ขั้น คง 24 ชม. วัดก่อน/ระหว่าง/หลัง 24 ชม. → ตรวจความเสียหาย รอยร้าว และ Δr ≤ Δ1/4 (ไม่ผ่าน ทดสอบซ้ำหลัง 72 ชม. ใช้ Δr ≤ Δ2/5)
5. ไม่ผ่าน → ลด load rating (ถ้าเจ้าพนักงานอนุมัติและชิ้นส่วนไม่วิบัติ) หรือเสริมกำลัง
6. โครงสร้างเสื่อมสภาพ → กำหนดอายุการใช้งานต่อ และโปรแกรมตรวจเป็นระยะ

## สรุปค่าที่ใช้บ่อย

| เรื่อง | ค่า |
|---|---|

| อายุขั้นต่ำก่อน load test | 56 วัน |
