# ออกแบบ/ตรวจสอบคาน RC — ACI 318M-19

ผลลัพธ์ใช้ประกอบรายการคำนวณ วิศวกรผู้รับผิดชอบต้องตรวจและลงนามเอง

## กฎหลัก

1. **คำนวณด้วย `scripts/beam.py` เท่านั้น** ห้ามคำนวณในหัวหรือเขียนสูตรเองใหม่ — ถ้ากรณีที่ต้องการไม่มีในสคริปต์ ให้แจ้งว่าอยู่นอกขอบเขต
2. **ห้ามเดาค่าที่ไม่ได้ให้มา** (fy, fyt, cover, ℓn, ตำแหน่งคาน) ให้ถาม — ยกเว้นค่าเริ่มต้นที่ระบุในตารางอินพุต และต้องบอกผู้ใช้ว่าใช้ค่าเริ่มต้น
3. **หน่วย:** ksc → MPa คูณ 0.0980665 (SD40 = 4,000 ksc = 392.3 MPa **ไม่ใช่ 420**) ถ้าผู้ใช้ให้ MPa ใช้ `"units": "SI"`
4. รายงานต้องแยกสถานะแต่ละข้อ และ **ห้ามสรุปว่า "คานผ่านทุกข้อ"** ถ้ายังมีรายการ "ยังไม่ตรวจ"

## Workflow

1. **ตรวจขอบเขต** — คานสี่เหลี่ยม ไม่อัดแรง ไม่มีแรงตามแกน (Pu < 0.10f′cAg) ไม่มีแรงบิดที่ต้องคิด (Tu < φTth) ไม่ใช่ deep beam (ℓn > 4h และไม่มีแรงจุดภายใน 2h) ไม่อยู่ในระบบ SMF/ผนังพิเศษ — สคริปต์ตรวจให้ถ้าได้ข้อมูล และหยุดเมื่อเกิน
2. **รวบรวมอินพุต** → เขียนไฟล์ JSON (ดู `examples/beam_B1_kgfm.json`)
3. **รัน** `python3 scripts/beam.py input.json` → ได้รายงาน markdown
   - หลายหน้าตัด (ปลาย-ซ้าย / กลางช่วง / ปลาย-ขวา) → รันทีละหน้าตัด Mu เป็นลบที่ปลาย (เหล็กบน), บวกกลางช่วง (เหล็กล่าง)
   - ใช้ Vu ที่หน้าตัดวิกฤต: ที่ระยะ d จากผิวจุดรองรับได้เมื่อ (a) แรงปฏิกิริยาทำให้ปลายคานรับแรงอัด (b) น้ำหนักกระทำที่ผิวบน (c) ไม่มีแรงจุดระหว่างผิวจุดรองรับกับระยะ d (§9.4.3.2) — ไม่ครบให้ใช้ที่ผิวจุดรองรับ
4. **ตรวจผลก่อนส่ง:** ถ้ามี ❌ ให้เสนอทางแก้ (เพิ่มขนาดเหล็ก/หน้าตัด, เพิ่มขาปลอก, ลดระยะปลอก) แล้วรันใหม่
5. **ส่งรายงาน** + checklist การตัดเหล็ก/integrity ที่สคริปต์พิมพ์ออกมา — ถามตำแหน่งคาน (ริม/ภายใน) ถ้ายังไม่รู้
6. ถ้าผู้ใช้ต้องการเล่มคำนวณ → ส่งต่อให้ skill `structural-calc-book`

## สคริปต์ทำอะไรให้ (ทุกบรรทัดอ้างเลขข้อ)

- **แรงดัด** — strain compatibility + bisection หาแกนสะเทิน, เหล็กหลายชั้น, เหล็กอัดไม่บังคับคราก, หักคอนกรีตที่ถูกแทนที่เฉพาะเมื่อเหล็กอยู่ใน block; φ จาก εt; **εt ≥ εty + 0.003** แยกจากกำลัง; As,min; โหมดออกแบบหาจำนวนเหล็กน้อยสุด (singly ก่อน แล้วเพิ่มเหล็กอัด)
- **แรงเฉือน** — **fyt ≤ 420 MPa**; Vc ตาม Table 22.5.5.1 (a)/(b)/(c) พร้อม λs; เกณฑ์ปลอกขั้นต่ำ 0.083φλ√f′c·bw·d; Table 9.6.3.1; Av,min; ขนาดหน้าตัด §22.5.1.2; ระยะปลอก **ตามยาวและระยะขาตามขวาง** Table 9.7.6.2.2
- **รายละเอียด** — ระยะว่าง §25.2, คุมรอยร้าว Table 24.3.2, ปลอกยึดเหล็กอัด §9.7.6.4, เหล็กผิวข้าง h > 900 mm, Ktr เมื่อ fy ≥ 550, ความลึกขั้นต่ำ Table 9.3.1.1
- **ระยะฝังยึด/ทาบ** — ℓd (รวม ψg 1.15 สำหรับ SD50, ψt เหล็กบนอัตโนมัติ), ℓdh (ψr/ψo ค่าอนุรักษ์ ถ้ายืนยันการโอบรัดได้ให้ปรับเอง), ℓdc, ทาบ Class A/B, ทาบรับแรงอัด
- **Checklist** การตัดเหล็กและ structural integrity

## ไม่รองรับ (แจ้งผู้ใช้)

คาน T/L (ใช้ปีก), แรงบิด, แรงตามแกน, deep beam (Ch.23), คาน SMF/IMF (Ch.18), คานอัดแรง, ปลอกเอียง/เหล็กคอม้า, การกระจายโมเมนต์ใหม่, การคำนวณการแอ่นตัวละเอียด (§24.2)
