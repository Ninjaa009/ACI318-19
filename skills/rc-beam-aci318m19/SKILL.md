# ออกแบบ/ตรวจสอบคาน RC ตาม ACI 318M-19 (singly / doubly)

**Edition ที่ใช้:** ACI 318M-19 (ฉบับ Reapproved 2022 เนื้อหาทางเทคนิคเหมือน 318-19 — ดู §10)
**ผู้ใช้ skill นี้:** วิศวกรโครงสร้าง ผลลัพธ์ใช้เป็นข้อมูลประกอบแผ่นคำนวณ ต้องมีวิศวกรผู้รับผิดชอบตรวจและลงนามเอง

## 1. Workflow

1. **ตรวจขอบเขต (§2)** — ถ้าเกิน ให้แจ้งและหยุด ไม่ใช้สูตรพื้นฐานต่อโดยอัตโนมัติ
2. **รวบรวมอินพุต (§3)** — ถามสิ่งที่ขาด: b, h, f′c, fy, fyt, cover, ขนาดปลอก, ขนาดเหล็กหลัก/เหล็กอัด, Mu (พร้อมเครื่องหมาย), Vu, โหมด (ออกแบบ/ตรวจสอบ), สภาพแวดล้อมของ cover (Table 20.5.1.3.1)
3. **แปลงหน่วยเป็น MPa–mm–N** (ห้ามแทน ksc หรือ m ลงสูตร MPa–mm โดยตรง)
4. **ระบุด้านอัด/ด้านดึง** จากเครื่องหมายโมเมนต์ (Mu > 0 → ดึงด้านล่าง, Mu < 0 → ดึงด้านบน) พิกัด y วัดลงจากผิวรับแรงอัด
5. **แรงดัด** — โหมดออกแบบ: ลอง singly ก่อน ถ้าไม่ผ่านให้ doubly; โหมดตรวจสอบ: วิเคราะห์หน้าตัดที่กำหนด (§5)
6. **คำนวณ d, dt, d′ ใหม่จากเหล็กที่เลือกจริง** แล้วตรวจสมดุล, φMn, strain ซ้ำ
7. **แรงเฉือน** (§6) → **detailing** (§7) → **รายงานสถานะ** (§9)
8. รัน `scripts/beam.py` (ฟังก์ชัน `design_flexure`, `analyze`, `design_stirrups`, `check_stirrups`) แทนการคำนวณมือ แล้วเทียบกับสูตรปิดใน §5 เสมอ

## 2. ขอบเขต

รองรับ: คานหน้าตัดสี่เหลี่ยม ไม่อัดแรง ไม่มีแรงตามแกนหรือแรงบิด ไม่ใช่ deep beam ไม่ต้องใช้ข้อกำหนดแผ่นดินไหวเพิ่มเติม
**ยังไม่รองรับ:** T/L-beam (ระดับถัดไป), แรงบิด, แรงตามแกน, คานต่อเนื่องที่ต้อง redistribute, deep beam (Ch. 23), SMF/IMF (Ch. 18), ปลอกเฉียง/เหล็กงอรับเฉือน, lightweight (λ ≠ 1 รองรับเฉพาะผ่านพารามิเตอร์ `lam` แต่ยังไม่ได้ทดสอบ)

## 4. Strain limit และ φ

- **§9.3.3.1:** คานต้อง tension-controlled: **εt ≥ εty + 0.003** (ไม่ใช้ εt ≥ 0.004 เป็นเกณฑ์ผ่านของฉบับ 2019)
- εty = fy/Es, Es = 200,000 MPa (§20.2.2.2); fy = 420 MPa → εty = 0.0021, เกณฑ์ = 0.0051, **cmax = 0.37037·dt**
- **ข้อยกเว้น Grade 420 (§21.2.2.1):** ใช้ εty = 0.002 → เกณฑ์ 0.005, cmax = 0.375·dt เลือกได้เฉพาะ fy = 420 MPa และต้องระบุในรายงาน **ห้ามผสมสองวิธี** ไม่เปลี่ยนกฎ fs = Esεs
- cmax = 0.003·dt / (0.003 + εty + 0.003)
- **dt** = ระยะถึงเหล็กดึงชั้นนอกสุด (ใช้หา εt และ cmax); **d** = ระยะถึงจุดศูนย์ถ่วงเหล็กดึง (ใช้หา Mn ด้วยสูตรสมดุล, ρw, Vc) ต้องแยกกันเมื่อมีหลายชั้น
- φ (Table 21.2.2, ปลอกธรรมดา): εt ≥ εty+0.003 → 0.90; εty < εt < εty+0.003 → 0.65 + 0.25(εt − εty)/0.003; εt ≤ εty → 0.65
- ช่วง transition ใช้แสดงผลได้ แต่ **ห้ามสรุปว่าผ่าน strain limit เพียงเพราะลด φ แล้วกำลังเพียงพอ** ให้รายงาน "Strain limit: ไม่ผ่าน" แยกจากกำลังดัด

## 5. แรงดัด (singly / doubly)

**สมมติฐาน (ระบุในรายงานว่าเป็นข้อกำหนดโดยตรง):** สมดุลและ strain compatibility §22.2.1.1–22.2.1.2; εcu = 0.003 และไม่คิดแรงดึงคอนกรีต §22.2.2.1–22.2.2.2; stress block 0.85f′c, a = β1c §22.2.2.4.1–22.2.2.4.3 (β1 = 0.85 เมื่อ f′c ≤ 28 MPa, ลด 0.05 ต่อ 7 MPa, ต่ำสุด 0.65); fs = Esε ไม่เกิน ±fy §20.2.2.1

**สูตร (อนุมานจากสมดุล):**
- Singly (เหล็กดึงคราก): a = Asfy/(0.85f′c·b), Mn = Asfy(d − a/2); ออกแบบ: a = d − √(d² − 2Mu/(φ·0.85f′c·b)), As = 0.85f′c·b·a/fy ถ้าไม่ผ่าน tension-controlled → เพิ่มหน้าตัดหรือใช้ doubly แล้วตรวจใหม่
- Doubly:
  - **ห้ามสมมติว่าเหล็กอัดครากเสมอ** คำนวณ ε′s = 0.003(c − d′)/c, f′s = ±min(Es|ε′s|, fy)
  - เหล็กอัดอยู่ใน stress block (d′ ≤ a): Cs = A′s(f′s − 0.85f′c)
  - **a < d′ < c:** เหล็กยังรับแรงอัด แต่ **ไม่หักคอนกรีตที่ถูกแทนที่** (Cs = A′s·f′s)
  - d′ > c: เหล็กนั้นรับแรงดึง (solver รองรับเครื่องหมาย)
  - สูตรแยก Mn = Mn1 + Mn2 (ที่ c = cmax: A′s = (Mn,req − Mn1)/[(f′s − 0.85f′c)(d − d′)], As = (Cc + A′s(f′s − 0.85f′c))/fy) ใช้เป็นค่าประมาณเริ่มต้น/ตรวจเทียบเท่านั้น และใช้ได้เมื่อสมมติฐานครบ (เหล็กดึงคราก, เหล็กอัดอยู่ใน block)
- **โหมดตรวจสอบ:** หารากของสมดุลแรง ΣF(c) = 0 (bisection) โดยคำนวณ strain/stress ของเหล็กทุกชั้นทุกครั้งที่ลองค่า c ไม่บังคับสมการกำลังสองทุกกรณี

## 6. แรงเฉือน

- Critical section ที่ d จากผิวรองรับใช้ได้เมื่อครบเงื่อนไข §9.4.3.2 เท่านั้น (ถามผู้ใช้/ระบุสมมติฐาน)
- **Vc ตาม Table 22.5.5.1 เลือกจากปลอกที่จัดให้จริง** (ρw = As/(bw·d), √f′c ≤ 8.3 MPa §22.5.3.1)
  - Av/s ≥ Av,min/s: (a) 0.17λ√f′c·bw·d หรือ (b) 0.66λρw^(1/3)√f′c·bw·d เลือกได้ (ค่าเริ่มต้นของ solver = (a) และรายงานค่า (b) ควบคู่)
  - Av/s < Av,min/s (รวมไม่มีปลอก): (c) 0.66λsλρw^(1/3)√f′c·bw·d, λs = √(2/(1 + d/250)) ≤ 1 (d เป็น mm)
  - §22.5.5.1.3 คือข้อกำหนด λs ไม่ใช่สมการ Vc; ตรวจเพดาน Vc ≤ 0.42λ√f′c·bw·d (§22.5.5.1.1–1.2)
  - **ห้ามตั้ง Av,min = 0** เพราะแรงเฉือนต่ำ และ **ห้ามสรุปว่า "Vc แบบง่ายอนุรักษ์นิยมกว่าเสมอ"** (ค่าจาก (a),(b),(c) สูง/ต่ำกว่ากันได้) รายงานต้องแสดงสมการที่เลือกและเหตุผล
- **ต้องมีปลอกขั้นต่ำเมื่อ** Vu > 0.083φλ√f′c·bw·d (§9.6.3.1; ตรวจข้อยกเว้น Table 9.6.3.1 เอง — solver รับ `exempt_9631`) ไม่ใช้ 0.5φVc
- **Av,min/s = max[0.062√f′c·bw/fyt, 0.35bw/fyt]** — Table 9.6.3.4 (ไม่ใช่ 9.6.3.3)
- **ขนาดหน้าตัด §22.5.1.2:** Vu ≤ φ(Vc + 0.66√f′c·bw·d) (MPa–mm–N) ถ้าแสดงเป็น Vs ให้ระบุว่า **Vs,required = Vu/φ − Vc** ไม่ใช่กำลังจากปลอกที่จัดให้ (Vs,provided)
- Vs = Av·fyt·d/s §22.5.8.5.3 (ปลอกตั้งฉาก, Av รวมขาปลอกที่มีผล); φ = 0.75 (Table 21.2.1); φVn ≥ Vu §9.5.1.1(b)
- ระยะปลอก Table 9.7.6.2.2: ตามยาวและตามขวาง (ระยะขาปลอก) — โค้ดใน `design_stirrups` ใช้ Vs,req ≤ 0.33√f′c·bw·d → min(d/2, 600) ตามยาว มิฉะนั้น min(d/4, 300); **ค่าตามขวางและขอบ 0.33 ต้องเทียบกับตารางจริง (ยังไม่ได้ยืนยัน)**

## 9. รูปแบบรายงานและสถานะผลตรวจ

เรียงขั้นตอน แสดงสูตร → แทนค่า (หน่วยภายใน MPa–mm) → ผล (แปลงกลับ kgf–m, cm²) พร้อมเลขข้อทุกบรรทัด และแยกสถานะอย่างน้อย:

| รายการ | สถานะ |
|---|---|
| กำลังดัด (φMn ≥ Mu) | ผ่าน / ไม่ผ่าน |
| Strain limit (εt ≥ εty + 0.003) | ผ่าน / ไม่ผ่าน (แยกจากกำลังดัด) |
| กำลังเฉือน + §22.5.1.2 | ผ่าน / ไม่ผ่าน |
| เหล็กขั้นต่ำและ detailing | ผ่าน / ไม่ผ่าน / **ยังไม่ตรวจ** (รายข้อ) |
| Deflection | **ยังไม่ตรวจ** เว้นแต่ตรวจแล้วจริง |
| Development / anchorage | **ยังไม่ตรวจ** (Ch. 25) |

รายการใดไม่ได้ตรวจให้เขียน "ยังไม่ตรวจ" และ **ห้ามสรุปว่าออกแบบคานผ่านครบทุกข้อ** ท้ายรายงานระบุ: edition, สมมติฐาน (εty mode, critical section ที่ d หรือไม่), ขอบเขตที่ไม่รองรับ
