**Checklist การตัดเหล็กและ integrity (ต้องระบุในแบบ)**
- [ ] เหล็กยื่นเลยจุดที่ไม่ต้องใช้ ≥ max(d, 12db); เหล็กต่อเนื่องฝัง ≥ ℓd เลยจุดตัด (§9.7.3.3–9.7.3.4)
- [ ] เหล็กบวก ≥ 1/3 (ช่วงเดียว) / ≥ 1/4 (ต่อเนื่อง) เข้าจุดรองรับ ≥ 150 mm (§9.7.3.8.2)
- [ ] เหล็กลบ ≥ 1/3 เลยจุดดัดกลับ ≥ max(d, 12db, ℓn/16) (§9.7.3.8.4)
- [ ] Integrity: คานริม → เหล็กบวก ≥ max(1/4, 2 เส้น) + เหล็กลบ ≥ max(1/6, 2 เส้น) ในปลอกปิด; คานอื่น → เหล็กบวก ≥ max(1/4, 2 เส้น) หรือปลอกปิด (§9.7.7)
- [ ] ต่อเหล็ก integrity: เหล็กบวกที่/ใกล้จุดรองรับ, เหล็กลบที่/ใกล้กลางช่วง, ทาบ Class B หรือต่อกล ≥ 1.25fy (§9.7.7.5)
