## 20.1 ขอบเขต

- เหล็กเสริม: คุณสมบัติวัสดุ, คุณสมบัติที่ใช้ออกแบบ, ความทนทาน (รวมระยะหุ้มขั้นต่ำ)

### 20.2.2.5 เหล็กในระบบแผ่นดินไหวพิเศษ (SDC C–F)

เหล็กยืนที่รับโมเมนต์/แรงตามแกนจากแผ่นดินไหวในระบบพิเศษ และ anchor reinforcement:
- **(a) ASTM A706:** Grade 60, 80, 100 สำหรับผนังพิเศษ; Grade 60, 80 สำหรับ SMF
- **(b) ASTM A615 Grade 60** ถ้าครบทุกข้อ:
  - (i) fy จริงจาก mill test **เกินค่าระบุไม่เกิน 18,000 psi**
  - (ii) **fu จริง / fy จริง ≥ 1.25**
  - (iii) การยืดตัวที่ขาด (ใน 8 in.) ≥ 14% (No.3–6), ≥ 12% (No.7–11), ≥ 10% (No.14, 18)
  - (iv) uniform elongation ≥ 9% (No.3–10), ≥ 6% (No.11, 14, 18)
- ⛔ **A615 Grade 80 และ 100 ห้ามใช้ในระบบแผ่นดินไหวพิเศษ** (ข้อกังวลด้าน low-cycle fatigue)
- เหตุผล: fy จริงสูงกว่าที่ออกแบบมาก → แรงเฉือนและแรงยึดเกาะสูงขึ้นจนวิบัติแบบเปราะ; fu/fy สูงช่วยให้ช่วงครากยาวขึ้น (มีความสามารถหมุนตัวแบบไม่ยืดหยุ่น)

**fps — ลวดยึดเกาะ (20.3.2.3)** — ใช้แทนการคำนวณ strain compatibility ได้ ถ้าลวดอัดแรงทั้งหมดอยู่ในโซนรับแรงดึง และ **fse ≥ 0.5fpu**:

$$f_{ps} = f_{pu}\left\{1 - \frac{\gamma_p}{\beta_1}\left[\rho_p\frac{f_{pu}}{f'_c} + \frac{d}{d_p}\frac{f_y}{f'_c}(\rho - \rho')\right]\right\}$$

**Table 20.3.2.3.1 — γp**

| fpy/fpu | γp | ชนิดลวด (commentary) |
|---|---|---|
| ≥ 0.80 | 0.55 | A722 Type II (ข้ออ้อย) |
| ≥ 0.85 | 0.40 | A722 Type I (กลม), stress-relieved strand/wire |
| ≥ 0.90 | 0.28 | low-relaxation strand/wire |

- ถ้า d′ > 0.15dp → ไม่นับเหล็กรับแรงอัด
- ถ้านับเหล็กรับแรงอัด: พจน์ในวงเล็บ [ ] ต้อง ≥ 0.17
- pretensioned ภายในระยะ ℓd จากปลายลวด: fps ≤ ค่าตาม §25.4.8.3

**fps — ลวดไม่ยึดเกาะ (Table 20.3.2.4.1)** — ใช้ได้ถ้า fse ≥ 0.5fpu:

- แนวทาง: ACI 423.10R, PTI Post-Tensioning Manual — การประเมินการสูญเสียเกินจริงก็เสียหายพอ ๆ กับประเมินต่ำ (camber และการเคลื่อนตัวมากเกิน)

## 20.4 Headed shear stud reinforcement

- ชุด stud ตาม **ASTM A1044** (หัวมีพื้นที่ ≥ 10 เท่าของก้าน; fy ขั้นต่ำ 51,000 psi)
- stud ตาม AWS D1.1 (หัวเล็กกว่า ~2.5–4 เท่า) **ใช้เป็นเหล็กรับแรงเฉือนไม่ได้**

### 20.5.1.4 สภาพแวดล้อมกัดกร่อน

- เพิ่มระยะหุ้มตามความเหมาะสม และผ่านข้อกำหนด exposure category ตาม §19.3 หรือใช้การป้องกันอื่น
- commentary แนะนำ (คลอไรด์จากภายนอก): ระยะหุ้ม **≥ 2 in.** (ผนัง, พื้น) และ **≥ 2½ in.** (ชิ้นส่วนอื่น); precast ในโรงงาน **≥ 1½ in.** (ผนัง, พื้น) และ **≥ 2 in.** (อื่น ๆ)
- **คอนกรีตอัดแรง Class T หรือ C** (§24.5.2) ในสภาพกัดกร่อน: ระยะหุ้มลวดอัดแรง **≥ 1.5 เท่า** ของค่าใน Table 20.5.1.3.2 / 20.5.1.3.3 — ยกเว้นโซนรับแรงอัดล่วงหน้าไม่รับแรงดึงภายใต้น้ำหนักค้าง
