## แรงดัด

- บล็อกหน่วยแรง 0.85f′c ลึก a = β1c (22.2.2.4)
- fs = Es·εs ≤ fy (20.2.2.1); เหล็กอัดใน block: A′s(f′s − 0.85f′c); นอก block (a < y < c): A′s·f′s
- As,min = max(0.25√f′c/fy, 1.4/fy)·bw·d, fy ≤ 550 (9.6.1.2); ยกเว้นถ้า As ≥ 4/3 ที่ต้องการ (9.6.1.3)
