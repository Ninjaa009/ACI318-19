# ออกแบบ/ตรวจสอบเสา RC — ACI 318M-19

ผลลัพธ์ใช้ประกอบรายการคำนวณ วิศวกรผู้รับผิดชอบต้องตรวจและลงนามเอง

## กฎหลัก

1. **คำนวณด้วย `scripts/column.py` เท่านั้น** ห้ามคำนวณในหัว ห้ามใช้ Bresler/สูตรประมาณแทน 3D interaction — กรณีที่ไม่มีในสคริปต์ให้แจ้งว่าอยู่นอกขอบเขต
2. **ห้ามเดาค่าที่ไม่ได้ให้มา** (fy, cover, ℓu, ทิศการดัด, ข้อมูลชั้น) ให้ถาม — ยกเว้นค่าเริ่มต้นในตารางอินพุต และต้องบอกผู้ใช้ว่าใช้ค่าเริ่มต้น
3. **หน่วย:** ksc → MPa คูณ 0.0980665 (SD40 = 392.3 MPa **ไม่ใช่ 420**) ถ้าผู้ใช้ให้ MPa ใช้ `"units": "SI"`
4. **แกน:** `Mx` = โมเมนต์รอบแกน x ทำให้ด้าน h รับแรงดัด (ความลึก h); `My` รอบแกน y (ความลึก b) · `Vuy` แรงเฉือนทิศ y (คู่กับ Mx), `Vux` ทิศ x (คู่กับ My) — ถ้าดึงจาก STAAD ให้ยืนยัน local axis กับผู้ใช้ก่อน
5. **ห้ามสรุปว่า "เสาผ่านทุกข้อ"** ถ้ายังมีรายการ "ยังไม่ตรวจ" (sway เมื่อไม่มีข้อมูลชั้น, รอยต่อคาน-เสา, ฐานราก)

## Workflow

1. **ตรวจขอบเขต** — เสาสี่เหลี่ยม tied, ไม่อัดแรง, frame **non-sway** (Q ≤ 0.05 ถ้ามีข้อมูลชั้น), ไม่ใช่ SMF/IMF — สคริปต์หยุดเมื่อ Q > 0.05 หรือ `system` = SMF/IMF
2. **รวบรวมอินพุต** → JSON (ดู `examples/column_S1_SI.json`) ใส่ทุก load combination ที่วิกฤต: Pu สูงสุด, Mx สูงสุด, My สูงสุด, Pu ต่ำสุด
   - ต้องมีโมเมนต์ **ทั้งปลายบนและปลายล่าง** พร้อม `Vux`/`Vuy` และ `L` (ระยะ c/c ชิ้นส่วน) เพื่อแยกโค้งทางเดียว/สองทางจาก |V|·L ถ้าไม่มี V ให้ถามผู้ใช้หรือใส่ `curv_x`/`curv_y` = `single`/`double`
   - ถ้าไม่มีข้อมูลชั้น (ΣPu, Δo, Vus, lc) สคริปต์สมมติ non-sway และรายงานว่า "ยังไม่ตรวจ" — ต้องบอกผู้ใช้
3. **รัน** `python3 scripts/column.py input.json` → รายงาน markdown
4. **ตรวจผลก่อนส่ง:** ถ้ามี ❌ ให้เสนอทางแก้ (เพิ่มเหล็ก/หน้าตัด, ลดระยะปลอก, เพิ่ม crosstie) แล้วรันใหม่ · ถ้า δ สูงหรือไม่เสถียร (Pu ≥ 0.75Pc) แนะนำเพิ่มหน้าตัดก่อนเพิ่มเหล็ก
5. **ส่งรายงาน** พร้อมระยะทาบ และย้ำรายการ "ยังไม่ตรวจ"
6. ถ้าผู้ใช้ต้องการเล่มคำนวณ → ส่งต่อให้ skill `structural-calc-book`

## สคริปต์ทำอะไรให้ (อ้างเลขข้อในรายงาน)

- **แรงอัดสูงสุด** φPn,max = 0.65·0.80·Po, fy ≤ 550 (§22.4.2)
- **Sway** Q = ΣPuΔo/(Vus·lc) ≤ 0.05 (§6.6.4.3)
- **ความชะลูด** kℓu/r เทียบ min(34 + 12M1/M2, 40); ทิศการดัดจาก |V|·L; M1 = M2 = 0 → เกณฑ์ 22; (EI)eff, Pc, Cm, δ ≥ 1, M2,min = Pu(15 + 0.03h) กับ Cm = 1, ไม่เสถียรเมื่อ Pu ≥ 0.75Pc, Mc ≤ 1.4M (§6.2.5, §6.6.4.4–6.6.4.6)
- **3D interaction** strain compatibility หน้าตัดจริงทุกเส้น, บล็อกหน่วยแรงตัดเป็นรูปหลายเหลี่ยมตามมุมแกนสะเทิน, หามุมที่ทิศโมเมนต์ความจุตรงทิศโหลดที่ Pu เดียวกัน, ตรวจปลายบน ปลายล่าง และกลางเสา (โมเมนต์ขยาย) · φ จาก εt (tied)
- **แรงเฉือน** ทั้งสองทิศ, Nu/6Ag ≤ 0.05f′c (แรงดึงใช้ค่าลบ), Vc (a)/(c) ตาม Av ≥ Av,min, Vc,max, **fyt ≤ 420**, Av,min เมื่อ Vu > 0.5φVc, s ≤ d/2 หรือ d/4 เมื่อต้องมีเหล็กเฉือน, แรงเฉือนสองทิศ §22.5.1.11, §18.3.3 ใช้ Mn **ไม่คูณ φ**
- **รายละเอียด** ρg 1–8%, ≥ 4 เส้น, ระยะว่าง §25.2.3, ขนาดปลอก/ระยะปลอก §25.7.2.1–2, crosstie §25.7.2.3 (ระยะว่าง 150 mm + เว้นเส้น), Ktr เมื่อ fy ≥ 550
- **ต่อทาบ** ทาบรับแรงอัด (ลด 0.83 เมื่อปลอกพอ), ทาบรับแรงดึง Class B, ψg สำหรับ SD50 (§10.7.5, Ch.25)

## ไม่รองรับ (แจ้งผู้ใช้)

เสากลม/ปลอกเกลียว, หน้าตัดรูปตัว L/T, เหล็กไม่สมมาตรหรือคนละขนาดในหน้าตัด, sway frame (δs), SMF/IMF (Ch.18), เสาอัดแรง, คอนกรีตมวลเบา, รอยต่อคาน-เสา (Ch.15), แรงบิด, ระยะ hook/ทาบที่ฐานราก (ใช้ rc-beam ส่วน Ch.25 หรือคำนวณแยก)

## ข้อจำกัดของความถูกต้อง

ค่าคงที่ SI ทั้งหมดตรวจแล้วว่าตรงกับการแปลงหน่วยของค่า inch-pound ที่เทียบกับต้นฉบับ ACI 318-19 แล้ว (ส่วนต่าง ≤ 2.4% จากการปัดเลขของ 318M) และมีแหล่งภายนอกยืนยันบางค่า (สมการทั่วไป ℓd ใช้ 1.1, ℓdc 0.24/0.043, ทาบอัด 0.071) — ดู `references/si-constants-check.md` ยังไม่ได้เทียบตารางต่อตารางกับเล่ม 318M ฉบับพิมพ์ ให้ระบุในรายงาน
