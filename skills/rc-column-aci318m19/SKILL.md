# ออกแบบ/ตรวจสอบเสา RC — ACI 318M-19 ตาม KB โครงการ

ผลลัพธ์ใช้ประกอบรายการคำนวณ วิศวกรผู้รับผิดชอบต้องตรวจและลงนามเอง

## หลักการ: KB มาก่อน

สกิลนี้มี knowledge base ของโครงการอยู่ใน `kb/` เป็นสรุป ACI 318-19 ภาษาไทยที่เทียบกับต้นฉบับแล้ว ดูแผนที่ใน `kb/INDEX.md`

1. **คำถามเชิงข้อกำหนด** (ข้อไหนใช้ ค่าเท่าไร ทำไม) → เปิดไฟล์ใน `kb/` ตาม INDEX อ่านข้อที่เกี่ยวข้อง แล้วตอบพร้อมเลขข้อ (§) และชื่อไฟล์ ถ้า KB ไม่มี ให้บอกตรง ๆ ว่าไม่มีใน KB ห้ามเติมจากความจำโดยไม่บอก
2. **ค่าตัวเลข SI** → ใช้ `references/si-constants-318m.md` (เทียบเล่ม 318M-19 แล้ว) และ `references/si-formulas.md` — KB เป็นหน่วย inch-pound ตามต้นฉบับ
3. **การคำนวณ** → ใช้ `scripts/column.py` เท่านั้น ห้ามคำนวณในหัว ห้ามใช้ Bresler แทน 3D interaction
4. **ห้ามเดาอินพุต** (fy, cover, ℓu, ทิศการดัด, ระบบโครงสร้าง, ข้อมูลชั้น) ให้ถาม — ยกเว้นค่าเริ่มต้นในตาราง และต้องบอกผู้ใช้ว่าใช้ค่าเริ่มต้น
5. **หน่วย:** ksc → MPa คูณ 0.0980665 (SD40 = 392.3 MPa **ไม่ใช่ 420**)
6. **ห้ามสรุปว่าผ่านทุกข้อ** ถ้ายังมีรายการ "ยังไม่ตรวจ"

## Workflow (ลำดับเดียวกับรายงาน)

| ขั้น | ทำอะไร | KB | สคริปต์ |
|---|---|---|---|
| 0 | ระบุระบบ: ไม่อยู่ในระบบต้านแผ่นดินไหว / OMF / IMF / SMF — SMF หยุด | ch18 §18.2–18.4 | ✅ `system` |
| 1 | หน้าตัด วัสดุ เหล็ก (fy ≤ 550, fyt ≤ 420) | ch10 §10.3, ch20 | ✅ |
| 2 | ดึงแรงจาก STAAD ทุก combo: Pu, Mx/My **ปลายบนและล่าง**, Vux/Vuy; ยืนยัน local axis | — | อินพุต |
| 3 | Q = ΣPuΔo/(Vus·lc) ≤ 0.05 → non-sway; sway หยุด | ch06 §6.6.4.3 | ✅ |
| 4 | ความชะลูด, M1/M2 จาก V·L, δ, M2,min, Mc ≤ 1.4M | ch06 §6.2.5, 6.6.4 | ✅ |
| 5 | φPn,max, 3D interaction ที่ปลายบน/ล่าง/กลาง | ch22 §22.4, ch21 | ✅ |
| 6 | แรงเฉือนสองทิศ + Nu; OMF §18.3.3 / IMF §18.4.3.1 (Mn สูงสุดในช่วง Pu, ไม่คูณ φ) | ch22 §22.5, ch10, ch18 | ✅ |
| 7 | ρg, ระยะว่าง, ปลอก, crosstie; IMF so และ ℓo | ch10, ch25, ch18 | ✅ |
| 8 | ทาบรับแรงอัด/ดึง (DB20 = แถวเหล็กใหญ่) | ch10 §10.7.5, ch25 | ✅ |
| 9 | §15.5 คอนกรีตพื้น, ปลอกในรอยต่อ, dowel 0.005Ag | ch15, ch16 | ✅ บางส่วน — แรงเฉือนรอยต่อยังไม่ตรวจ |
| 10 | สรุปสถานะ + รายการยังไม่ตรวจ | — | ✅ |

ขั้นตอนใช้งาน:
1. ถามข้อมูลที่ขาด → เขียน JSON (ดู `examples/`)
2. รัน `python3 scripts/column.py input.json`
3. ถ้ามี ❌ เสนอทางแก้ (เพิ่มเหล็ก/หน้าตัด, ลดระยะปลอก, เพิ่ม crosstie) แล้วรันใหม่ — δ สูงหรือไม่เสถียร ให้ขยายหน้าตัดก่อนเพิ่มเหล็ก
4. ส่งรายงาน (ทุกหัวข้อมีบรรทัด "อ้างอิง: kb/…") และย้ำรายการยังไม่ตรวจ
5. ต้องการเล่มคำนวณ → ส่งต่อ skill `structural-calc-book`

## อินพุต (JSON)

| key | ความหมาย | kgf-m | SI | ค่าเริ่มต้น |
|---|---|---|---|---|
| `units` | `"kgf-m"` หรือ `"SI"` | — | — | kgf-m |
| `system` | `null` / `"OMF"` / `"IMF"` (`"SMF"` หยุด) | | | null |
| `b`, `h` | ด้านขนานแกน x, ด้านขนานแกน y | m | mm | **ต้องให้** |
| `fc`, `fy`, `fyt` | กำลังวัสดุ | ksc | MPa | fyt = fy |
| `bar_db`, `nx`, `ny` | ขนาดเหล็กยืน, จำนวนต่อด้าน b และด้าน h (รวมมุม) | mm | mm | **ต้องให้** |
| `cover`, `cover_to` | ระยะหุ้ม, วัดถึง `"tie"` หรือ `"bar"` | mm | mm | 40, tie |
| `tie_db`, `tie_s` | ปลอก, ระยะปลอกทั่วไป | mm | mm | 10, 150 |

| `tie_legs_x`, `tie_legs_y` | จำนวนขาปลอกที่ขนานทิศ x / y | | | 2, 2 |

| `lu` (หรือ `lux`, `luy`), `L` | ความยาวไม่ค้ำยัน, ความยาว c/c | m | m | ต้องให้ถ้าตรวจชะลูด/แผ่นดินไหว |

## ไม่รองรับ (แจ้งผู้ใช้)

SMF (§18.7), โครง sway, เสากลม/ปลอกเกลียว, หน้าตัด L/T, เหล็กต่างขนาดในหน้าตัด, คอนกรีตมวลเบา, เสาอัดแรง, แรงบิด, **แรงเฉือนในรอยต่อคาน-เสา (Ch.15)**, เสารองรับชิ้นส่วนแข็งที่ไม่ต่อเนื่อง (§18.4.3.6)
