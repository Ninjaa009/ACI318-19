# ACI 318-19 Chapter 15 — Beam-Column and Slab-Column Joints (จุดต่อคาน-เสา และพื้น-เสา)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 211–215 (ฉบับ inch-pound, f′c หน่วย psi, Vn หน่วย lb) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ mm" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ ไม่ใช่ค่าจากฉบับ 318M

## 15.1 ขอบเขต

- ออกแบบและจัดรายละเอียด **จุดต่อคาน-เสา และพื้น-เสา แบบหล่อในที่**
- joint = ส่วนที่ชิ้นส่วนตัดกัน, connection = joint + ส่วนของชิ้นส่วนที่ต่อเข้ามา
- **SDC B–F:** ต้องทำตาม Ch.18 เพิ่ม (จุดต่ออาจรับแรงสลับทิศหลายรอบ)

## 15.2 ทั่วไป

| ข้อ | สาระสำคัญ |
|---|---|
| 15.2.1 | จุดต่อคาน-เสาต้องผ่านรายละเอียด §15.3 และกำลัง §15.4 |
| 15.2.2 | ทั้งจุดต่อคาน-เสาและพื้น-เสาต้องผ่าน §15.5 (ถ่ายแรงตามแกนเสาผ่านพื้น) |
| 15.2.3 | ถ้ามีการถ่ายโมเมนต์ที่จุดต่อ (จากน้ำหนักแนวดิ่ง ลม แผ่นดินไหว ฯลฯ) ต้องคิดแรงเฉือนที่เกิดขึ้นในจุดต่อ |
| 15.2.4 | **จุดต่อมุม** (สองชิ้นส่วน เช่น หลังคา-เสาริม หรือ knee joint) ต้องคิดผลของโมเมนต์ทั้งแบบ **หุบ (closing) และกาง (opening)** — โมเมนต์ผ่านจุดต่อนี้กระจายไปที่อื่นไม่ได้ |
| 15.2.5 | **คานลึกกว่า 2 เท่าของความลึกเสา** → ออกแบบจุดต่อด้วย strut-and-tie (Ch.23) โดยกำลังเฉือนที่ได้ต้องไม่เกิน φVn ตาม §15.4.2 และต้องผ่านรายละเอียด §15.3 (strut ทแยงระหว่างมุมจุดต่ออาจไม่ได้ผล) |
| 15.2.9 | จุดต่อพื้น-เสาที่ถ่ายโมเมนต์ → กำลังและรายละเอียดตาม Ch.8, §15.3.2 และ §22.6 |

### ส่วนยื่นที่ถือว่าให้ความต่อเนื่อง (ใหม่ใน 318-19)

ส่วนยื่นของเสาหรือคานที่ออกแบบถูกต้อง ช่วยโอบรัดจุดต่อได้เทียบเท่าชิ้นส่วนต่อเนื่อง:

| ชนิด | เงื่อนไข (ต้องครบทั้งสองข้อ) |
|---|---|
| เสายื่น (15.2.6) | (a) เสายื่นเหนือจุดต่อ ≥ 1 เท่าความลึกเสา h (ในทิศแรงเฉือนที่พิจารณา) (b) เหล็กยืนและเหล็กปลอกจากเสาล่างต่อเนื่องเข้าส่วนยื่น |
| คานยื่น (15.2.7) | (a) คานยื่นเลยหน้าจุดต่อ ≥ 1 เท่าความลึกคาน h (b) เหล็กยืนและเหล็กปลอกจากคานฝั่งตรงข้ามต่อเนื่องเข้าส่วนยื่น |

### จุดต่อที่ถือว่าถูกโอบรัด (15.2.8)

ถือว่าโอบรัดในทิศแรงเฉือนที่พิจารณา ถ้ามี **คานขวาง 2 ตัว** ที่:
- (a) กว้าง **≥ ¾ ของความกว้างหน้าเสา** ที่คานต่อเข้า
- (b) ยื่นเลยหน้าจุดต่อ **≥ 1 เท่าความลึกคาน h**
- (c) มีเหล็กบนและล่างต่อเนื่องอย่างน้อย 2 เส้น (ตาม §9.6.1.2) และปลอก **No.3 หรือใหญ่กว่า** (ตาม §9.6.3.4 และ §9.7.6.2.2)

> ใน 318-19 แยกชิ้นส่วนที่ **สร้างแรงเฉือนในจุดต่อ** (คานในทิศ Vu → นับผ่านความกว้างประสิทธิผล) ออกจากชิ้นส่วนที่ **ช่วยโอบรัด** (คานขวาง) — เสากลมคิดเป็นสี่เหลี่ยมจัตุรัสพื้นที่เท่ากันได้

## 15.3 รายละเอียดจุดต่อ

### 15.3.1 เหล็กปลอกในจุดต่อคาน-เสา

ต้องใส่ปลอกในจุดต่อตามข้อ 15.3.1.2–15.3.1.4 **ยกเว้น** ครบทั้ง 3 ข้อนี้:
- (a) จุดต่อถูกโอบรัดตาม §15.2.8 **ทุกทิศ** ที่พิจารณา
- (b) จุดต่อไม่ได้เป็นส่วนของระบบต้านแรงแผ่นดินไหว
- (c) โครงสร้างไม่อยู่ใน SDC D, E, F

(จุดต่อภายในที่มีคานลึกใกล้เคียงกันทั้ง 4 ด้านไม่ต้องใช้ปลอก แต่จุดต่อริมนอกอาคารต้องใช้ เพื่อกันรอยร้าวเฉือนและกันเหล็กยืนเสาโก่งเดาะ)

| ข้อ | ข้อกำหนด |
|---|---|
| 15.3.1.2 | ใช้ปลอก (§25.7.2), เกลียว (§25.7.3) หรือ hoop (§25.7.4) |
| 15.3.1.3 | อย่างน้อย **2 ชั้น** ภายในความลึกของคานที่ตื้นที่สุด |
| 15.3.1.4 | ระยะห่าง **≤ 8 in. (≈ 200 mm)** ภายในความลึกของคานที่ลึกที่สุด |

### 15.3.2 เหล็กปลอกในจุดต่อพื้น-เสา

- ต้องต่อปลอกเสาผ่านจุดต่อพื้น-เสา (รวม capital, drop panel, shear cap) ตาม §25.7.2 / 25.7.3 / 25.7.4 — **ยกเว้น** พื้นยึดรั้งเสาทั้ง 4 ด้าน

### 15.3.3 เหล็กตามยาว

- เหล็กที่สิ้นสุดในจุดต่อ หรือในส่วนยื่นของเสา/คาน → ฝังยึดตาม §25.4 (ความยาวในส่วนยื่นที่ไม่รับแรงนับเป็นระยะฝังยึดได้)
- เหล็กที่สิ้นสุดด้วยขอมาตรฐาน → **หันขอเข้าหากึ่งกลางความลึก** ของคานหรือเสา

## 15.4 กำลังของจุดต่อคาน-เสา

ตรวจแยกกันในแต่ละทิศหลักของแรง

### 15.4.1 แรงเฉือนที่ต้องการ

Vu คำนวณที่ระนาบกึ่งกลางความสูงจุดต่อ จากแรงดึง/อัดของคานและแรงเฉือนของเสา โดยใช้อย่างใดอย่างหนึ่ง:
- (a) โมเมนต์สูงสุดที่ถ่ายระหว่างคาน-เสา จากการวิเคราะห์ด้วยน้ำหนักประลัย (สำหรับจุดต่อที่คานต่อเนื่องในทิศนั้น)
- (b) กำลังโมเมนต์ระบุ Mn ของคาน

### 15.4.2 กำลังออกแบบ

$$\phi V_n \ge V_u$$

- φ ตาม Table 21.2.1 สำหรับแรงเฉือน

**Table 15.4.2.3 — กำลังเฉือนระบุของจุดต่อ Vn (lb)**

| เสา | คานในทิศ Vu | โอบรัดด้วยคานขวาง (§15.2.8) | Vn |
|---|---|---|---|
| ต่อเนื่อง หรือผ่าน §15.2.6 | ต่อเนื่อง หรือผ่าน §15.2.7 | โอบรัด | 24λ√f′c·Aj |
| | | ไม่โอบรัด | 20λ√f′c·Aj |
| | อื่น ๆ | โอบรัด | 20λ√f′c·Aj |
| | | ไม่โอบรัด | 15λ√f′c·Aj |
| อื่น ๆ | ต่อเนื่อง หรือผ่าน §15.2.7 | โอบรัด | 20λ√f′c·Aj |
| | | ไม่โอบรัด | 15λ√f′c·Aj |
| | อื่น ๆ | โอบรัด | 15λ√f′c·Aj |
| | | ไม่โอบรัด | 12λ√f′c·Aj |

λ = 0.75 คอนกรีตมวลเบา, 1.0 คอนกรีตปกติ

### 15.4.2.4 พื้นที่ประสิทธิผล Aj

$$A_j = \text{ความลึกจุดต่อ} \times \text{ความกว้างประสิทธิผล}$$

- **ความลึกจุดต่อ** = ความลึกทั้งหมดของเสา h ในทิศแรงเฉือนที่พิจารณา
- **ความกว้างประสิทธิผล:**
  - คานกว้างกว่าเสา → ใช้ความกว้างเสา
  - เสากว้างกว่าคาน → ไม่เกินค่าน้อยกว่าของ (a) b + h และ (b) b + 2x (x = ระยะตั้งฉากจากแกนคานถึงผิวเสาด้านที่ใกล้ที่สุด)
- Aj ต้องไม่เกินพื้นที่หน้าตัดเสา; คิดแยกในแต่ละทิศ

## 15.5 การถ่ายแรงตามแกนเสาผ่านพื้น

ถ้า **f′c ของพื้น < 0.7 × f′c ของเสา** ต้องใช้วิธีใดวิธีหนึ่ง:

| วิธี | รายละเอียด | ใช้กับ |
|---|---|---|
| (a) เทคอนกรีตเสาทะลุพื้น | เทคอนกรีตกำลังเท่าเสาในพื้นที่ตำแหน่งเสา ยื่นออกจากหน้าเสา **≥ 2 ft (≈ 600 mm)** ตลอดความหนาพื้น และผสานกับคอนกรีตพื้น (ต้องระบุลำดับการเทในแบบ และอาจต้องตรวจงานเพิ่ม) | ทุกตำแหน่ง |
| (b) ใช้กำลังคอนกรีตต่ำ + เสริมเหล็ก | คำนวณกำลังเสาผ่านพื้นด้วย f′c ที่ต่ำกว่า โดยเพิ่มเหล็กเสียบแนวดิ่งและเหล็กปลอกตามที่ต้องการ | ทุกตำแหน่ง |
| (c) กำลังเทียบเท่า | ใช้ f′c ในจุดต่อ = **0.75 f′c,เสา + 0.35 f′c,พื้น** โดย f′c,เสา ≤ **2.5 f′c,พื้น** | เฉพาะจุดต่อคาน-เสาที่มีคานลึกใกล้เคียงกันทั้ง 4 ด้าน (ผ่าน §15.2.7 และ §15.2.8(a)) หรือจุดต่อพื้น-เสาที่พื้นล้อมทั้ง 4 ด้าน — เช่น เสาภายใน |

- เสามุมและเสาริม ใช้ได้เฉพาะ (a) หรือ (b)
- เพดาน 2.5 เท่า มาจากงานวิจัยที่พบว่าพื้นรับน้ำหนักมากโอบรัดได้น้อยกว่าพื้นรับน้ำหนักน้อย

3. ☐ คานลึก > 2 เท่าความลึกเสา → ใช้ strut-and-tie
4. ☐ ตรวจส่วนยื่นเสา/คาน (§15.2.6, 15.2.7) และการโอบรัดด้วยคานขวาง (§15.2.8)
5. ☐ Vu ที่กึ่งกลางความสูงจุดต่อ (จากโมเมนต์ที่ถ่าย หรือ Mn คาน)

9. ☐ ขอของเหล็กที่สิ้นสุดในจุดต่อหันเข้าหากึ่งกลาง
10. ☐ จุดต่อมุม: ตรวจทั้งโมเมนต์หุบและกาง
11. ☐ f′c พื้น < 0.7 f′c เสา → เลือกวิธี (a), (b) หรือ (c) ของ §15.5
