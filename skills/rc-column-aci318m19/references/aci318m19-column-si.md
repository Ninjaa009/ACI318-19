## 3D interaction

- เหล็กทุกเส้นตามพิกัดจริง; ความเครียดเชิงเส้นจากแกนสะเทินเอียงมุม β
- บล็อก 0.85f′c ลึก a = β1c ตั้งฉากกับแกนสะเทิน → ตัดรูปสี่เหลี่ยมเป็นรูปหลายเหลี่ยม (Sutherland–Hodgman) หาพื้นที่และ centroid
- เหล็กในบล็อกหัก 0.85f′c
- ที่ Pu ที่กำหนด หา c จาก φPn = Pu แล้วหา β (bisection) ให้ atan(φMny/φMnx) = ทิศโหลด → ratio = Mres/φMcap
