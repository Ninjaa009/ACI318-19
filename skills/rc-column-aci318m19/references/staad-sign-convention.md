ยืนยันกับผล STAAD.Pro 2025 ของโมเดลทดสอบ CC.std (เสาปกติ 0.5×0.4, เสากลับด้าน 0.6×0.6, คานแนว X และแนว Z) — ชุดทดสอบ `skills/_shared/tests/test_staadio.py` (38 เคส) ใช้ตัวเลขจริงจาก STAAD
สคริปต์ `scripts/from_staad.py` ทำการแปลงทั้งหมดนี้ให้ ห้ามแปลงเองด้วยมือ

## แกน local (BETA = 0, แกน Y ชี้ขึ้น)

| สมาชิก | x | y | z |
|---|---|---|---|
| เสา start ล่าง → end บน | +Y | −X | +Z |
| เสา start บน → end ล่าง (กลับด้าน) | −Y | **+X** | +Z |
| คานแนว +X | +X | +Y | +Z |
| คานแนว +Z | +Z | +Y | −X |

YD = ความลึกตามแกน local y, ZD = ตามแกน local z → **h = YD, b = ZD; Mz ดัดโดยใช้ความลึก YD, My ใช้ ZD**

## สองตาราง สอง convention — กับดักหลัก

| | Beam End Forces | Beam Section Forces |
|---|---|---|
| ค่าที่ปลาย start | เหมือนกัน | เหมือนกัน |
| ค่าที่ปลาย end | **กลับเครื่องหมาย**เทียบตาราง Section | ต่อเนื่องเป็น diagram |
| แรงตามแกน | start: + = อัด, end: − = อัด | + = อัด ทุกตำแหน่ง |
| ทิศการดัดของเสา | Mz สองปลาย **เครื่องหมายเดียวกัน** = โค้งสองทาง | Mz สองปลาย **เครื่องหมายต่างกัน** = โค้งสองทาง |
| โมเมนต์คาน (แกน y ชี้ขึ้น) | M ซ้าย = −Mz(start), M ขวา = +Mz(end) | **M = −Mz ทุกตำแหน่ง** (Mz > 0 = ดึงบน) |
| กลางช่วงคาน | ไม่มี | มี — ต้องใช้ตารางนี้สำหรับคาน |

ตัวอย่างจริง (คาน 13, LC 2): Section ที่ 0.5 = −6.651 → M = +6.65 kN·m ดึงล่าง (สมดุลแรงจุดของ FLOOR LOAD ได้ +6.658) · ที่ 1.0: Section = +10.501 แต่ End Forces = −10.501

## เสา

- Pu = แรงอัดมากสุดตามความยาว (ปลายล่าง) — เสา 30 (กลับด้าน) LC102: start (บน) 58.85, ฐาน **94.48** kN
- บน/ล่าง ตัดสินจากพิกัด Y ของ node ไม่ใช่ start/end
- Vuy = |Shear-Y| (คู่ Mz), Vux = |Shear-Z| (คู่ My)
- ℓu ตั้งต้น = L − ความลึกคานที่หัวเสา (ตรวจแก้ได้)
- ตรวจ: |Shear-Y|·L ≈ |Mz บน| + |Mz ล่าง| เมื่อโค้งสองทาง (เสา 1: 8.70 × 3.5 = 30.45 = 9.54 + 20.91)

## คาน

- M และ V ที่**ผิวเสา** (§9.4.2): ห่าง node = ครึ่งความกว้างเสาตามแนวคาน — interpolate จากตาราง Section
- M กลางช่วง = โมเมนต์บวกมากสุดระหว่างผิวเสา
- ℓn = L − ระยะผิวเสาทั้งสองข้าง

## หยุดและถาม

BETA ≠ 0 (ยังไม่ได้ทดสอบ), สมาชิกเอียง, หน้าตัดที่ไม่ใช่ PRIS YD/ZD, คานที่แกน local y ไม่ชี้ขึ้น, หน่วย STAAD ที่ไม่ใช่ kN–m
