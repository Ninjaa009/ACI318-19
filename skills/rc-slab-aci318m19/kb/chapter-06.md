# ACI 318-19 Chapter 6 — Structural Analysis (การวิเคราะห์โครงสร้าง)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 67–87 (ฉบับ inch-pound) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

## 6.1 ขอบเขต

วิธีวิเคราะห์ การจำลองชิ้นส่วนและระบบโครงสร้าง และการคำนวณผลของน้ำหนัก (load effects)

## 6.2 ทั่วไป

- จำลองตาม §6.3 และวิเคราะห์หาผลสูงสุด รวมการจัดเรียง live load ตาม §6.4

### วิธีวิเคราะห์ที่อนุญาต (6.2.3)

| วิธี | ข้อ | ลักษณะ |

| (a) วิธีอย่างง่าย | §6.5 | สัมประสิทธิ์โมเมนต์/แรงเฉือน สำหรับคานต่อเนื่องและพื้นทางเดียว (น้ำหนักแนวดิ่ง) |

## 6.3 สมมติฐานการจำลอง

- เลือก stiffness สัมพัทธ์อย่างสมเหตุสมผลและ **สอดคล้องกันตลอดการวิเคราะห์หนึ่ง ๆ** (วิเคราะห์หลายชุดด้วย stiffness ต่างกันเพื่อวัตถุประสงค์ต่างกันได้)
- โครงค้ำยัน: ทั่วไปใช้ 0.5Ig สำหรับคาน และ Ig สำหรับเสา
- **แรงบิด:** equilibrium torsion → ต้องรวม torsional stiffness; compatibility torsion → มักไม่รวม
- น้ำหนักแนวดิ่ง: จำลองเฉพาะชั้นที่พิจารณา + เสาเหนือและใต้ชั้น โดยสมมติปลายไกลของเสาเป็นยึดแน่นได้
- ต้องคิดการเปลี่ยนหน้าตัด เช่น คานเสริมปลาย (haunch)

## 6.4 การจัดเรียง live load

- ออกแบบพื้น/หลังคาสำหรับน้ำหนักแนวดิ่ง: สมมติ live load อยู่เฉพาะชั้นที่พิจารณาได้

**พื้นทางเดียวและคาน (6.4.2)**
- Mu บวกสูงสุดใกล้กลางช่วง: L ประลัยบนช่วงนั้นและ **ช่วงเว้นช่วง**
- Mu ลบสูงสุดที่จุดรองรับ: L ประลัยบน **ช่วงที่ติดกัน** เท่านั้น

**พื้นสองทาง (6.4.3)** — ต้องไม่น้อยกว่ากรณี L เต็มทุกแผง และ:
- ถ้ารู้รูปแบบ L → วิเคราะห์ตามนั้น
- ถ้า **L ≤ 0.75D** หรือ L จะเกิดพร้อมกันทุกแผง → ใช้ L เต็มทุกแผงได้
- กรณีอื่น: Mu บวกสูงสุด ใช้ **75% ของ L** บนแผงนั้นและแผงเว้นแผง; Mu ลบสูงสุด ใช้ **75% ของ L** บนแผงติดกัน (อาศัยการกระจายโมเมนต์ใหม่ — จึงห้ามกระจายโมเมนต์ซ้ำอีก)

## 6.6 Linear elastic first-order analysis

- ต้องคิดความชะลูดตาม §6.6.4 (ยกเว้นละเลยได้ตาม §6.2.5.1)
- กระจายโมเมนต์ใหม่ได้ตาม §6.6.5
- โมเมนต์ที่ระดับพื้นกระจายเข้าเสาตาม stiffness; ต้องคิดผลของรูปแบบน้ำหนักต่อการถ่ายโมเมนต์เข้าเสาริมและเสาใน และน้ำหนักเยื้องศูนย์

**ลดความซับซ้อนได้ (6.6.2.3)**
- (a) พื้นตันหรือระบบตงทางเดียว ช่วงว่าง ≤ 10 ft หล่อเป็นเนื้อเดียวกับจุดรองรับ → วิเคราะห์เป็นคานต่อเนื่องบนจุดรองรับคมมีด ช่วง = ช่วงว่าง (ไม่คิดความกว้างคานรองรับ)
- (b) โครงข้อแข็ง: สมมติบริเวณที่ชิ้นส่วนตัดกัน (จุดต่อ) เป็น **rigid** ได้

### 6.6.4 ความชะลูด — Moment Magnification Method

- จำแนกเสา/ชั้นเป็น **nonsway** (§6.6.4.5) หรือ **sway** (§6.6.4.6)
- มิติหน้าตัดในการวิเคราะห์ต้องคลาดจากแบบ **ไม่เกิน 10%** (ถ้าใช้ Table 6.6.3.1.1(b) อัตราส่วนเหล็กก็ต้องคลาดไม่เกิน 10%) มิฉะนั้นวิเคราะห์ใหม่

**ถือเป็น nonsway ได้ถ้า (6.6.4.3)**
- (a) โมเมนต์ปลายเสาเพิ่มจาก second-order ≤ 5% ของ first-order **หรือ**
- (b) **Q ≤ 0.05**

**ดัชนีเสถียรภาพ (6.6.4.4.1)**

$$Q = \frac{\Sigma P_u \Delta_o}{V_{us}\ell_c}$$

ΣPu = น้ำหนักแนวดิ่งประลัยรวมของชั้น, Vus = แรงเฉือนชั้น, Δo = การเคลื่อนตัวสัมพัทธ์ first-order ระหว่างบน-ล่างชั้น (ถ้าใช้ค่าจากน้ำหนักใช้งาน: ใช้ 1.2ΣP, แรงเฉือนชั้นใช้งาน และ 1.4Δ)

**น้ำหนักวิกฤต (6.6.4.4.2)**

$$P_c = \frac{\pi^2 (EI)_{eff}}{(k\ell_u)^2}$$

- k: ใช้ Ec ตาม §19.2.2 และ I ตาม §6.6.3.1.1; nonsway ใช้ k = 1.0 ได้; sway ต้อง k ≥ 1.0

**(EI)eff (6.6.4.4.4)**

| | สมการ |
|---|---|
| (a) | (EI)eff = 0.4EcIg / (1 + βdns) |
| (b) | (EI)eff = (0.2EcIg + EsIse) / (1 + βdns) |
| (c) | (EI)eff = EcI / (1 + βdns) — I จาก Table 6.6.3.1.1(b) |

βdns = แรงตามแกนค้างประลัยสูงสุด / แรงตามแกนประลัยสูงสุด (ชุดผสมเดียวกัน) — ประมาณ βdns = 0.6 ทำให้ (a) เป็น 0.25EcIg

### 6.6.4.5 Nonsway frames

$$M_c = \delta M_2, \qquad \delta = \frac{C_m}{1 - \dfrac{P_u}{0.75P_c}} \ge 1.0$$

(0.75 = stiffness reduction factor φK ของเสาเดี่ยว)

| Cm | |
|---|---|
| ไม่มีแรงขวางระหว่างจุดรองรับ | Cm = 0.6 − 0.4(M1/M2) |
| มีแรงขวางระหว่างจุดรองรับ | Cm = 1.0 |

**โมเมนต์ขั้นต่ำ (6.6.4.5.4)** — M2 ≥ M2,min แยกแต่ละแกน (ไม่ต้องใช้พร้อมกันสองแกน):

$$M_{2,min} = P_u(0.6 + 0.03h) \quad \text{(h หน่วย in.)}$$

ถ้า M2,min > M2 → Cm = 1.0 หรือคำนวณจาก M1/M2 ของโมเมนต์ปลายจริง

### 6.6.4.6 Sway frames

$$M_1 = M_{1ns} + \delta_s M_{1s}, \qquad M_2 = M_{2ns} + \delta_s M_{2s}$$

(ns = จากน้ำหนักที่ไม่ทำให้เซ, s = จากน้ำหนักที่ทำให้เซ)

**δs หาด้วยวิธีใดวิธีหนึ่ง** — ถ้า δs > 1.5 ใช้ได้เฉพาะ (b) หรือ (c):

| วิธี | สมการ |
|---|---|
| (a) Q method | δs = 1 / (1 − Q) ≥ 1 |
| (b) Sum of P | δs = 1 / (1 − ΣPu / (0.75ΣPc)) ≥ 1 |
| (c) Second-order elastic analysis | — |

ΣPc ของเสาที่ต้านการเซทั้งชั้น — Pc ใช้ k ของ sway และ (EI)eff ที่ใช้ βds แทน βdns (ลม/แผ่นดินไหวเป็นแรงระยะสั้น ปกติ βds = 0)

- **คาน** ต้องออกแบบรับโมเมนต์ปลายเสาที่ขยายแล้วทั้งหมดที่จุดต่อ
- ต้องคิดผล second-order **ตามความยาวเสา** ใน sway frame ด้วย (ใช้ §6.6.4.5 กับ M1, M2 จาก 6.6.4.6)
- ถ้าอาคารบิดมาก ควรใช้ 3D second-order analysis

### 6.6.5 การกระจายโมเมนต์ใหม่ (Redistribution)

ลดโมเมนต์ลบสูงสุดหรือบวกสูงสุดจาก elastic analysis ได้ **ยกเว้น** ใช้วิธีอย่างง่าย §6.5, inelastic §6.8, หรือพื้นสองทางที่ใช้รูปแบบ 75% ตาม §6.4.3.3 — เงื่อนไข:
- (a) ชิ้นส่วนรับแรงดัดต่อเนื่อง
- (b) **εt ≥ 0.0075** ที่หน้าตัดที่ลดโมเมนต์

| ข้อ | ข้อกำหนด |
|---|---|
| 6.6.5.2 | ชิ้นส่วนอัดแรง: โมเมนต์รวมผลจาก secondary moment ของการอัดแรง |
| 6.6.5.3 | **ลดได้ไม่เกินค่าน้อยกว่าของ 1000εt % และ 20%** |
| 6.6.5.4 | ใช้โมเมนต์ที่ลดแล้วคำนวณโมเมนต์ที่หน้าตัดอื่นให้ยังสมดุลสถิต ในแต่ละรูปแบบน้ำหนัก |
| 6.6.5.5 | แรงเฉือนและแรงปฏิกิริยาคำนวณใหม่ตามสมดุลกับโมเมนต์ที่กระจายแล้ว |

## 6.7 Linear elastic second-order analysis

- ต้องคิดผลของแรงตามแกน บริเวณแตกร้าว และระยะเวลาของน้ำหนัก (ใช้คุณสมบัติหน้าตัดตาม §6.7.2 ซึ่งรวม φK แล้ว)
- ต้องคิดความชะลูด **ตามความยาวเสา** — ใช้ §6.6.4.5 ได้ (ถ้าไม่ได้แบ่ง node ตามความยาวเสา)
- มิติหน้าตัดคลาดจากแบบไม่เกิน 10%
- กระจายโมเมนต์ใหม่ได้ตาม §6.6.5
- คุณสมบัติหน้าตัด: น้ำหนักประลัย ใช้ §6.6.3.1; น้ำหนักใช้งาน ใช้ §24.2 หรือ 1.4 × I (≤ Ig)

## 6.8 Inelastic analysis

- ต้องคิดความไม่เชิงเส้นของวัสดุ; first-order สมดุลบนรูปทรงเดิม, second-order สมดุลบนรูปทรงที่เสียรูป
- วิธีวิเคราะห์ต้องพิสูจน์แล้วว่าผลกำลังและการเสียรูปสอดคล้องกับผลทดสอบจริง (ชิ้นส่วน, subassemblage หรือระบบ) ที่มีกลไกตอบสนองคล้ายกัน
- ถ้าไม่ละเลยความชะลูด ต้องสมดุลบนรูปทรงที่เสียรูป (ใช้ §6.6.4.5 ตามความยาวเสาได้)
- มิติหน้าตัดคลาดจากแบบไม่เกิน 10%
- ⛔ **ห้ามกระจายโมเมนต์ใหม่** (inelastic analysis คิดผลไม่ยืดหยุ่นไว้แล้ว)
- ตรวจสอบอาคารต้านแผ่นดินไหวด้วย nonlinear response history → Appendix A (ใช้กำลังวัสดุที่คาดหวัง)

## 6.9 Finite element analysis

- ใช้หาผลของน้ำหนักได้ — แบบจำลองต้องเหมาะกับวัตถุประสงค์ (โปรแกรม, ชนิด element, ขนาด mesh)
- **Inelastic FEA: ต้องวิเคราะห์แยกทุกชุดผสมน้ำหนัก** (ใช้ superposition ไม่ได้)
- วิศวกรต้องยืนยันว่าผลเหมาะสม
- มิติหน้าตัดคลาดจากแบบไม่เกิน 10%
- ⛔ ห้ามกระจายโมเมนต์ใหม่จาก inelastic analysis
