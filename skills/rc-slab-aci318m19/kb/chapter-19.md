# ACI 318-19 Chapter 19 — Concrete: Design and Durability Requirements (คอนกรีต: คุณสมบัติออกแบบและความทนทาน)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 355–369 (ฉบับ inch-pound, f′c หน่วย psi) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> ค่า "≈ MPa / ksc / kg/m³" เป็นการแปลงหน่วยตรง ๆ เพื่อความเข้าใจ (1000 psi ≈ 6.9 MPa ≈ 70 ksc) ไม่ใช่ค่าจากฉบับ 318M

## 19.1 ขอบเขต

- คุณสมบัติคอนกรีตที่ใช้ในการออกแบบ และข้อกำหนดความทนทาน
- ความทนทานของ grout สำหรับ tendon ยึดเกาะ (§19.4)

## 19.2 คุณสมบัติคอนกรีตสำหรับออกแบบ

### 19.2.1 กำลังอัดที่กำหนด f′c

f′c ต้องผ่าน: (a) ขั้นต่ำตาม Table 19.2.1.1 (b) ความทนทานตาม Table 19.3.2.1 (c) กำลังที่ต้องการทางโครงสร้าง (d) คอนกรีตมวลเบาใน SMF ผนังพิเศษ และฐานราก — f′c ที่ใช้คำนวณ **≤ 5000 psi** เว้นแต่พิสูจน์ด้วยการทดสอบ

**Table 19.2.1.1 — f′c ขั้นต่ำ** (ใช้ทั้งคอนกรีตปกติและมวลเบา)

| การใช้งาน | f′c ขั้นต่ำ (psi) |
|---|---|
| ทั่วไป | 2500 (≈ 17 MPa, 175 ksc) |
| ฐานรากของโครงสร้าง SDC A, B, C | 2500 |
| ฐานรากอาคารพักอาศัย/สาธารณูปโภค โครงผนังเบา ≤ 2 ชั้น ใน SDC D, E, F | 2500 |
| ฐานรากโครงสร้าง SDC D, E, F อื่น ๆ | 3000 (≈ 21 MPa, 210 ksc) |
| Special moment frame; ผนังพิเศษที่ใช้เหล็ก Grade 60 หรือ 80 | 3000 |
| ผนังพิเศษที่ใช้เหล็ก **Grade 100** (ใหม่ใน 318-19) | 5000 (≈ 34 MPa, 350 ksc) |
| เข็มตอก precast ไม่อัดแรง; เข็มเจาะ (drilled shaft) | 4000 (≈ 28 MPa, 280 ksc) |
| เข็มตอก precast อัดแรง | 5000 |

- ไม่มีขีดสูงสุดของ f′c (ยกเว้นตามข้อเฉพาะ เช่น √f′c ≤ 100 psi ในบางสูตร, พุก §17.3.1)
- f′c ใช้ในการออกแบบส่วนผสม (§26.4.3) และการทดสอบยอมรับ (§26.12.3)
- **อายุทดสอบ 28 วัน** เว้นแต่ระบุอายุอื่นในเอกสารก่อสร้าง
- ส่วนผสมต้องออกแบบให้กำลังเฉลี่ยสูงกว่า f′c (เผื่อความแปรปรวนทางสถิติ)

### 19.2.2 โมดูลัสยืดหยุ่น Ec

| กรณี | สมการ (psi) |
|---|---|
| (a) wc = 90–160 lb/ft³ (≈ 1440–2560 kg/m³) | Ec = wc^1.5 × 33√f′c |
| (b) คอนกรีตปกติ | Ec = 57,000√f′c |

- นิยาม: ความชันของเส้นตัดจากหน่วยแรงศูนย์ถึง 45% ของ f′c (ASTM C469 ใช้ 40%)
- ค่าจริงอาจต่างจากสมการมาก สำหรับ f′c > 8000 psi, คอนกรีตมวลเบา, ส่วนผสมมวลรวมหยาบน้อย (เช่น SCC)
- **กำหนด Ec จากการทดสอบได้ (ใหม่ใน 318-19):** (a) ใช้ในการออกแบบส่วนผสม (b) ทดสอบยืนยันและส่งผลพร้อม mix submittal (c) อายุทดสอบ 28 วันหรือตามที่ระบุ — เหมาะกับอาคารสูงหรืองานที่การโก่งตัว/การเคลื่อนตัว/การสั่นสะเทือนสำคัญ

### 19.2.3 Modulus of rupture

$$f_r = 7.5\lambda\sqrt{f'_c} \quad \text{(psi)}$$

### 19.2.4 คอนกรีตมวลเบา — ตัวปรับ λ

เลือกได้สองวิธี (ยกเว้นตามที่ Table 25.4.2.5 กำหนด):

**Table 19.2.4.1(a) — λ จากความหนาแน่นสมดุล wc (ใหม่ใน 318-19)**

| wc (lb/ft³) | λ |
|---|---|
| ≤ 100 (≈ 1600 kg/m³) | 0.75 |
| 100 < wc ≤ 135 | 0.0075wc ≤ 1.0 |
| > 135 (≈ 2160 kg/m³) | 1.0 |

**Table 19.2.4.1(b) — λ จากชนิดมวลรวม**

| คอนกรีต | มวลรวม | λ |
|---|---|---|
| All-lightweight | ละเอียด: C330 / หยาบ: C330 | 0.75 |
| Lightweight, fine blend | ละเอียด: C330 + C33 / หยาบ: C330 | 0.75 – 0.85 ¹ |
| Sand-lightweight | ละเอียด: C33 / หยาบ: C330 | 0.85 |
| Sand-lightweight, coarse blend | ละเอียด: C33 / หยาบ: C330 + C33 | 0.85 – 1.0 ² |

¹ ประมาณค่าเชิงเส้นตามสัดส่วนปริมาตรมวลรวมละเอียดปกติ · ² ตามสัดส่วนปริมาตรมวลรวมหยาบปกติ

- ใช้ λ = **0.75** สำหรับคอนกรีตมวลเบาทุกกรณีได้ (อนุรักษ์)
- คอนกรีตปกติ λ = **1.0**
- ฉบับ 2019 นิยามคอนกรีตมวลเบาเป็น wc = **90–135 lb/ft³** (เดิม 90–115 ทำให้ช่วง 115–135 ไม่มีนิยาม) และตัดวิธีหา λ จาก splitting tensile strength ออก

## 19.3 ความทนทาน (Durability)

วิศวกรต้องกำหนด exposure class ให้ชิ้นส่วน **ครบทั้ง 4 หมวด** แล้วใช้ข้อกำหนดที่ **เข้มที่สุด** — Code ไม่ครอบคลุมสภาพรุนแรงพิเศษ เช่น กรด หรืออุณหภูมิสูง

### 19.3.1 หมวดและระดับการสัมผัส (Table 19.3.1.1)

| หมวด | Class | สภาพ |
|---|---|---|
| **F — Freezing and thawing** (เยือกแข็ง-ละลาย) | F0 | ไม่มีรอบเยือกแข็ง-ละลาย |
| | F1 | มีรอบเยือกแข็ง-ละลาย สัมผัสน้ำจำกัด |
| | F2 | มีรอบเยือกแข็ง-ละลาย สัมผัสน้ำบ่อย |
| | F3 | มีรอบเยือกแข็ง-ละลาย สัมผัสน้ำบ่อย + สารละลายน้ำแข็ง (deicing chemicals) |
| **S — Sulfate** (ซัลเฟต) | S0 | SO₄ ในดิน < 0.10% โดยมวล / ในน้ำ < 150 ppm |
| | S1 | 0.10 – 0.20% / 150 – 1500 ppm **หรือน้ำทะเล** |
| | S2 | 0.20 – 2.00% / 1500 – 10,000 ppm |
| | S3 | > 2.00% / > 10,000 ppm |
| **W — In contact with water** (สัมผัสน้ำ) | W0 | แห้งขณะใช้งาน |
| | W1 | สัมผัสน้ำ ไม่ต้องการความทึบน้ำต่ำ |
| | W2 | สัมผัสน้ำ ต้องการความทึบน้ำต่ำ (low permeability) |
| **C — Corrosion protection** (กันสนิมเหล็ก) | C0 | แห้งหรือป้องกันความชื้นแล้ว |
| | C1 | สัมผัสความชื้น แต่ไม่มีแหล่งคลอไรด์ภายนอก |
| | C2 | สัมผัสความชื้น + คลอไรด์ภายนอก (สารละลายน้ำแข็ง เกลือ น้ำกร่อย น้ำทะเล ละอองน้ำทะเล) |

- ซัลเฟตในดินทดสอบตาม ASTM C1580; ในน้ำตาม ASTM D516 หรือ D4130
- ตัวอย่าง: พื้นโรงจอดรถในเขตหนาว → F3, S0, W2, C2; ถังน้ำดื่มในอาคาร → F0, S0, W2, C1
- **สำหรับไทย:** โดยทั่วไป F0; งานชายทะเล/โครงสร้างสัมผัสน้ำทะเล → S1 และ C2; ฐานรากในดินเค็มหรือดินซัลเฟต ต้องทดสอบหา S

**ตัวอย่างหมวด F (Table R19.3.1)**

| Class | ตัวอย่าง |
|---|---|
| F0 | เขตไม่มีอุณหภูมิเยือกแข็ง, ภายในอาคาร, ฐานรากใต้ระดับ frost line |
| F1 | ผนังภายนอก คาน พื้นที่ไม่สะสมหิมะ/น้ำแข็ง และไม่สัมผัสดินโดยตรง |
| F2 | พื้นยกระดับภายนอกที่สะสมหิมะ, ผนังฐานรากเหนือดินที่มีหิมะพิง, ชิ้นส่วนสัมผัสดิน |
| F3 | ชิ้นส่วนแนวนอนในโรงจอดรถ, ผนังฐานรากเหนือดินที่สัมผัสหิมะผสมสารละลายน้ำแข็ง |

|---|---|---|---|---|---|

**เชิงอรรถสำคัญ**
1. w/cm คิดจากวัสดุประสานทั้งหมด (ซีเมนต์ + SCM)
2. **ขีด w/cm ไม่ใช้กับคอนกรีตมวลเบา** (คำนวณน้ำที่มวลรวมดูดซับยาก — ใช้แค่ f′c ขั้นต่ำ)
3. คอนกรีตไม่เสริมเหล็กใน F3: w/cm ≤ 0.45, f′c ≥ 4500 psi
4. ใช้วัสดุประสานผสมแบบอื่นได้ทุก class ซัลเฟต ถ้าทดสอบความต้านทานซัลเฟตผ่าน §26.4.2.2(c) (ASTM C1012)
5. **น้ำทะเล:** ใช้ซีเมนต์ปอร์ตแลนด์ที่ C₃A ≤ 10% ได้ ถ้า w/cm ≤ 0.40
6. ใช้ Type I หรือ III ได้ ถ้า C₃A < 8% (S1) หรือ < 5% (S2)
7. ปริมาณ pozzolan/slag ≥ ที่พิสูจน์ด้วยประวัติการใช้งาน หรือทดสอบตาม ASTM C1012 กับซีเมนต์ Type V
8. ถ้าใช้ Type V เป็นวัสดุประสานเดียว ต้องระบุข้อกำหนดเลือกได้ (optional) การขยายตัว ≤ 0.040%
9. **ใหม่ใน 318-19:** คลอไรด์คิดต่อมวล **วัสดุประสานทั้งหมด** (เดิมต่อซีเมนต์) — แต่มวล SCM ที่นับได้ ≤ มวลซีเมนต์ปอร์ตแลนด์ (คือ SCM ≤ 50%)
10. วิธีหาปริมาณคลอไรด์ตาม §26.4.2.2

**แนวทาง (commentary)**
- คอนกรีตต้องผ่านข้อที่เข้มที่สุด เช่น W1 + S2 → w/cm ≤ 0.45 และ f′c ≥ 4500 psi
- f′c ขั้นต่ำในตารางเป็นตัวแทนของ w/cm (ตรวจ w/cm ในสนามยาก จึงใช้ผลกำลังอัดแทน) — ระบุ f′c สูงกว่านี้ได้ให้สอดคล้องกับ w/cm
- C2: ป้องกันเพิ่มได้ด้วยเหล็กเคลือบ เหล็กทนสนิม ระยะหุ้มมากขึ้น ใช้ slag/เถ้าลอย/ซิลิกาฟูม และทดสอบ ASTM C1202
- ซีเมนต์ทนซัลเฟตไม่ช่วยต้านสารเคมีอื่น (เช่น กรดซัลฟิวริก) ต้องระบุแยก

- F3: ปริมาณ pozzolan (รวมเถ้าลอย ซิลิกาฟูม) และ slag สูงสุดตาม §26.4.2.2(b)

### 19.3.4 คลอไรด์ — เพิ่มเติม

- คอนกรีตไม่อัดแรงที่เทบน **แบบเหล็กชุบสังกะสีที่ทิ้งไว้ถาวร** (stay-in-place galvanized steel form) → คลอไรด์ไม่เกินเกณฑ์ **C1** (0.30%) เว้นแต่สภาพงานต้องการเข้มกว่า (C2 → 0.15%)
- ฝังอะลูมิเนียม → ดู §20.6.3 และ §26.8.2

## 19.4 ความทนทานของ Grout

- คลอไรด์ที่ละลายน้ำได้ใน grout ของ tendon ยึดเกาะ **≤ 0.06%** โดยมวลวัสดุประสาน (ทดสอบ ASTM C1218)

## Checklist วัสดุคอนกรีต

1. ☐ f′c ≥ ขั้นต่ำตามการใช้งาน (Table 19.2.1.1) — SMF/ผนังพิเศษ 3000 psi, ผนัง G100 5000 psi
2. ☐ คอนกรีตมวลเบาในระบบแผ่นดินไหว: f′c ใช้คำนวณ ≤ 5000 psi

4. ☐ fr = 7.5λ√f′c; λ จากความหนาแน่น (Table 19.2.4.1(a)) หรือมวลรวม (b)
5. ☐ กำหนด exposure class ครบ F, S, W, C
6. ☐ w/cm สูงสุด และ f′c ขั้นต่ำ ตามข้อที่เข้มที่สุด
7. ☐ ชนิดซีเมนต์สำหรับซัลเฟต (S1–S3); ห้าม CaCl₂ ใน S2, S3
8. ☐ คลอไรด์สูงสุด (C0–C2, อัดแรง 0.06%)
9. ☐ F1–F3: กักฟองอากาศตาม Table 19.3.3.1
10. ☐ ระบุ f′c, อายุทดสอบ (ถ้าไม่ใช่ 28 วัน), exposure class ในเอกสารก่อสร้าง
