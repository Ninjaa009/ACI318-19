# ACI 318-19 Chapter 21 — Strength Reduction Factors (ตัวคูณลดกำลัง φ)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 391–396 — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ

## 21.1 ขอบเขต

ใช้เลือก φ ในการออกแบบ ยกเว้นการประเมินโครงสร้างเดิมตาม Ch.27

**วัตถุประสงค์ของ φ:** (1) เผื่อโอกาสที่ชิ้นส่วนมีกำลังต่ำกว่าที่คำนวณ จากความแปรปรวนของวัสดุและมิติ (2) เผื่อความไม่แม่นยำของสมการ (3) สะท้อนความเหนียวและความน่าเชื่อถือที่ต้องการ (4) สะท้อนความสำคัญของชิ้นส่วน — ค่า φ สอดคล้องกับชุดผสมน้ำหนักของ ASCE 7 (Ch.5)

### 21.2.2 φ สำหรับโมเมนต์และแรงตามแกน

**Table 21.2.2** (εt = ความเครียดดึงสุทธิในเหล็กชั้นนอกสุดที่กำลังระบุ)

| εt | ประเภท | φ — เกลียวตาม §25.7.3 | φ — อื่น ๆ (ปลอกเดี่ยว) |
|---|---|---|---|
| εt ≤ εty | Compression-controlled | 0.75 | 0.65 |
| εty < εt < εty + 0.003 | Transition ¹ | 0.75 + 0.15(εt − εty)/0.003 | 0.65 + 0.25(εt − εty)/0.003 |
| εt ≥ εty + 0.003 | Tension-controlled | 0.90 | 0.90 |

¹ ช่วง transition ใช้ φ ของ compression-controlled ได้ (อนุรักษ์)

**ค่า εty**
- เหล็กข้ออ้อย: εty = **fy/Es** — Grade 60 ใช้ **0.002** ได้
- เหล็กอัดแรงทุกชนิด: εty = **0.002**

**ตัวอย่างค่า εty + 0.003 (คำนวณเอง, Es = 29,000 ksi)**

| เกรด | εty | ขีด tension-controlled |
|---|---|---|
| Grade 60 (SD40) | 0.00207 (ใช้ 0.002 ได้) | 0.005 |
| Grade 80 (SD50~) | 0.00276 | 0.00576 |
| Grade 100 | 0.00345 | 0.00645 |

**แนวคิด (commentary)**
- ฉบับก่อน 2019 ใช้ขีด tension-controlled = **0.005** (อิง Grade 60) — ฉบับ 2019 เปลี่ยนเป็น **εty + 0.003** เพื่อรองรับเหล็กกำลังสูง
- คำนวณที่ความเครียดคอนกรีตผิวรับแรงอัด = 0.003; εt ไม่รวมความเครียดจาก prestress, creep, shrinkage, อุณหภูมิ
- ชิ้นส่วนรับแรงอัดล้วนถือเป็น compression-controlled; รับแรงดึงล้วนถือเป็น tension-controlled
- คาน/พื้นมักเป็น tension-controlled; เสามักเป็น compression-controlled
- เสาเกลียวได้ φ สูงกว่าเพราะเหนียวกว่า
- การกระจายโมเมนต์ใหม่ต้องการ εt ≥ 0.0075 (§6.6.5)
- กรณีแรงตามแกน + โมเมนต์: ใช้ φ ค่าเดียวคูณทั้ง Pn และ Mn

### 21.2.3 ปลายชิ้นส่วน pretensioned (strand ยังพัฒนาไม่เต็ม)

ความยาวถ่ายแรง:

$$\ell_{tr} = \left(\frac{f_{se}}{3000}\right)d_b$$

(fse หน่วย psi) — φp = φ จาก Table 21.2.2 ที่หน้าตัดใกล้ปลายที่สุดซึ่ง strand ทุกเส้นพัฒนาเต็ม, ℓd ตาม §25.4.8.1

**Table 21.2.3**

| สภาพปลายชิ้นส่วน | หน่วยแรงคอนกรีตที่น้ำหนักใช้งาน ¹ | ระยะจากปลายถึงหน้าตัด | φ |
|---|---|---|---|
| strand ยึดเกาะทุกเส้น | ไม่เกี่ยว | ≤ ℓtr | 0.75 |
| | | ℓtr ถึง ℓd | ประมาณค่าเชิงเส้น 0.75 → φp ² |
| มี strand ที่ debond | ไม่มีแรงดึง | ≤ ℓdb + ℓtr | 0.75 |
| | | (ℓdb + ℓtr) ถึง (ℓdb + ℓd) | ประมาณค่าเชิงเส้น 0.75 → φp ² |
| | มีแรงดึง | ≤ ℓdb + ℓtr | 0.75 |
| | | (ℓdb + ℓtr) ถึง (ℓdb + 2ℓd) | ประมาณค่าเชิงเส้น 0.75 → φp ² |

¹ หน่วยแรงที่ผิวนอกสุดของ precompressed tension zone ที่น้ำหนักใช้งาน (หน้าตัดรวม หลังหักการสูญเสียทั้งหมด)
² ใช้ φ = 0.75 ตลอดได้

ℓdb = ความยาว debond — เหตุผล: ถ้าหน้าตัดวิกฤตอยู่ช่วงที่ strand ยังไม่พัฒนาเต็ม อาจวิบัติจากการลื่นของแรงยึดเกาะ ซึ่งคล้ายแรงเฉือนแบบเปราะ

### 21.2.4 φ แรงเฉือนในโครงสร้างต้านแผ่นดินไหว

ใช้กับโครงสร้างที่อาศัย (a) special moment frame (b) special structural wall (c) intermediate precast wall ใน SDC D, E, F ต้านแรง E:

| ข้อ | ข้อกำหนด |
|---|---|
| 21.2.4.1 | ชิ้นส่วนที่ออกแบบรับ E: **φ = 0.60** ถ้ากำลังเฉือนระบุ **น้อยกว่า** แรงเฉือนที่สอดคล้องกับการพัฒนากำลังดัดระบุ (Mn สูงสุดจาก Pu ในชุดผสมที่มี E) — เช่น ผนังเตี้ย, ผนังระหว่างช่องเปิด, ไดอะแฟรม |
| 21.2.4.2 | **ไดอะแฟรม:** φ เฉือน ≤ ค่าน้อยสุดของ φ เฉือนที่ใช้กับชิ้นส่วนแนวดิ่งของระบบต้านแรงหลัก (จากบทเรียน Northridge 1994 — ผนังยืดหยุ่น แต่ไดอะแฟรมครากก่อน) |
| 21.2.4.3 | **ฐานรากที่รองรับระบบต้านแรงหลัก:** φ เฉือน ≤ ค่าน้อยสุดของ φ เฉือนของชิ้นส่วนแนวดิ่งของระบบ |
| 21.2.4.4 | **จุดต่อคาน-เสา SMF และคานเชื่อมเหล็กทแยง: φ = 0.85** |

(ผนังที่ออกแบบตาม §18.10.6.2 ไม่ใช้ข้อ 21.2.4.1 — ดู §18.10.4.6)
