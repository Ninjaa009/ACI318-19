# ACI 318-19 Chapter 22 — Sectional Strength (กำลังของหน้าตัด)

> สรุปสาระสำคัญด้วยคำของผู้เรียบเรียง ไม่ใช่ตัวบทมาตรฐาน
> อ้างอิง: ACI 318-19 หน้า 397–434 (ฉบับ inch-pound, f′c และ fy หน่วย psi, ความยาว in.) — ใช้งานจริงให้ตรวจสอบกับต้นฉบับเสมอ
> สัมประสิทธิ์หน้า √f′c (2, 8, 4, 3.5 …) ใช้กับหน่วย psi เท่านั้น — ใน ACI 318M ค่าจะต่างไป (เช่น 2√f′c psi ≈ 0.17√f′c MPa)

## 22.1 ขอบเขต

คำนวณกำลังระบุที่หน้าตัด: (a) ดัด (b) แรงตามแกนหรือดัดร่วมแรงตามแกน (c) เฉือนทางเดียว (d) เฉือนสองทาง (e) บิด (f) แบกทาน (g) shear friction

- ใช้กับทุกชิ้นส่วน ยกเว้นส่วนที่ออกแบบด้วย strut-and-tie (Ch.23)
- กำลังออกแบบ = กำลังระบุ × φ (Ch.21)

## 22.2 สมมติฐานการออกแบบ (โมเมนต์และแรงตามแกน)

### 22.2.1 สมดุลและความเข้ากันได้ของความเครียด

- ทุกหน้าตัดต้องสมดุล
- ความเครียดในคอนกรีตและเหล็กไม่อัดแรง **แปรตามระยะจากแกนสะเทิน** (plane sections remain plane)
- คอนกรีตอัดแรงและลวดอัดแรง (ยึดเกาะ/ไม่ยึดเกาะ) ต้องรวมความเครียดจาก prestress ประสิทธิผล
- ความเครียดที่เปลี่ยนในลวดยึดเกาะแปรตามระยะจากแกนสะเทิน

### 22.2.2 คอนกรีต

| ข้อ | สมมติฐาน |
|---|---|
| 22.2.2.1 | ความเครียดสูงสุดที่ผิวรับแรงอัด **εcu = 0.003** |
| 22.2.2.2 | **ไม่นับกำลังรับแรงดึง** ของคอนกรีตในการคำนวณกำลังดัดและแรงตามแกน |
| 22.2.2.3 | ความสัมพันธ์หน่วยแรง-ความเครียด ใช้รูปสี่เหลี่ยม คางหมู พาราโบลา หรืออื่นที่สอดคล้องกับผลทดสอบ |
| 22.2.2.4 | ใช้ **บล็อกหน่วยแรงสี่เหลี่ยมเทียบเท่า**: หน่วยแรง **0.85f′c** สม่ำเสมอ ลึก **a = β1c** จากผิวรับแรงอัด (c วัดตั้งฉากแกนสะเทิน) |

### 22.2.3–22.2.4 เหล็กเสริม

- เหล็กข้ออ้อยตาม §20.2.1; หน่วยแรง-ความเครียดตาม §20.2.2.1 (elastic–perfectly plastic) และ Es ตาม §20.2.2.2
- ลวดอัดแรงยึดเกาะ: fps ตาม §20.3.2.3; ไม่ยึดเกาะ: §20.3.2.4
- strand ที่ฝังน้อยกว่า ℓd: หน่วยแรงออกแบบ ≤ ค่าตาม §25.4.8.3

## 22.3 กำลังดัด

- Mn คำนวณตามสมมติฐาน §22.2
- **ชิ้นส่วนอัดแรง:** นับเหล็กข้ออ้อยร่วมรับแรงดึงที่ **fy** ได้; เหล็กไม่อัดแรงอื่น (เช่น strand ไม่ดึง) นับได้ถ้าคำนวณ strain compatibility
- **ชิ้นส่วน composite:** ใช้หน้าตัด composite ทั้งหมดได้; **ไม่แยก** ระหว่างแบบมีค้ำยันกับไม่มีค้ำยัน (สำหรับกำลัง); ถ้า f′c ต่างกัน ใช้คุณสมบัติของแต่ละชิ้น หรือใช้ f′c ที่ให้ Mn วิกฤตที่สุด
- คานเหล็ก-คอนกรีต composite → AISC 360

**สูตรพื้นฐาน (คานสี่เหลี่ยม เหล็กชั้นเดียว — ไม่ใช่ข้อความใน Code):**

$$a = \frac{A_sf_y}{0.85f'_cb}, \qquad M_n = A_sf_y\left(d - \frac{a}{2}\right), \qquad c = \frac{a}{\beta_1}, \qquad \varepsilon_t = 0.003\frac{d_t - c}{c}$$

## 22.4 แรงตามแกน หรือดัดร่วมแรงตามแกน

### 22.4.2 กำลังรับแรงอัดสูงสุด

**Table 22.4.2.1 — Pn,max**

| ชิ้นส่วน | เหล็กตามขวาง | Pn,max |
|---|---|---|
| ไม่อัดแรง | ปลอกเดี่ยวตาม §22.4.2.4 | **0.80Po** |

- 0.80 / 0.85 เผื่อความเยื้องศูนย์โดยบังเอิญ (ประมาณ e/h = 0.10 สำหรับเสาปลอก, 0.05 สำหรับเสาเกลียว)

**Po ไม่อัดแรง**

$$P_o = 0.85f'_c(A_g - A_{st}) + f_yA_{st}$$

**Po อัดแรง**

$$P_o = 0.85f'_c(A_g - A_{st} - A_{pd}) + f_yA_{st} - (f_{se} - 0.003E_p)A_{pt}$$

(Apd = พื้นที่ท่อ/sheathing/ลวดอัดแรง — tendon post-tension ที่ grout แล้วใช้ Apd = Apt ได้; fse ≥ 0.003Ep)

- เหล็กปลอกยึดรั้งเหล็กยืนเสา: ตาม §10.7.6.2 และ §25.7.2; เกลียวตาม §10.7.6.3 และ §25.7.3

**ดังนั้น (สรุปเอง):** φPn,max = 0.65 × 0.80Po = **0.52Po** (เสาปลอก), 0.75 × 0.85Po = **0.6375Po** (เสาเกลียว)

### 22.4.3 กำลังรับแรงดึงสูงสุด

$$P_{nt,max} = f_yA_{st} + (f_{se} + \Delta f_p)A_{pt}$$

(fse + Δfp) ≤ fpy; ไม่อัดแรงใช้ Apt = 0

## 22.5 กำลังรับแรงเฉือนทางเดียว

### 22.5.1 ทั่วไป

$$V_n = V_c + V_s$$

**ขีดจำกัดมิติหน้าตัด** (กันวิบัติแบบอัดทแยงและจำกัดรอยร้าว):

$$V_u \le \phi\left(V_c + 8\sqrt{f'_c}\,b_wd\right)$$

- λ ตาม §19.2.4; ต้องคิดผลของช่องเปิดใน web
- ต้องคิดแรงดึงตามแกนจาก creep และ shrinkage (ถ้าไม่แน่ใจ ให้เหล็กเฉือนรับแรงเฉือนทั้งหมด)
- ชิ้นส่วนความลึกแปรผัน: คิดผลของแรงอัดจากการดัดที่เอียงได้

**แรงเฉือนสองแกน (ใหม่ใน 318-19)**
- ละเลยปฏิสัมพันธ์ได้ถ้า vu,x/(φvn,x) ≤ 0.5 **หรือ** vu,y/(φvn,y) ≤ 0.5
- ถ้าทั้งคู่ > 0.5:

$$\frac{v_{u,x}}{\phi v_{n,x}} + \frac{v_{u,y}}{\phi v_{n,y}} \le 1.5$$

### 22.5.2 สมมติฐานเรขาคณิต

- อัดแรง: d = ระยะถึงศูนย์ถ่วงลวดอัดแรงและเหล็ก แต่ **≥ 0.8h**
- หน้าตัดกลม: **d = 0.8 × เส้นผ่านศูนย์กลาง**; bw = เส้นผ่านศูนย์กลาง (ตัน) หรือ **2 × ความหนาผนัง** (กลวง)

### 22.5.3 ขีดจำกัดวัสดุ

- **√f′c ≤ 100 psi** (≈ f′c 10,000 psi) สำหรับ Vc, Vci, Vcw — เกินได้ในคานและตงที่มีเหล็กเฉือนขั้นต่ำตาม §9.6.3.4 หรือ §9.6.4.2
- fy, fyt สำหรับ Vs ≤ ค่าใน §20.2.2.4 (ส่วนใหญ่ **60,000 psi** — คุมความกว้างรอยร้าวทแยง)

### 22.5.4 ชิ้นส่วน composite

- ไม่แยกแบบมีค้ำยัน/ไม่มีค้ำยัน; ถ้าคุณสมบัติต่างกัน ใช้ของแต่ละชิ้นหรือค่าที่วิกฤตที่สุด
- คิด Vc และ Vs เหมือนหล่อเป็นเนื้อเดียวได้ (Vs: ถ้าเหล็กเฉือนยึดเข้าทั้งสองชิ้นตาม §25.7)

### 22.5.5 Vc ชิ้นส่วนไม่อัดแรง (ใหม่ใน 318-19 — คิด size effect และ ρw)

**Table 22.5.5.1**

| เงื่อนไข | Vc |
|---|---|
| **Av ≥ Av,min** | ใช้อย่างใดอย่างหนึ่ง: (a) [2λ√f′c + Nu/(6Ag)]bwd **หรือ** (b) [8λ(ρw)^(1/3)√f′c + Nu/(6Ag)]bwd |
| **Av < Av,min** | (c) [8**λs**λ(ρw)^(1/3)√f′c + Nu/(6Ag)]bwd |

- Nu เป็นบวกเมื่อรับแรงอัด, ลบเมื่อรับแรงดึง; **Vc ≥ 0**
- **Vc ≤ 5λ√f′c·bwd**
- **Nu/(6Ag) ≤ 0.05f′c**
- ρw = As/(bwd) — As นับเฉพาะเหล็กตามยาวที่อยู่ลึกเกิน 2/3 ของ h จากผิวรับแรงอัด
- Av,min ตาม Table 9.6.3.4 และ §10.6.2.2

**Size effect factor**

$$\lambda_s = \sqrt{\frac{2}{1 + \dfrac{d}{10}}} \le 1 \quad \text{(d หน่วย in.)}$$

- d ≤ 10 in. (≈ 250 mm) → λs = 1.0; d = 30 in. → λs ≈ 0.71
- เหตุผล: ผลทดสอบพบว่าเมื่อความลึกเพิ่มเป็น 2 เท่า แรงเฉือนที่วิบัติเพิ่มไม่ถึง 2 เท่า (ชิ้นส่วนไม่มีเหล็กเฉือน) และ ρw ต่ำทำให้กำลังลดลง
- **ผลในทางปฏิบัติ:** ชิ้นส่วนที่มีเหล็กเฉือนขั้นต่ำยังใช้สูตรคุ้นเคย 2λ√f′c·bwd ได้ — ชิ้นส่วนลึกที่ไม่มีเหล็กเฉือน (พื้นหนา ฐานราก) จะได้ Vc ลดลง (แต่ §13.2.6.2 ยกเว้น λs สำหรับฐานรากตื้นและ mat)

### 22.5.6 Vc ชิ้นส่วนอัดแรง

ใช้ในบริเวณที่แรงอัดถ่ายเต็มแล้ว (บริเวณที่ลดลงใช้ §22.5.7)

**วิธีประมาณ (Table 22.5.6.2)** — ใช้ได้ถ้า **Apsfse ≥ 0.4(Apsfpu + Asfy)**; Vc ≥ 2λ√f′c·bwd:

Vc = ค่าน้อยสุดของ
- (a) (0.6λ√f′c + 700·Vudp/Mu)bwd — Mu เกิดพร้อม Vu; **Vudp/Mu ≤ 1.0**; dp ในพจน์นี้ห้ามใช้ 0.8h
- (b) (0.6λ√f′c + 700)bwd
- (c) 5λ√f′c·bwd

**วิธีละเอียด (22.5.6.3)** — Vc = ค่าน้อยกว่าของ Vci และ Vcw:

*Flexure-shear cracking*

$$V_{ci} = 0.6\lambda\sqrt{f'_c}\,b_wd_p + V_d + \frac{V_iM_{cre}}{M_{max}}$$

$$M_{cre} = \frac{I}{y_t}\left(6\lambda\sqrt{f'_c} + f_{pe} - f_d\right)$$

- Vci ≥ 1.7λ√f′c·bwd (ถ้า Apsfse < 0.4(Apsfpu + Asfy)) หรือ ≥ 2λ√f′c·bwd (ถ้า ≥)
- dp ≥ 0.80h; Vd = แรงเฉือนจาก dead load ไม่คูณ factor; Vi, Mmax จากชุดผสมที่ให้โมเมนต์สูงสุดที่หน้าตัด

*Web-shear cracking*

$$V_{cw} = \left(3.5\lambda\sqrt{f'_c} + 0.3f_{pc}\right)b_wd_p + V_p$$

- Vp = องค์ประกอบแนวดิ่งของแรงอัดประสิทธิผล
- หรือใช้แรงเฉือน (D + L) ที่ทำให้หน่วยแรงดึงหลัก = 4λ√f′c ที่แกนศูนย์ถ่วง (หรือที่รอยต่อปีก-web ถ้าศูนย์ถ่วงอยู่ในปีก)

### 22.5.7 Pretensioned ในบริเวณแรงอัดลดลง

- ℓtr = **50db** (strand), **100db** (wire)
- strand ยึดเกาะถึงปลาย: แรงอัดแปรเชิงเส้นจากศูนย์ที่ปลายถึงเต็มที่ระยะ ℓtr
- strand ไม่ยึดเกาะถึงปลาย: แปรจากศูนย์ที่จุดเริ่มยึดเกาะถึงเต็มที่ระยะ ℓtr ถัดไป
- ใช้แรงอัดที่ลดลงในการตรวจเงื่อนไข §22.5.6.2 และคำนวณ Vcw; Vc จาก §22.5.6.2 ≤ Vcw ที่ใช้แรงอัดลดลง

### 22.5.8 เหล็กรับแรงเฉือน

ทุกหน้าตัดที่ **Vu > φVc**:

$$V_s \ge \frac{V_u}{\phi} - V_c$$

**ปลอกตั้งฉาก ตะแกรงลวด หรือเกลียว**

$$V_s = \frac{A_vf_{yt}d}{s}$$

- ปลอกสี่เหลี่ยม: Av = พื้นที่ทุกขาในระยะ s; ปลอกกลม/เกลียว: Av = **2 ×** พื้นที่เหล็ก

**ปลอกเอียง** (ทำมุม ≥ 45° กับแกน, ไม่อัดแรง)

$$V_s = \frac{A_vf_{yt}(\sin\alpha + \cos\alpha)d}{s}$$

**เหล็กดัดคอม้า** (ใช้ ¾ กลางของส่วนเอียงได้ ถ้า α ≥ 30°)
- เหล็กเส้นเดียวหรือกลุ่มเดียว: Vs = ค่าน้อยกว่าของ **Avfy sin α** และ **3√f′c·bwd**
- หลายชุดที่ระยะต่างกัน: ใช้สมการปลอกเอียง
- หลายชนิดในบริเวณเดียวกัน: รวม Vs

**ออกแบบ (commentary):** Av/s = (Vu − φVc)/(φfytd)

## 22.6 กำลังรับแรงเฉือนสองทาง (Punching)

ใช้ **หน่วยแรง** (vu, vn) แทนแรง — vn = vc (ไม่มีเหล็กเฉือน) หรือ vc + vs (มีเหล็กเฉือน) — Shearhead ถูกตัดออกจาก Code (ใช้ตาม 318-14 ได้)

### 22.6.2–22.6.3 ทั่วไป

- d = **ค่าเฉลี่ย** ของความลึกประสิทธิผลสองทิศ; อัดแรง d ≥ 0.8h
- **√f′c ≤ 100 psi**; fyt ≤ §20.2.2.4

### 22.6.4 หน้าตัดวิกฤต

- เส้นรอบรูป **bo น้อยที่สุด** แต่ไม่ใกล้กว่า **d/2** จาก: (a) ขอบหรือมุมของเสา แรงจุด พื้นที่รับแรง (b) จุดเปลี่ยนความหนา (ขอบ capital, drop panel, shear cap)
- เสา/พื้นที่สี่เหลี่ยม: ใช้ด้านตรงได้; เสากลม/หลายเหลี่ยม: คิดเป็นสี่เหลี่ยมจัตุรัสพื้นที่เท่ากัน
- มีเหล็กเฉือน: ต้องตรวจหน้าตัดวิกฤต **d/2 นอกแนวเหล็กเฉือนวงนอกสุด** ด้วย (รูปหลายเหลี่ยมที่ให้ bo น้อยสุด)
- **ช่องเปิดห่างจากขอบเสา < 4h:** ส่วนของ bo ที่อยู่ในเส้นตรงลากจากศูนย์กลางเสาสัมผัสขอบช่องเปิด ถือว่าไม่มีผล (ช่องเปิดห่าง > 4d ไม่มีผลต่อกำลัง)

### 22.6.5 vc ไม่มีเหล็กเฉือน

**Table 22.6.5.2** — vc = ค่าน้อยสุดของ:

| | vc |
|---|---|
| (a) | 4λsλ√f′c |
| (b) | (2 + 4/β)λsλ√f′c |
| (c) | (2 + αsd/bo)λsλ√f′c |

- λs ตาม §22.5.5.1.3 (ใหม่ใน 318-19 — พื้นหนา d > 10 in. ได้ vc ต่ำกว่า 4√f′c)
- β = ด้านยาว/ด้านสั้นของเสาหรือพื้นที่รับแรง (รูปทรงอื่นใช้มิติยาวสุด/มิติตั้งฉาก ของพื้นที่รับแรงประสิทธิผล)
- **αs = 40** (เสาใน), **30** (เสาริม), **20** (เสามุม) — หมายถึงหน้าตัดวิกฤตที่มีพื้นต่อเนื่อง 4, 3, 2 ด้าน

**พื้นอัดแรงสองทาง (22.6.5.4–5)** — ใช้ได้ถ้า (a) มีเหล็กยึดเกาะตาม §8.6.2.3, 8.7.5.3 (b) เสาห่างขอบไม่ต่อเนื่อง ≥ 4h (c) fpc ≥ 125 psi ทั้งสองทิศ:

vc = ค่าน้อยกว่าของ
- (a) 3.5λ√f′c + 0.3fpc + Vp/(bod)
- (b) (1.5 + αsd/bo)λ√f′c + 0.3fpc + Vp/(bod)

(fpc เฉลี่ยสองทิศ ≤ 500 psi; √f′c ≤ 70 psi)

## 22.7 กำลังรับแรงบิด

แนวคิด: **thin-walled tube / space truss** — หลังแตกร้าว แรงบิดรับโดยปลอกปิดและเหล็กตามยาวใกล้ผิว (ไม่นับคอนกรีตรับแรงบิด และไม่ลด Vc เพราะมีแรงบิด)

### 22.7.1–22.7.2 ทั่วไป

- ใช้เมื่อ **Tu ≥ φTth** — ถ้าน้อยกว่า ละเลยแรงบิดได้
- √f′c ≤ 100 psi สำหรับ Tth, Tcr; fy, fyt ≤ **60,000 psi**

### 22.7.3 แรงบิดออกแบบ

| ชนิด | ข้อกำหนด |
|---|---|
| **Equilibrium torsion** (แรงบิดจำเป็นต่อสมดุล — เช่น หลังคายื่นบนคานขอบ) | ต้องออกแบบรับ Tu เต็ม (ลดไม่ได้) |
| **Compatibility torsion** (โครงสร้างอินดีเทอร์มิเนต แรงบิดกระจายได้หลังแตกร้าว — เช่น คานขอบรับพื้น) | Tu ≥ φTcr → **ลด Tu เหลือ φTcr** ได้ (และชิ้นส่วนข้างเคียงต้องออกแบบให้สมดุลกับแรงบิดที่ลดแล้ว) |

### 22.7.4 Threshold torsion Tth (= ¼ Tcr)

Acp = พื้นที่ภายในเส้นรอบรูปนอก, pcp = เส้นรอบรูปนอก

**Table 22.7.4.1(a) — หน้าตัดตัน**

| ชิ้นส่วน | Tth |
|---|---|
| ไม่อัดแรง | λ√f′c·(Acp²/pcp) |
| อัดแรง | λ√f′c·(Acp²/pcp)·√(1 + fpc/(4λ√f′c)) |
| ไม่อัดแรง + แรงตามแกน | λ√f′c·(Acp²/pcp)·√(1 + Nu/(4Agλ√f′c)) |

**Table 22.7.4.1(b) — หน้าตัดกลวง:** เหมือน (a) แต่ใช้ **Ag²/pcp** แทน Acp²/pcp (ช่องว่างเล็ก เช่น ท่อ PT ที่ Ag/Acp ≥ 0.95 ละเลยได้)

|---|---|

### 22.7.6 กำลังบิด Tn = ค่าน้อยกว่าของ

$$T_n = \frac{2A_oA_tf_{yt}}{s}\cot\theta \qquad\qquad T_n = \frac{2A_oA_\ell f_y}{p_h}\tan\theta$$

- At = พื้นที่ปลอกปิด **หนึ่งขา**; Aℓ = พื้นที่เหล็กตามยาวรับแรงบิด; ph = เส้นรอบรูปแนวศูนย์กลางปลอกปิดนอกสุด
- **Ao = 0.85Aoh** ได้ (Aoh = พื้นที่ภายในแนวศูนย์กลางปลอกปิดนอกสุด)
- **θ** (30°–60°): ใช้ **45°** (ไม่อัดแรง หรืออัดแรงที่ Apsfse < 0.4(Apsfpu + Asfy)) หรือ **37.5°** (อัดแรงที่ ≥) — ต้องใช้ θ เดียวกันในทั้งสองสมการ

**ออกแบบ (สรุปเอง, θ = 45°):** At/s = Tu/(2φAofyt); Aℓ = (At/s)·ph·(fyt/fy)

### 22.7.7 ขีดจำกัดมิติหน้าตัด

**(a) หน้าตัดตัน**

$$\sqrt{\left(\frac{V_u}{b_wd}\right)^2 + \left(\frac{T_up_h}{1.7A_{oh}^2}\right)^2} \le \phi\left(\frac{V_c}{b_wd} + 8\sqrt{f'_c}\right)$$

**(b) หน้าตัดกลวง**

$$\left(\frac{V_u}{b_wd}\right) + \left(\frac{T_up_h}{1.7A_{oh}^2}\right) \le \phi\left(\frac{V_c}{b_wd} + 8\sqrt{f'_c}\right)$$

- หน้าตัดตัน: หน่วยแรงเฉือนและบิดรวมแบบ square root (บิดอยู่ที่ผิวนอก เฉือนกระจายทั่ว web); กลวง: รวมโดยตรง
- อัดแรง: d ≥ 0.8h
- กลวงที่ผนังหนาไม่คงที่: ตรวจที่ตำแหน่งที่ผลรวมมากที่สุด
- กลวงที่ผนังบางกว่า Aoh/ph: ใช้ Tu/(1.7Aoh·t) แทน Tuph/(1.7Aoh²)

## 22.9 Shear friction

ใช้ถ่ายแรงเฉือนข้ามระนาบ: รอยร้าวเดิมหรือที่อาจเกิด, รอยต่อวัสดุต่างชนิด, รอยต่อคอนกรีตเทต่างเวลา — แนวคิด: รอยร้าวขรุขระเลื่อนแล้วแยกออก ดึงเหล็กที่ข้ามให้คราก เกิดแรงหนีบ Avffy

- การเตรียมผิวต้องระบุในเอกสารก่อสร้าง; fy ≤ §20.2.2.4 (60,000 psi)
- φVn ≥ Vu (φ = 0.75)

### 22.9.4 กำลังระบุ

**เหล็กตั้งฉากระนาบเฉือน**

$$V_n = \mu A_{vf}f_y \qquad\Rightarrow\qquad A_{vf} = \frac{V_u}{\phi f_y\mu}$$

**เหล็กเอียง** (แรงเฉือนทำให้เหล็กรับแรงดึง; α = มุมแหลมระหว่างเหล็กกับระนาบ)

$$V_n = A_{vf}f_y(\mu\sin\alpha + \cos\alpha)$$

ถ้าแรงเฉือนทำให้เหล็กรับแรงอัด → shear friction ใช้ไม่ได้ (Vn = 0)

**Table 22.9.4.2 — สัมประสิทธิ์แรงเสียดทาน μ**

| สภาพผิวสัมผัส | μ |
|---|---|
| (a) คอนกรีตเทเป็นเนื้อเดียว (monolithic) | 1.4λ |
| (b) เทบนคอนกรีตแข็งตัวที่สะอาด ไม่มี laitance และ **ทำผิวขรุขระ** ความสูงคลื่น ~**¼ in. (≈ 6 mm)** | 1.0λ |
| (c) เทบนคอนกรีตแข็งตัวที่สะอาด ไม่มี laitance **ไม่ได้ทำผิวขรุขระ** | 0.6λ |
| (d) เทบนเหล็กรูปพรรณ (as-rolled) ที่สะอาด ไม่มีสี ถ่ายแรงด้วย headed stud หรือเหล็ก/ลวดเชื่อม | 0.7λ |

λ = 1.0 คอนกรีตปกติ; มวลเบาตาม §19.2.4 แต่ **≤ 0.85**

**Table 22.9.4.4 — Vn สูงสุด** (คอนกรีตต่างกำลัง ใช้ f′c ที่น้อยกว่า)

| สภาพ | Vn สูงสุด |
|---|---|
| คอนกรีตปกติ เทเป็นเนื้อเดียว หรือเทบนคอนกรีตแข็งตัวทำผิวขรุขระ ~¼ in. | ค่าน้อยสุดของ 0.2f′cAc, (480 + 0.08f′c)Ac, 1600Ac |
| กรณีอื่น | ค่าน้อยกว่าของ 0.2f′cAc และ 800Ac |

(Ac = พื้นที่หน้าตัดคอนกรีตที่ต้านแรงเฉือน, หน่วย lb)

- **แรงอัดถาวรข้ามระนาบ** บวกเข้ากับ Avffy ได้ (ลดเหล็กที่ต้องใช้)
- **แรงดึงสุทธิข้ามระนาบ** ต้องเพิ่มเหล็กรับแรงดึงนั้นเข้าไป
- โมเมนต์ข้ามระนาบไม่ต้องเพิ่มเหล็ก (แรงอัด-ดึงจากการดัดสมดุลกัน) เว้นแต่เหล็กรับแรงดัดที่ต้องการ > เหล็ก shear friction ในโซนดึง

### 22.9.5 รายละเอียด

- เหล็กที่ข้ามระนาบต้อง **ยึดให้ได้ fy ทั้งสองข้าง** (ยึดเกาะ, อุปกรณ์กล, dowel เกลียว) — และควรยึดเข้ากับเหล็กหลัก
- ไม่มีโมเมนต์: กระจายสม่ำเสมอตามระนาบ; มีโมเมนต์: วางในโซนรับแรงดึงจากการดัดเป็นหลัก
